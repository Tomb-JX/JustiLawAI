# 回路清单

> 版本 v1 · 2026-10-28
> 记录已经发生过的"兜圈子"。每条写明**触发信号**：发现自己正在做信号里描述的事时，先停下来读这一条。

## R1 法律放在哪

- **触发信号**：
  - 提议把档位当成模型的预测目标或输出头；
  - 提议在模型输出之后"按法律截断 / 过滤 / 投影"；
  - 提议把省级档位当成"一个特征"拼进分类器；
  - 提议严格按成文推导、不看实务。
- **发生过**：两周里换了六种答法。
  1. 10-15 设计："门槛只作约束和特征"。
  2. 10-22 至 10-26：完全不用法律。
  3. 10-26 冠军栈：档位由文本预测（EXP-030）。
  4. 10-28 D-005：分档定种类（正确方向）。
  5. 10-28 概率版：严格按原文推导（EXP-049）。
  6. 10-28 会话："先自由学，再用法律截断"。
- **正确方向其实早有人提**：法医诊断 §4.3（10-26）、外部对照 §8 B（10-26）、ml-review §5（10-27）、v5 冲刺"下一轮"（10-27），都写了"档位 + 档内偏差"或"规则生成候选、模型只在合法选项内学档内位置"。但落地时，档位要么由文本预测，要么档内模型仍以历史种类为条件。
- **根因**：法律的三种角色（硬边界、定档、特征）混在一起说，没有一份决策写明每层里法律是什么角色。
- **现在的答案**：[ADR-001](./adr/ADR-001-law-first.md)。

## R2 "要素有没有用"

- **触发信号**：引用"要素无增益""数额信息无用"之类的结论，来支持绕开要素或绕开法律。
- **发生过**：
  - 10-20 至 10-22 在 n=23、n=168 上测得"要素无增益"，M4 此后绕开要素一周。
  - 实际测的是"银标要素取 log 后拼进线性分类器"。
  - 10-28 让要素经过法律查表，唯一子集上 +0.3。
- **根因**：结论被引用时丢了条件。
- **现在的答案**：[C-08](./claims.md)（拼进分类器无增益）与 [C-01](./claims.md)、[C-09](./claims.md)（经法律机制有增益）同时成立；接入方式决定结论。

## R3 抽取和绑定反复重建

- **触发信号**：提议写金额提取器、正则、角色分类器、归属模型、NIL 判定，或者"先把要素抽准再说"。
- **发生过**：
  - 10-21 至 10-27 做了十余轮，标注约 ¥120，服务做了三版，10-27 停线。
  - 10-28 会话中又两次滑回：重做简单金额提取器；用通用修饰词写正则。
- **根因**：停线决定只写在状态文档的一个括号里，没有关闭清单，也没有重开条件。
- **现在的答案**：[ADR-002](./adr/ADR-002-llm-extraction-in-experiments.md)；[Q-11](./questions.md#已关闭)。

## R4 已知事实被重新发现

- **触发信号**：
  - 发现"实务和成文不一致"；
  - 准备用处罚结果反推要素或先验；
  - 准备按成文规则推导缺失要素的后果。
- **发生过**：
  - 实务偏离被发现了四次：
    1. 10-26 方案 C：偏离约 36%，江苏第一档"其他"类低于档仍罚 22 条；
    2. 10-27 M2 软建议：25 条中 3 条的历史种类不在规则候选内；
    3. 10-27 信息链对账：河北 8 条规则建议与历史不符；
    4. 10-28 概率版：江苏 100–500 元 29 条中 28 条罚款，于是失败。
  - 删失 EM 文档（10-27）已经警示"后验当特征会循环论证"，10-28 又从头推了一遍等价性。
- **根因**：事实散在按日期命名的报告里，没有按问题聚合；新设计前不知道去哪查。
- **现在的答案**：[C-03](./claims.md)（E 层偏离）、[C-13](./claims.md)（等价性）。动手前先查 claims.md 对应层。

## R5 结论被推广到没检验过的条件

- **触发信号**：用"不可预测""无效""无增益"去否定一个**条件不同**的新设计。
- **发生过**：
  - 10-28 预注册 A 以历史种类为条件、用通用数额阈值，结论写成"档内数额不能从可迁移的信息中预测"。
  - 引擎因此只出全国按种类的分布。
  - 但"省份 × 规则档位"这个条件从没被检验过（EXP-050）。
- **根因**：同 R2，结论的范围比实验宽。
- **现在的答案**：[C-07](./claims.md) 的"没检验什么"一列；[Q-01](./questions.md#开放)。

## R6 文本模型反复调参

- **触发信号**：提议再调 TF-IDF 分类器的损失、权重、分解、融合方式，或者"先把文本基线做强"。
- **发生过**：
  - 批次分层 softmax、两段式数值、事件分组、类别权重、LinearSVC、机关先验融合、目标人身份……增益多在噪声带内。
  - ml-review 指出约 30 个实验在同一批 357 条上反复选冠军。
- **根因**：没有"这一层已经做到头"的记录；文本模型是最容易动手的地方。
- **现在的答案**：[Q-20](./questions.md#搁置) 搁置；在 ADR-001 下，文本模型只负责候选内选择和无基准省份兜底。

## R7 评估口径漂移

- **触发信号**：拿两个实验的数字直接比较，或新实验自己定一套切分。
- **发生过**：
  - 切分换了七种：混池 → 分队列 → 批次轴 → 机关轴 → 事件 × 机关 → LOBO → 时间外推。
  - 机关轴先按 `event_id` 首段分组，后按真实机关字段，两者分数不能相减。
  - 指标也在换：准确率、Macro-F1、MAE、±20%、RPS、命中率、前 2。
- **根因**：评估协议没有版本。
- **现在的答案**：[eval-protocol.md](./eval-protocol.md)。每个实验注明协议版本；跨版本的数字不直接比。
