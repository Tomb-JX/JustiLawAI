## 1. 阶段与产出

  - 四.（三）.14 中"望风看场"（`conduct.role` = 望风者）→ 第三档；接送、发牌坐庄、兑换筹码无字段，保留缺口。

### P2 规则生成特征（E 层）
- 新模块 `app/discretion/rule_features.py`：
  - 从两省规则文件枚举固定特征名单：规则结论（唯一 / 候选 / 无分档 × 四种类）；每个计量（档位序号 one-hot、档内位置 = log(值 / 本档下限)、缺失、取值来源）；每个分类（落在哪类门槛）；每个 `elevate` / `floor_hint` 条件（三值）；国家法修正情节触发（`_active` 的方向）；省份；
  - 每个案件跑一次 `assess`，从 `stake_threshold.computation` 与 `assessment.directions` 填值；
  - 名单与规则同源：规则改了，名单随之改，参数文件里存名单哈希，加载时校验。
- 学习笔记：规则生成特征的原理与做法（同步本地）。
- **停止条件**：若特征维数 > 训练样本数的 1/5（约 95），先合并稀有条件（出现 < 5 次的条件并入"其他条件"），记录做法。
