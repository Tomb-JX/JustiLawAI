# ADR-004 新法案件推定沿用省级分档判断处罚种类

- **状态**：现行（同时登记为偏离 [D-006](../../05-research/deviation-log.md)）
- **日期**：2026-10-28
- **决策者**：负责人指示（"先查法宝新法裁量标准，再做接口和页面"）
- **关联**：ADR-003、Q-05

## 背景

两省基准按旧法制定。决定日期在 2026-01-01 之后的案件，此前一律返回空档位。

## 证据

- 2026-10-28 法宝关键词检索 4 次：河北、江苏省公安厅和公安部层面都没有新法版赌资裁量标准，旧版仍标现行有效。
- 新法第八十二条与旧法第七十条档次结构相同，只提高了罚款上限。

## 决定

- 新法案件推定沿用省级赌资门槛与档次判断处罚种类，结果标 `law_alignment=新法推定沿用`，`applicability=provisional`，并写入 needs_review。
- 档位原文中的罚款数额视为旧法数额；本案数额按新法法定幅度过滤档内分布。

## 后果与局限

- 旧法时期的检验结果不能证明新法案件上的准确率；新法时期没有数据（Q-05）。
- 第一档"五百元以下罚款"在新法下按 1000 元还是 500 元封顶，属省厅口径，未定。页面同时展示原文与新法幅度。

## 重开条件

省厅发布新法版基准时，重录基准并撤销本推定；或者有了新法时期的数据。
