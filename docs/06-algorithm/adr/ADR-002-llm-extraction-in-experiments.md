# ADR-002 实验期要素抽取交给大模型，算法研究集中在裁量层

- **状态**：现行
- **日期**：2026-10-28
- **决策者**：负责人（原话："语义化抽取理解的任务实验阶段直接交由大模型去做……我允许调用大模型直接处理到文本中所有能提取理解出来的要素字段，就是这样之后的裁量算法优化"）
- **关联**：Q-06、[关闭的 Q-11](../questions.md#已关闭)、[loops.md R3](../loops.md#r3-抽取和绑定反复重建)

## 背景

10-21 到 10-27，A 层（金额候选、角色、归属、NIL）做了十余轮，标注花费约 ¥120，金额绑定服务做了三版。根因是零形回指（[C-11](../claims.md)），这条线 10-27 停掉了。10-28 会话中又两次滑回 A 层：提出重做金额提取器，以及用通用修饰词写正则。

## 考虑过的选项

| 选项 | 结论 |
|---|---|
| 继续自研抽取和绑定 | 否：根因未解，且 M4 不消费绑定（[C-22](../claims.md)） |
| 先做简单金额提取器，再研究裁量 | 否：等于重新进入 A 层（R3） |
| **实验期用人工标注或大模型抽取全部可抽要素，算法精力放在 C、D、E 层** | **采纳** |

## 决定

- 实验和评估中，A 层输入取自人工标注（如两省 397 条）或大模型抽取，二者分开标记来源。
- 研究问题只在 C、D、E 层提出；A 层的错误视为输入噪声，结果须在人工标注子集上同口径对照。
- 上线时要素从哪来、推理时是否调用大模型，**不在本决定范围内**（Q-06）。金额绑定服务的既有约束（推理不调大模型）仍记录在案，待 Q-06 一并处理。

## 后果

- 大模型抽取会花钱：每批先估算单价和总额，经负责人批准再跑（B-12 / I-21 纪律）。
- A 层相关文件（`research/discretion/unify/`、binding 服务）只维护，不再扩展。

## 重开条件

C、D 层的研究证明某个要素必须自动抽取，而大模型抽取在该要素上不可用（例如成本或一致性不达标）。
