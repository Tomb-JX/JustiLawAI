# ADR-001 法律先行：法律在各层的角色

- **状态**：现行
- **日期**：2026-10-28
- **决策者**：负责人（原话："法律规则对于要素判定的约束又变成了后验截断……提前规则化的挡位处理也能显著提升后续的处罚金额等数值回归率"）
- **关联**：[problem.md §3](../problem.md#3-分层)、[loops.md R1](../loops.md#r1-法律放在哪)、ADR-003、Q-01、Q-04

## 背景

"法律放在模型的哪里"这个问题，两周里换了六种答法（[R1](../loops.md#r1-法律放在哪)），每次都从头推一遍。原因是三种不同的东西混在一起说：

1. **法定空间**：罚则、时间效力、修正情节；
2. **省级分档**：要素 → 档位 → 种类，与实务大体一致，但有系统偏离；
3. **一个可选特征**。

## 考虑过的选项

| 选项 | 做法 | 结果 | 结论 |
|---|---|---|---|
| a. 法律只作特征和约束 | 原设计 v0.4："门槛只作约束和特征，不直接决定结果" | 档位拼进 LR，增益 ≈0（[C-09](../claims.md)） | 否：法律的作用被接入方式吃掉 |
| b. 不用法律 | 10-22 至 10-26 M4 只读文本 | 门禁全部不达标；唯一种类子集上比规则低约 0.3（[C-01](../claims.md)） | 否 |
| c. 档位当文本模型的预测目标 | 10-26 冠军栈的档位头 | 罚款 MAE 首次低于中位数，但档位是猜出来的（[C-16](../claims.md)） | 否：档位可以由要素按法律算出，不应去猜 |
| d. 按原文推导缺失要素 | 10-28 概率版：缺失要素当隐变量，逐一按原文推导再加权 | RPS 更差（[C-13](../claims.md)、[C-03](../claims.md)） | 否：实务偏离成文；先验由结果反推，构成循环 |
| e. 先自由学，再用法律截断 | 10-28 会话中的"分省台阶模型"提议 | 未实施，负责人否定 | 否：法律退化为事后过滤，回到纯要素判别 |
| **f. 法律先行** | B 层是硬边界；C 层定档，并决定 D 层的结构；只学 D、E 层 | 种类部分已由 ADR-003 验证；档内部分待 Q-01 | **采纳** |

## 决定

| 层 | 法律的角色 |
|---|---|
| B 法定空间 | **硬边界**。任何输出不得越出 Ω；修正情节按法定效果展开 |
| C 基准定档 | **定档**。要素足够时，档位和种类由规则算出，不由模型预测；要素不足时给候选集合，不猜 |
| D 裁量 | **档位决定结构**：<br>• 用哪个子模型（每个"省份 × 档位"一个）；<br>• 取值范围（该档的法定幅度）；<br>• 有哪些特征（档内位置、该档是否可减轻等，只在定档之后才有意义）。<br>学习只发生在档位给定之后 |
| E 偏离 | 成文结论照常输出；实务偏离作为单独的学习或提示对象，**不去改 C 层规则来迎合实务** |

## 后果

- D 层所有模型以"省份 × 规则档位"为索引。现行引擎的档内分布是全国按种类混合的，与本决定不一致，修正待 Q-01。
- 江苏低额"成文免罚、实务罚款"（[C-03](../claims.md)）属于 E 层：C 层照原文给结论，E 层给实务分布（Q-02）。
- 未录基准的省份没有 C 层，只有 B 层和统计参考（Q-04）。法律先行的覆盖面取决于录入了多少省份。
- 任何把档位当成模型预测输出、或在模型输出后再按法律截断的设计，都违反本决定。

## 重开条件

在预注册的、两省都有足够样本的未见机关评估上，按"省份 × 规则档位"条件化的 D 层模型，系统性地输给不使用规则档位的模型。
