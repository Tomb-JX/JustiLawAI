# ADR-006 只在河北、江苏两省上调试优化，暂不扩录其他省份基准

- **状态**：现行
- **日期**：2026-10-28
- **决策者**：负责人（原话："就算录入了基准，也没有那么多的相应省份的训练数据……应当专门针对已有的省份做好调试优化，而不是盲目的扩基准"）
- **关联**：Q-04（转搁置）、ADR-001

## 背景

法律先行（ADR-001）的覆盖面取决于录入了哪些省份的基准。我曾建议 Q-04 扩录数据量大的省份。

## 考虑过的选项

| 选项 | 结论 |
|---|---|
| 扩录数据量大的省份基准（法宝积分） | 否：录了基准也缺该省的已处理训练与检验数据，无法验证；已处理数据主要集中在江苏 |
| **只在两省上把 C、D、E 层做对，按错误来源逐项优化** | **采纳** |

## 决定

- 两省之外只给国家法定空间与文本统计参考，不再投入。
- 算法优化的优先级按两省的错误来源分解决定（EXP-054）。

## 重开条件

某个其他省份积累了足以独立检验的已处理数据（例如按 EP-3 口径 ≥ 300 条，且有足够的未见机关）。
