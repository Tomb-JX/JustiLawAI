# ADR-003 两目标省的处罚种类由省级分档确定

- **状态**：现行（同时登记为偏离 [D-005](../../05-research/deviation-log.md)）
- **日期**：2026-10-28
- **决策者**：负责人批准（"自己做出合理决定""合并好"）
- **关联**：ADR-001、[EXP-046](../experiments.md)、Q-10、[规则链路验证](../../05-research/2026-10-28-rule-chain-validation.md)

## 背景

原设计让 M4 从数据学处罚种类，省级门槛只作特征。两省基准三档分别对应罚款、拘留、并处，种类本可由要素按规则算出。

## 考虑过的选项

| 选项 | 证据 | 结论 |
|---|---|---|
| 种类由 M4 文本模型学 | 规则给出唯一种类时，文本只有 0.38–0.40 | 否 |
| 省级档位作为文本模型特征 | 增益 ≈0（[C-09](../claims.md)） | 否 |
| **规则给出唯一种类就用规则；给出多个候选时，文本概率只在候选内选；无分档时退回文本，并标为统计参考** | 唯一子集上规则 0.68–0.72（[C-01](../claims.md)） | **采纳** |

## 决定

- 路由：`rule_single` / `rule_candidates` / `model_fallback` / `undetermined`，实现在 `justilaw-api/app/discretion/decide.py`。
- 河北计量口径：个人赌资查明按个人；个人不明按一场赌资门槛；一场达到起罚线而个人未达第一档时按第一档。
- 河北参与赌博有升档条件、但赌资不明时，返回候选{未达起罚标准, 升档}。
- schema 升到 1.2.0，新增 `conduct.gambling_form`（江苏方式类别）。

## 后果与局限

- 检验 331 条整体 +0.06，未达预注册的 +0.10；江苏未验证，河北达标。**本决定是设计改向，不是放行依据。**
- "赌资不明时升档给候选"是看过检验结果后提出的，须用新数据检验（Q-10）。
- 公开文书约一半不写赌资，唯一覆盖只有 21%（[C-02](../claims.md)）。

## 重开条件

在新数据上，唯一子集里规则不再优于文本；或者省厅发布新版基准。
