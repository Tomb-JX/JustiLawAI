# ADR-010 引擎定位与分层边界：规则由基准逐条台账驱动，学习层只做实务校准与偏离，档内只给统计参照

- **状态**：现行（第 4 条"逐条台账"与第 5 条"特征由规则生成"待实现）
- **日期**：2026-10-28
- **决策者**：负责人（"法律决定档位和种类，机关决定档内落点……要不要把这个定位连同前面的结论一起写进 ADR-010？"——"可以"）
- **关联**：ADR-001、ADR-005、ADR-007、ADR-009；Q-21、Q-26、Q-27；C-04、C-05、C-25、C-26、C-39、C-44、C-45；loops.md R9、R10；偏离日志 D-009（提议）

## 背景

提议检查单：
1. **改哪一层**：横切。重新划定 C（规则）、D（档内）、E（实务）、F（输出）的边界与评价标准。
2. **碰到的结论与关闭项**：档内细分对未见机关无增益（C-25、C-26、C-39），档内要素学习第一阶段未通过（C-45）；新数据低准确率主因是输入缺失与规则漏编（C-44）；Q-26 终端用户与目标函数悬而未决。
3. **法律的角色**：不变（ADR-001）：硬边界、定档、种类。
4. **部署可得性**：不变（ADR-009）：要素 + 辖区 + 日期。
5. **评估**：本 ADR 规定各服务的评价口径（见决定 1）。
6. **零成本证伪**：已做，即 EXP-063、EXP-064。

10-28 的三件事促成这条决定：
- **规则一再漏编，靠新数据报错再补**：江苏基准一（三）"每次赌博查实的赌资应当累计计算"、一（五）"网络按投注总额认定"一直没编进规则，而要素里早已有"累计赌资"（C-44）。编码是"照档位表抄门槛"，没有逐条对照原文。河北规则库里只存了 869 字的节选。
- **特征越加越多**：RAP 的特征是手工挑的，与规则没有绑定；每次看了新数据的错误再补一个特征，等于拟合手头数据。
- **档内学习不可行**：以实际种类为条件，结构化要素预测档内取值，对未见机关显著差于不用要素的分布（C-45）；方差分解显示机关间差异占档内方差 11%～62%，其余大多是公开文书没写的信息。同一事件内几乎同判（C-04），说明这不是随机，而是**机关习惯 + 未记录的信息**，对陌生机关不可预测。

## 考虑过的选项

| 选项 | 结论 |
|---|---|
| 继续以"预测实际处罚的准确率"为主目标，加更复杂的模型（分层、深度、提升树） | 否：档内的信息上限由数据决定，提升树同样更差（C-45）；种类层的误差主要来自输入缺失和成文≠实务，不是模型能力 |
| 退回纯规则引擎，不要学习层 | 否：成文与实务确有系统差异（C-32、C-44），实务参照对公众预期和偏离审查有用；RAP 在种类层有校准价值（C-37） |
| **按"法律定框架、机关定落点"分层定位：规则层求完整、学习层求校准、档内只给参照，服务价值落在合法性、一致性与偏离量化** | **采纳** |

## 决定

1. **定位与目标函数**（同时回答 Q-26）：引擎的核心价值是**合法性、一致性与偏离的量化**，不以"预测实际处罚的准确率"为主判据。各服务的评价口径：
   - A 执法计算器：规则完整且可追溯（台账覆盖率 100%、规则测试通过）；要素不全时候选覆盖率与补查提示的有效性；
   - B 公众预期：输出"结果范围 + 条件"，评校准度与区间覆盖率（分组共形，Q-07）；
   - C 决定书审查：偏离检测的误报与漏报，偏离理由可追溯。
   - 种类准确率（要素齐全、规则能定档的记录）仍作为诊断指标报告，不作发布门槛。
   服务排序：A 与 C 为主，B 为辅。产品需求用户角色表补"执法 / 法制审核人员"一项，由产品负责人确认。
2. **处罚种类 = 法律框架**：由国家法与省级基准确定（ADR-003、ADR-008 不变）；规则给不出唯一结论时给候选和补查提示，不猜。
3. **档内落点 = 机关裁量**：
   - 基准或国家法**写明的**档内规则（档内从重从轻情节、"可以并处罚款"的适用条件等）编成规则，经台账覆盖；
   - **没写明的部分只给统计参照**（全国按种类的历史分布、法定幅度过滤，ADR-005），标"参照，不是法律结论"；
   - 不做要素式档内学习（C-45），不按机关、省份、档位细分（C-25、C-26、C-39）。
4. **规则由逐条台账驱动**（国家层与省级层同一方法）：
   - 每部规范原文切成条目，每条必须有处置：已编码（指向规则）/ 交给要素定义（指向字段）/ 不适用（写理由）/ 编不了需人工（写原因）；
   - 测试强制：原文中出现无处置的条目即失败；规则引用的条文必须逐字出自原文（现有测试的扩展）；
   - 台账由负责人或法律组复核"不编的理由"；
   - 规范库必须存**完整原文**，不存节选；河北基准需补全原件后建台账。
5. **要素与特征由规则推出**：
   - 要素表是各省共用的概念，新增字段必须注明是哪条条文要求的；条文不要求、对追溯或涉刑门槛有用的字段保留抽取但不参与裁决；
   - RAP 特征 = 规则结论 + 规则读到的每一个量 + 每一个升档 / 从重条件，由规则声明自动生成，不再手工挑选；
   - **禁止以"某批数据上的错误"作为加规则、加特征的理由**；改动必须引用条文（规则）或经预注册检验（学习层）。
6. **学习层的范围**：
   - 采纳：RAP（种类层实务校准，ADR-007）、大模型要素抽取（A 层，ADR-002）、偏离检测（共形 p 值，待做）；
   - 备选（未采纳，须单独提议与预注册）：离散选择模型分析"机关遵循基准的程度与偏离方向"（描述性）；规则归纳把实务偏离写成可读规则（描述性，供审查与法律组参考）。

## 证据

- C-45（EXP-064，预注册）：616 单元按机关留出，要素模型 RPS 0.224 vs 不用要素 0.191（+0.033，区间 +0.014 ~ +0.050）；提升树同样更差；机关 ICC 0.11～0.62。
- C-44（EXP-063）：工单 B 79% 缺本人与一场赌资；27 条金额已标为累计赌资而规则与 RAP 不读；补上后河北网络投注全判第三档、7/21 与实际一致。
- C-04：同一事件内几乎同判。C-05：罚款 91% 落在法定锚点。
- 同类研究对照：事前、结构化输入的实务裁量计算器均不报准确率，目标是合法与一致。
