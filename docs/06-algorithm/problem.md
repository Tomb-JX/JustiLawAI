# 问题骨架

> 版本 v1 · 2026-10-28 · 稳定文档，改动走 ADR
> 任何算法提议，先说它改的是本文哪一层（[README 提议检查单](./README.md#提议检查单任何新算法提议先答这六问)第 1 问）。

## 1. 任务

给定一起赌博类治安案件的事实、辖区、行为日期和决定日期，输出对**某一名违法行为人**的处罚建议：
- 适用的法律与法定处罚空间；
- 处罚种类：不予处罚 / 罚款 / 拘留 / 拘留并处罚款；
- 拘留天数、罚款数额的分布；
- 依据、缺失信息、与拟处罚意见的偏离。

定位是**辅助**：结论供办案人参考，事实由人确认，结论可被推翻（法发〔2022〕33 号）。

**非目标**：刑事量刑；替代人工决定；在不知道辖区和日期时给出确定结论。

## 2. 处罚是怎样一层层定出来的

| 环节 | 规定 | 性质 |
|---|---|---|
| 罚则 | 旧法《治安管理处罚法》（2012）第七十条；新法（2025 修订，2026-01-01 施行）第八十二条。两者档次结构相同：一般情形"五日以下拘留**或**罚款"；情节严重"十日以上十五日以下拘留**并处**罚款"。新法只提高罚款上限（500 → 1000；500–3000 → 1000–5000） | 法律本身 |
| 时间效力 | 从旧兼从轻（行政处罚法第三十七条），按行为时与决定时选罚则 | 法律本身 |
| 修正情节 | 减轻、从轻、从重、不予处罚、不执行拘留、多个违法行为合并执行（≤20 日） | 法律本身；其中"可以"减轻、从轻属于裁量 |
| 赌资认定 | 公通字〔2005〕30 号第六条：个人投注无法确定时，按参赌财物总额除以人数 | 部门规定 |
| 省级基准 | 把"赌资较大""情节严重"细化成档位，**每档直接对应一种处罚**。两目标省都是三档：第一档罚款、第二档拘留、第三档并处 | 省级规范；**与实务有系统偏离**（[C-03](./claims.md)） |
| 机关取值 | 档内罚多少、拘几天；一般档选拘留还是罚款（无省级基准时）；"可以"减轻用不用 | 裁量 |

两目标省的分档要点（原文已逐字核验，见 `justilaw-api/app/discretion/norms/provinces/`）：

- **河北**（2021 修订版第 120、121 条）：
  - 参与赌博按个人赌资 200 / 500 / 1000 元，或一场赌资 500 / 1000 / 2000 元分档。个人查明按个人；个人不明按一场；一场达到起罚线而个人未达第一档时按第一档（D-005 口径）。
  - 国家工作人员、公共场所、互联网投注直接升到第三档。
  - 为赌博提供条件按累计获利 200 / 500 / 1000 元分档。
- **江苏**（苏公规〔2019〕1 号）：
  - 按方式分两类。聚众、网络、赌博机、赌场、私彩一类，个人或人均赌资 100 / 500 / 1000 元；其他赌博活动一类，500 / 2000 / 5000 元。
  - 未达起罚下限的，免予处罚。

## 3. 分层

| 层 | 回答什么 | 法律在这一层的角色 | 学不学 |
|---|---|---|---|
| **A 事实** | 本案要素：本人赌资、现场合计、人数、方式、组织形式、角色、前科、年龄、身份等 | — | 实验期交大模型抽取（[ADR-002](./adr/ADR-002-llm-extraction-in-experiments.md)），本层不做算法研究 |
| **B 法定空间** | 适用哪部法；合法处罚组合 Ω；修正情节的法定效果 | **硬边界**：任何输出不得越出 Ω | 不学 |
| **C 基准定档** | 要素 → 省级档位 → 处罚种类；要素不足时给候选集合 | **定档，并决定 D 层的结构**（[ADR-001](./adr/ADR-001-law-first.md)、[ADR-003](./adr/ADR-003-type-by-provincial-band.md)） | 不学档位本身 |
| **D 裁量** | 法律留给机关的选择：候选内选哪个、档内取多少、"可以"减轻用不用、无省级基准时一般档选拘留还是罚款 | 档位决定用哪个子模型、取值范围和特征 | **学，且只学这一层** |
| **E 偏离** | 实务和成文不一致：江苏低额仍罚、河北网络赌博升档执行不一 | 成文结论照常输出，偏离单独表达 | 学或提示 |
| **F 输出** | 分布、区间、依据、缺失信息、偏离预警、类案 | 依据只引用已核验条文 | 校准与区间 |
| 横切 | 评估协议、目标总体、数据供给 | | |

**法律先行原则**（[ADR-001](./adr/ADR-001-law-first.md)）：C 层先定档，档位决定 D 层；学习只做 D、E 两层。法律既不是事后截断，也不是一个可有可无的特征。

## 4. 部署时什么可得

| 信息 | 部署时 | 说明 |
|---|---|---|
| 事实文本、辖区、行为日期、决定日期 | 可得 | 办案人手里有完整案卷，要素比公开文书全 |
| 要素 | 可得（经人确认） | 引擎第一版由人填写；自动抽取是 A 层问题 |
| 机关身份 | 可得 | 但"本机关习惯"不能冒充通用规律（[C-07](./claims.md)、[C-10](./claims.md)） |
| 采集批次 | **不可得** | 批次先验不能用（[C-06](./claims.md)） |
| 处罚结果 | **不可得** | 训练时可用作标签；凡是从结果反推出的要素或先验，部署时都不存在（[C-13](./claims.md)） |

**规范输入（ADR-009）**：引擎核心只吃要素 + 辖区 + 日期；案卷文本经抽取成要素、人工确认后才进入。公开决定书事实段与部署时的案卷不是同一种文本，不能用它直接训练部署用的预测器。

协作决策 A-05 已规定：历史观察处罚（训练目标）、规范层结论（单独报告）、部署时可知输入三者分开。

## 5. 目标总体与数据现实

- **目标总体**：河北、江苏两省公安机关作出的赌博类治安行政处罚决定。其他省份只给国家法定空间和统计参考。
- **训练数据**：公开处罚决定书（法宝为主），全部是旧法时期决定；新法时期没有数据。
- **公开文书与办案案卷的差别**：公开文书约一半不写可用赌资（[C-02](./claims.md)），所以公开数据上测得的规则覆盖率低于真实使用。
- **数据集中**：两省样本集中在少数机关（河北定兴、辛集等），机关习惯和省级规律容易混淆。评估必须有"未见机关"一轴（[eval-protocol.md](./eval-protocol.md)）。
- **标签**：处罚结果来自决定段，可以客观解析，质量不是瓶颈；要素是银标或人工标注，不是专家金标。
