# 结论台账

> 版本 v1 · 2026-10-28
> **用法**：引用结论时写编号（如"见 C-07"），不要复述成更宽泛的话；"没检验什么"一列和结论同样重要（[A2](./README.md#维护规则)）。
> **置信**：
> - **预注册**：判据先于结果，在未看过的数据上检验；
> - **开发**：在开发数据上测得，可能有选择偏差；
> - **探索**：小样本或未预注册，只作方向；
> - **理论**：由问题结构推出，附实测佐证。
> 被新证据推翻的结论不删除，在"状态"里标"被 C-xx 取代"。
