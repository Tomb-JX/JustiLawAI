# 术语表

> 团队统一用语，文档 / 代码 / 沟通均以此为准。按主题分组，持续补充。

## AI / 平台术语

| 术语 | 英文 | 含义 |
|---|---|---|
| 大模型 / LLM | Large Language Model | 大语言模型，平台的核心推理引擎 |
| 智能体 | Agent | 带人设（系统提示词）、能力（工具/知识库）的对话应用单元 |
| 工作流 | Workflow | 节点组成的可视化编排流程，按图执行；DSL 指其 `{nodes, edges}` JSON 描述 |
| 节点 | Node | 工作流中的一个步骤（LLM / 检索 / 分支 / HTTP 等） |
| RAG | Retrieval-Augmented Generation | 检索增强生成：先从知识库检索相关片段，再让模型基于片段回答 |
| 知识库 | Knowledge Base / Dataset | 文档集合，解析成分段并向量化后供 RAG 检索 |
| 分段 | Chunk | 文档切分后的最小检索单元 |
| 向量 / Embedding | Embedding | 文本的语义向量表示，用于相似度检索 |
| 相似度分数 | Score | 检索片段与查询的相关程度（0~1，越高越相关） |
| 命中测试 | Hit Testing | 输入查询查看检索结果的调试功能 |
| 提示词 | Prompt | 发给模型的指令文本；「系统提示词」定义模型人设与规则 |
| Token | Token | 模型计费/计长的最小文本单位，汉字约 1~2 token |
| 温度 | Temperature | 采样随机性参数，越低越确定 |
| 流式输出 | Streaming / SSE | 服务端逐段推送生成结果；前端打字机效果 |
| 引用标注 | Citation | 回答中 [1][2] 标记的来源片段，可溯源 |
| 结构化输出卡片 | Card | 消息以预定义卡片渲染（预测卡/案例列表卡/风险清单卡），区别于纯 Markdown |
| Mock | Mock | 用假数据先行开发；本项目用 MSW 按契约打桩 |
| MSW | Mock Service Worker | 前端 Mock 工具，拦截请求返回约定数据 |

## 法律术语

| 术语 | 含义 |
|---|---|
| CAIL2018 | 中国法研杯法律智能挑战赛数据集（罪名/法条/刑期预测），本项目语料基础 |
| 类案检索 | 按案情相似度查找已决案例 |
| 罪名预测 / 法条预测 / 刑期预测 | CAIL 三大子任务；本案延伸到行政处罚预测 |
| 行政处罚 | 赌博类行政案件的典型后果：行政拘留、罚款（治安管理处罚法） |
| 案由 / 案号 | 案件类别标识 / 案件唯一编号 |
| 裁判文书 | 法院作出的判决书、裁定书等 |
| 处罚决定书 | 行政机关作出的处罚决定文书（本项目文书起草对象之一） |
| 法律援助 / 法律意见 | 平台输出仅为辅助参考，**不构成正式法律意见**（合规声明） |
