# JustiLawAI 产品需求说明（PRD 精简版）

> 版本 v0.1 · 2026-10-14 · 配套：[前端设计方案](../02-design/frontend-design.md) · [API 契约](../02-design/api-contract.md)

## 1. 项目背景与定位

通过 AI 大模型辅助**赌博类行政案件**的裁决，建设一个法律大模型智能体工作平台：平台提供通用的对话、智能体、工作流、知识库（RAG）能力，并在赌博类行政案件场景上做重点定制（处罚预测、类案检索、文书起草）。

**价值主张**：
- 对公众 / 当事人：低成本获得法律咨询与结果预期
- 对执法 / 司法人员：类案参考、处罚幅度校准、文书初稿生成，提升效率与一致性
- 对研究：基于 CAIL2018 等语料的判决/处罚预测模型落地为可用产品

## 2. 用户角色

| 角色 | 描述 | 核心诉求 |
|---|---|---|
| 普通用户 | 公众、法学师生、法律从业者 | 法律咨询、类案/法条检索、文书生成 |
| 智能体创作者 | 进阶用户 | 创建/编排自己的智能体与工作流 |
| 管理员 | 平台运营者 | 用户管理、内容审核、用量统计 |

## 4. 法律场景定制（项目重点）

### 4.1 通用法律智能体（六大内置）
法律咨询助手 / 判决预测 / 类案检索 / 法条解释 / 合同审查 / 文书起草（详见设计方案 §5）

### 4.2 赌博类行政案件重点场景（与模型组对齐）
| 场景 | 输入 | 输出 | 说明 |
|---|---|---|---|
| 处罚预测 | 案情事实（时间/地点/情节/金额等） | 结构化卡片：处罚种类（拘留/罚款）、幅度区间、依据法条（治安管理处罚法等）+ 置信度 | 对接微调模型（HTTP/模型节点） |
| 类案检索 | 案情描述 | 相似行政案例卡片（案号/法院/处罚结果/相似度） | 检索库以赌博类行政案例为主 |
| 处罚决定书起草 | 引导式收集要素 | 文书预览 + 导出 | 要素模板由法律组提供 |
| 情节认定辅助 | 证据材料描述 | 情节轻重分析（聚众/牟利/初犯等要素勾选卡） | 结构化卡片 |

**合规声明**：平台输出仅供研究/辅助参考，页面需显著提示"不构成法律意见"。

## 5. 非功能需求

- **性能**：首屏 < 2s；流式输出流畅无卡顿（批量渲染）；长会话（500+ 消息）滚动不降帧
- **安全**：Markdown 渲染防 XSS；上传类型/大小白名单；前端不做权限校验的唯一裁判（以后端为准）
- **兼容**：Chrome / Edge 最新两个大版本；桌面优先，对话页适配移动端
- **可用性**：错误有兜底提示；空状态有引导；断网/模型超时有明确反馈
