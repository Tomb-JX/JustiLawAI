## 2. 原训练数据规划（v0.5 系）与现实的对照

### 2.1 原设计三层骨架（`data-collection.md` v0.5 + `project-status.md` §4–6）

1. **产物清单**：行政案例金标 **≥500 件、目标省 ≥300**（G1.1）；省级裁量基准 1–2 省；
   CAIL 刑事子集 4,160（已入库）；裁判文书第三方采购 channel C（替代主键去重、脱敏后进训练）。
2. **银标→训练协议**：教师模型全量打银标；人工只校正随机抽样 ≥100 件 + 最不确定案例；
   **银标只用于训练，测试集只用金标**；划分按事件分组 + 时间外推 + 地域外推，MinHash≥0.8 配对归零。
3. **管道规范**：六层目录（raw→parsed→build→delivery→acceptance→labels/splits）、REGISTRY.csv 唯一记账、
   引擎自动验收、数据湖 T-L1..T-L5 渐进迁移。

### 2.2 现实改写了什么（按现行口径登记）

| 原规划 | 现状 | 依据 |
|---|---|---|
| 人工金标 ≥500 | **人工标注劳力为零是既定事实**（用户拍板）；金标概念替换为 model-adjudicated 标签 + 抽样人审；G0.3 采信裁定已立 | D-002/金标线解散；评审 §9 |
| 脱敏后进训练 | **D-003：主链路零掩码**，脱敏仅导出派生工具；内外双口径 | 协调规范修订 |
| 教师=单模型银标 | **A/B 双盲 + C 仲裁**（deepseek/小米双厂 + pro 裁决），B 线实现中 | 评审 F1–F4/R-01 |
| 目标省候选六省（山西上海为 0 的担忧） | 已反转：山西 391、上海 107；但重心漂移到云南/广西/河北——**目标省与原选省逻辑脱节，需要协调层重定目标省或接受三省集中** | 本实测 §1.2 |
| T-time ≥50、不予处罚单独达标 | T-time 表面 475、不予处罚 41+71=112：数量近达标，**质量口径（新法×叙述式×结果完整）未验证**，属发现层下阶段定向供给任务 | 本实测 §1.4 |

**训练目标两模型**（宏观既定）不变：提取模型（≈解析管线蒸馏，语料=parsed-2 全量）+ 裁量模型

labels 存量 203 accepted（v2 契约）+12 smoke12。
