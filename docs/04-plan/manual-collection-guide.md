# 人工采集指南：裁判文书网、信用中国与政府网站公示

> 版本 v0.1 · 2026-10-15 · 配套：[数据收集计划](./data-collection.md)（渠道 B/C/E）· [批量采集运维计划](./crawler-ops.md) · 采集脚本见 [`research/discretion/collect/`](../../research/discretion/collect/README.md)
>
> 用途：说明**不能或不该自动抓取**的来源怎么人工找、怎么检索、怎么入台账。本文结论来自 2026-10-15 的实测：搜索引擎检索、浏览器打开各平台，并在本机抓取样例页核对正文质量。

## 0. 结论先行：之前为什么找不到

| 之前的做法 | 问题 | 改为 |
|---|---|---|
| 去**省级司法厅**、北京各区找复议决定书 | 2024 年新《行政复议法》施行后，不服公安处罚的复议**集中由县级人民政府办理**，赌博复议案落在**县/区政府网站**，省级专栏几乎没有（实测 234 件 0 件赌博） | 用搜索引擎 `site:gov.cn` 直接定位**县/区政府**的复议决定书 |
| 去**信用中国**搜"赌博" | 只能按**主体名称/信用代码**查，每次查询都要验证码；涉及自然人的处罚多数只归集不公示，简易程序处罚不上报 | 放弃信用中国；改找**县政府网站的"行政执法公示/双随机一公开/执法结果信息"栏目**，那里直接挂着公安的《行政处罚决定书》 |
| 在裁判文书网漫无目的翻 | 不登录不能检索下载；行政文书总量只有 330 万，2021 年起公开量骤降 | 登录后用**高级检索 + 法律依据字段**精确定位，批量收藏后下载 |

**新的渠道优先级**（按"赌博密度 × 事实完整度 × 可获取性"排序）：

1. **县级政府网站上的公安行政处罚决定书**（渠道 E 的真正来源）——非复议来源，正好用来满足 T-admin"复议/诉讼 ≤50%"的硬约束，而且已有 2026 年新法案件（T-time）。
2. **县/区政府行政复议决定书**（渠道 B 的正确入口）——事实、处罚、说理三要素齐全，搜索结果首页 10 条里 9–10 条是赌博案。
3. **裁判文书网行政判决**（渠道 C）——需登录、纯人工，量中等，带法院说理。
4. **北大法宝 / 威科先行**——取决于学校账号（W1 必须问清楚）。
5. 人民法院案例库、12309 检察网——只作权威样例或刑事边界参考，不靠它们凑量。
6. ~~信用中国~~——不投入人力。

## 1. 主力方法：百度 `site:gov.cn` 定向发现（渠道 B + E）

### 1.1 原理

县、区政府网站分散在几千个域名下，逐站探查行不通；但搜索引擎已经把它们索引好了。用"文书类型词 + 赌博特征词 + 法条 + `site:gov.cn`"检索，结果几乎全是目标文书。找到一篇以后，再顺着页面的**面包屑/栏目**找到整个栏目，一个栏目往往有几十到几百篇同类文书。

### 1.2 实测检索式（2026-10-15 百度，首页命中情况）

| # | 检索式 | 首页结果 | 主要文书类型 |
|---|---|---|---|
| Q1 | `行政复议决定书 赌博 治安管理处罚法第七十条 site:gov.cn` | 10 条中约 9 条是赌博复议案（淇县、金东、卢氏、武义、上杭、花都×2、开化、温岭） | 复议决定书 |
| Q2 | `公安局行政处罚决定书 赌博 第七十条 site:gov.cn` | 魏县、定兴×2、博湖、陆良等，多为**原始处罚决定书全文** | 处罚决定书 |
| Q3 | `治安管理处罚法 第八十二条 赌博 行罚决字 2026 site:gov.cn` | 栖霞市公安局《2026 年第一季度执法结果信息》（表格，含第八十二条、拘留/罚款、文号）；北京市公安局 2026 版裁量基准 | 2026 新法案件 + 规范文件 |

**组合矩阵**：每次固定 `site:gov.cn`，再从下面三组各取一个词组合，逐个跑：

- 文书类型：`行政复议决定书` / `复决字` / `行政处罚决定书` / `行罚决字` / `执法结果信息` / `行政执法公示` / `双随机一公开`
- 赌博特征：`赌博` / `赌资` / `麻将` / `扑克` / `网络赌博` / `为赌博提供条件` / `抽头` / `不予处罚 赌博`（**专门找不予处罚样本，门禁 G3.2 要求单独达标**）
- 法条与年份：`第七十条`（2025 年及以前的行为）/ `第八十二条`（2026 年施行的新法）/ `2024` / `2025` / `2026`
- 目标省加限定：在检索式里加省名或市名，例如 `浙江`、`山西`；也可以把范围收窄到具体地级市域名，例如 `site:jh.gov.cn`

### 1.3 操作步骤（每人每天约 2 小时）

1. **检索**：用真实浏览器手动打开百度，逐条执行 §1.2 的检索式，每条翻 5–10 页。**不要写脚本批量请求百度**：会触发验证码，也违反"不绕过验证码"的纪律。
2. **记 URL**：把命中文书的标题和 URL 贴到 `urls.txt`，每行一条，格式为 `URL<Tab>标题<Tab>检索式编号`。只记标题或摘要里能看出是赌博的条目。
3. **顺藤摸瓜找栏目**：打开文书页，看面包屑（例如"首页 > 行政执法公示专栏"或"政府信息公开 / 法定主动公开内容 / 双随机一公开"），点进栏目列表：
   - 栏目里赌博文书 **≥20 篇** → 登记到 `sites.csv`（`kind` 填 `县政府-执法公示` 或 `县政府-复议`，状态填"探查中"），交给数据链路写适配器批量收割；
   - 不到 20 篇 → 只保留 `urls.txt` 里的单篇。
4. **入库**：`urls.txt` 交给数据链路。单篇 URL 按 §4 的 URL 导入流程抓取并登记台账；整个栏目走 `crawl_reconsider.py` 的新适配器。
5. **检索日志**：每条检索式记一行到检索日志（§4.3）。研究上要能复现"这批样本是怎么来的"，数据卡（G1.4）也要用。

### 1.5 质量与偏差提醒

- **脱敏程度不统一**：定兴用 `xx`，博湖、武义用 `某某`；个别页面可能露出身份证号片段或村名。所有页面入库前必须过 R6 扫描（数据收集计划 §4）。
- **执法结果表**（如栖霞季度表）只有结果、没有事实：可以用于结果分布统计和 T-time 的结果核对，**不能**当抽取器金标。
- **非复议来源很宝贵**：处罚决定书公示是 T-admin 里"非复议/诉讼"那一半的主要供给，统计时单独计数。
- **公开有地域偏差**：主动公示处罚决定书的县有限，数据卡里要写明来源县名单。

## 2. 裁判文书网（渠道 C，纯人工）

> 现状（2026-10-15 首页）：文书总量 1.69 亿，其中行政文书 330 万。检索、查看、下载都要**登录**（手机号注册）；不登录只能看首页统计。**禁止**任何脚本或自动登录批量下载，GitHub 上那些 selenium 爬虫项目一律不用。

### 2.1 检索步骤

1. 注册并登录（每人用自己的手机号，不共用账号）。
2. 打开**高级检索**，它有 17 个字段。推荐组合：
   - 案件类型：`行政案件`
   - 文书类型：`判决书`（裁定书大多是程序性的，事实少，第二轮再收）
   - 全文检索：`赌博`
   - 法律依据：`治安管理处罚法 第七十条`；另跑一轮 `第八十二条`，抓 2026 年案件
   - 裁判日期：按年份切成 2019–2026 共 8 段分别检索（单次结果太多时列表会截断）
   - 地域：先跑**目标省**，再跑全国
   - 案由：左侧分类树里选"行政管理范围 → 治安管理"相关案由（名称以页面实际为准）
3. 在列表页左侧用**分类引导树**看每年、每省的数量分布，**截图存档**，这是校准产量估计的依据。
4. 在列表页勾选文书 →"批量收藏"→ 收进案例包（每个检索式建一个包，包名就用检索式编号）。
5. 在"个人中心 → 我的收藏 → 案例包"里下载。
6. 把下载文件放进 `$JUSTILAW_DATA_DIR/inbox/`，运行：

```bash
python research/discretion/collect/import_manual.py --channel C --source-type 判决书 --ref "WS-Q1 行政/判决书/赌博/§70/2024"
```

### 2.2 注意

- 2021 年起行政文书公开量骤降约 80%，年份分布不能直接解读为案发量变化，数据卡里要注明。
- 同一案件可能有一审、二审两份文书：用"关联文书"功能确认，只取终审结果作标签，另一份记为同案（划分时同侧）。
- 诉讼和复议同受"T-admin ≤50%"约束。

## 4. 统一入库流程

### 4.1 文件命名

`<文号或标题>_<地区>.<扩展名>`，例如 `定兴公（天）行罚决字〔2024〕0325号_河北定兴.html`。不要用"下载(1).pdf"这类名字。

### 4.2 三种入口

| 来源形态 | 入口 | 现状 |
|---|---|---|
| 浏览器手动下载的文件（裁判文书网、法宝） | `$JUSTILAW_DATA_DIR/inbox/` → `import_manual.py` | 已有 |
| 搜索发现的单篇 URL（`urls.txt`） | **URL 导入脚本**：按 URL 抓取，经 `common.session()` 发请求，间隔 ≥1.5s，存原文并登记台账；`channel` 填 B 或 E，`notes` 写检索式编号 | **待数据链路实现**（建议名 `import_urls.py`，`collect/` 目录归数据链路） |
| 有规律的整个栏目 | `sites.csv` 登记，再给 `crawl_reconsider.py` 加适配器 | 已有框架 |

### 4.3 检索日志（建议新增 `research/discretion/collect/search-log.csv`，入库）

```
date,platform,query_id,query,filters,hits_reported,collected,by,notes
2026-10-15,baidu,Q1,行政复议决定书 赌博 治安管理处罚法第七十条 site:gov.cn,,首页10条,9,hhy,
```

## 5. 合规红线（人工采集同样适用）

- 不绕过登录、验证码、JS 盾；不批量自动请求搜索引擎；不共用平台账号。
- 只取已公开文书；商用库内容仅限校内科研，不二次传播。
- 原文只放在 `$JUSTILAW_DATA_DIR`，永不入库；仓库只放台账、检索日志和脚本。
- 发现未充分脱敏的页面照常存档，但必须先过 R6 扫描再进标注；**不要截图或转发到群聊**。
