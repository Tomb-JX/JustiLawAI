# S1 混合句与表格来源归因实验（B 评审分支，2026-10-18）

## 范围与结论

本次只作离线取证，没有修改生产链路、固定 final300 分母、S3 门槛或教师数据。固定 final300 的 26/299 硬错中，先前定位的 6 件“事实与定性同句”可以通过句内边界处理消除对应的 `facts_quality` 错误，但这只是单项检查的反事实，不等于完整 S3 通过。该问题的本质是 **S0 仅按句末标点建原子句，而 S1 只能给整句贴一个 zone**；增加“其行为构成”等短语正则只能当候选召回，不能作为事实边界的最终裁决。

表格问题则必须按来源层分开：有些原网页缺少刑期/金额/事实，任何下游步骤都无法恢复；有些原网页有表格行列，但 parsed-1 行切片夹带下一行，S0 又移除单元格分隔。后者应在源结构保留与表格过滤处处理。把两者合并成“S0 丢字段”会误导修复。

## 300 件之外的混合句实验

对 `D:\02_Dev\Data\justilaw-research\unified_raw\web\20261017-web-r3\records.jsonl` 排除 final300 所有 ID，且排除其 `-dN` 同源页面前缀，以降低同一网页近重复造成的泄漏。剩余 4701 条；其中 `form=叙述式-独立成篇` 且 `prefilter.release=true` 为 627 条。按“同一标点句内先有至少 15 字，后出现行为构成/违反/属于”等宽松触发语，在这 627 条中找到 5 个候选句；这只是候选检索数，不是总体混合句发生率。另把复议和混合形式纳入，共 3522 条，宽松触发得到 351 条、337 个页面前缀；其中大量为“认定事实清楚，证据确凿”之类评价语，不应切出事实。

人工核查的独立例子：

| ID | 观察 | 边界判断 |
| --- | --- | --- |
| W-000380 | “被查获时潘小慧持有赌资110元，潘小慧的行为已构成赌博。” | “潘小慧的行为”前存在可锚定事实前缀；是混合句。 |
| W-000377 | “……未办理《出版物经营许可证》……被……查获，该行为违反了……” | 事实与法律评价同句；但案件为出版物，不应仅因“六合彩”进入赌博金标。 |
| W-000073 | “……通过修改主板程序……转换为押分功能和退分奖励……其行为属于……” | 行为描述与法律归类同句；可切，但不是简短通用事实模板。 |
| W-000319 | “综上所述，违法行为……的行为构成赌博，根据……现决定……” | 句首已经是归纳/定性，不存在可单独标成事实的前缀；按关键词一律切会造假事实。 |
| W-002073-d5 | “覃某某的行为已经构成殴打他人，其行为属于情节较轻……” | 全句均为评价；按第二个触发语切仍不是事实。 |

另外，非 `release` 的 W-000331-d4/d5 有长篇“现查明……其行为已构成”句，证明同一问题不限于固定 300 的环江样本。复议文本 W-000570、W-000574 还出现事实、评价和后续事实在同句/同段内交替，说明单次关键词截断不足以泛化。

**建议的工程解法**：先保留原始句号及字符 offset，把“句内事实 span”作为 S1 的可选细粒度输出，要求 span 精确引用 `cleaned_text`，允许同句多 span、未标注部分为评价/证据/决定。正则仅提供高召回候选边界与低成本预警；由语义模型在上下文中决定事实起止，S3 验证 offset、原文逐字一致及评价词污染。不能把候选正则的命中本身写成金标。以独立页面前缀留出集检验：事实 span 精确度/召回、错误切分率、最终 S3 硬错率；尤其将“综上所述”类纯评价负例纳入。现有 5 条独立候选太少，不支持宣布某套正则具有可靠泛化率。

## 来源逐层核对

核对的是本地 `harvest/pages.jsonl` 指向的原始 HTML、`harvest/text/*.txt`、parsed-1 `text_full` 和 S0 `cleaned_text`。HTML 按 `<tr>/<td>` 解读，避免把去标签后串接的纯文本当作原网页字段结构。

| 页面/样本 | 原始 HTML 事实 | 后续层变化 | 定性 |
| --- | --- | --- | --- |
| W-000421（翁牛特旗） | 同一字段表有“罚款金额 3000”“处罚类别 行政拘留并处罚款”，但“处罚内容”为空；无拘留天数。 | harvest/parsed-1 均有这些字段；S0 保留 3000 和类别。 | 拘留天数是**原文缺失**，不能从类别推断。 |
| W-001186（禹会月报） | 每人表格给姓名、案由、处罚结果、文号；赌博行仅写“行政拘留、罚款”，无天数/金额及行为叙述。 | parsed-1 保留行内容；S0 拼连“第七十条行政拘留、罚款蚌公……”。 | 数值和叙述原文缺失；单元格边界在 S0 进一步受损。 |
| W-000522（弋江月报） | 表格列为文书编号、违法类别、处罚依据、处罚方式、时间、机关；“行政罚款/拘留”未附数值，也无行为事实。 | S0 把相邻行拼成连续串。 | **原文缺失**值/事实，兼有结构压平；不适合作叙述式金标原料。 |
| W-000412（镜湖公示） | “主要犯罪事实”有多人抓获及筹码；“行政处罚的执行方式和期限”单元格实际只列法律条款，没有处罚结果/金额。 | harvest/parsed-1/S0 均无相应处罚数值。 | 原网页字段名具有误导性，**原文缺失**结果，不是 S0 丢值。 |
| W-000798-d2（旌德表） | HTML 单行明确含王*彬、赌博、拘留 2 日、罚款 770 元。 | parsed-1 把下一行序号“3 赌博”带进本行；S0 又把法条、人名、日期、2日、770元、下一行号拼在一起。 | 数值未丢，但 **parsed-1 行切片越界 + S0 压平边界**；不能与原文缺失归一类。 |

建议为每条硬错记录字段级来源状态：`present_in_html / present_in_harvest / present_in_parsed1 / present_in_s0 / source_missing`，另记 `row_boundary_corrupt`、`cell_boundary_corrupt`。只对源中有值而下游丢失/错位者修解析；原文缺失者输出“未知”或排除相应训练任务，严禁按处罚类别补造具体数值。

## 对金标候选池的影响

若阶段目标是高精度 L5 教师原料，宜在进入 S1 前预声明“独立叙述式、单案、能定位行为事实及处分原句、关键字段有来源”的候选标准，将表格月报、统计/新闻、缺关键事实或结果的材料放入其他任务或弃权池。`form=叙述式-独立成篇 && prefilter.release=true` 只是粗筛：独立于 final300 来源页的 627 条中仍含 W-000377 这类主题假阳性，不能直接当金标。筛选后的通过率应与固定 final300 的 26/299 分别报告，不能通过事后改分母宣称原门槛已过。

下一步应先实现离线候选分类与句内 span 对照实验，逐例复查独立来源页；通过后才改 S1 schema/提示词及 S3 检查。表格结构问题优先定位 parsed-1 行边界与 S0 的换行处理，不宜在 S1 用正则补表格字段。
