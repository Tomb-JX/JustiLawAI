## 3. 公开网页链路的实现

### 3.1 流程

```
千帆"百度搜索"官方 API（不抓百度结果页）
  │ L1 plan.py 查询规划（模板 × 特征词 → 时间窗 → 地名；定向扩面用地级市全称）
  │ L2 search.py 执行（请求体哈希缓存、三道预算闸门、限速重试、顶到 50 条即拆分）
  ▼
L3 triage.py 分诊（以 API 摘录为主：文书类型、赌博三态、文号、发布单位）──► urls.tsv（只交"是"）
  │                                                                      urls_pending.tsv（"待定"备查）
  ├─ 逐站精扫（weekly.py：sw 模板 + 行内 site:<县级主域名>，顶格县转整栏）
  └─ L4 expand.py 栏目扩展（同形链接计分、严格形状保留类目号、CMS 指纹）──► columns.csv
  ▼
harvest.py 收割（单篇 + 整栏翻页自动识别 + 标题预筛 + 附件下载）──► raw/ text/ pages.jsonl manifest_web.csv
  ▼
ocr.py + winocr.ps1（复用本机 Windows 自带 OCR，Tesseract 兜底）──► ocr/
  ▼
parse.py 解析（五种页面形态切分 + 处罚结果结构化 + 全文复判赌博 + 范围判定）──► admin/web_cases.pre_deid.jsonl
  ▼
【未实现】脱敏 + R6 → 去重 + 区划 → 教师银标 → 人工校正 → 金标 → admin_cases.schema-x.jsonl 交引擎
```

## 7. 已知问题与风险

1. **"待定"噪声**（已修）：发现层"待定"<1% 是赌博，此前混进了交付和覆盖统计；现已只交付"是"，并作为回归测试。
2. **汇总页信息贫乏**：红塔 351 件只有"因赌博"三字，无金额无情节；在范围内的件数被它撑高。
3. **目标省与数据不匹配**：候选六省中山西、上海仍为 0，湖南、浙江很少；信息完整的案例集中在河北（定兴、辛集、清河、魏县、蠡县）和新疆（博湖、塔城）。**建议周会讨论把河北纳入目标省**，或接受目标省以复议、诉讼来源为主。
4. **扫描件**：定兴 2025 年起只发 JPG；OCR 已解决正文，但**落款日期被公章压住**，`decision_date` 普遍为空；新旧法以行为日期判断。
5. **解析薄弱点**：明写情节只抽到 4 件（"情节严重"3、"减轻"1），需要补规则；未识别法律版本 187 件、无行为日期 147 件；结果未解析 88 件（多为复议与汇总页）。
6. **未去重**：文号重复 17 组；跨来源（复议引用原处罚）也会重复。
7. **栏目质量**：可收割的 9 个栏目中 6 个是各部门混合，翁牛特旗估算 13,700 条只抓了 18 条（标题预筛后），其余待按需收；13 个 `mixed`、11 个 `js_shell` 栏目需人工看。
8. **台账**：`harvest/manifest_web.csv` 作为 `collect/manifest.csv` 的并列台账，待数据链路确认；数据链路台账仍有重复 id `B-098`。
9. **凭据与积分**：千帆 Key 曾明文出现，建议换新；法宝积分 9,700 分 2026-11-15 过期，需两条工作流商定分配。
10. **隐私**：原文与解析产物含半脱敏乃至真名、部分身份证号，**只存于仓库外**；交引擎前必须脱敏 + R6 扫描。
