## 2. 任务清单（分阶段，先免费后付费）

### P0 基础正确性（免费，先做）

1. 合并 `d254487`；跑现有单测，确认基线。
2. **坐标/契约修复**：按评审证实的问题修 F3 坐标混用（64/88 逐数复现）、字段/契约真传递、非法状态隔离。
3. **证据改句编号引用（D2）**：S1/elements 只输出句 ID；管线回填原文证据。S2 保留坐标投影、输入权限、本人归属、值与证据支持关系校验；旧 quote 定位只作历史兼容。**不要整体删除 S2 职责**（评审主文档已明确）。
4. **decision 边界**：区分 `decision` 整块与 `legal_basis / operative_outcome / execution / remedy_notice / signature` 细粒度引用；复议文书区分被引述的原处罚与本次复议主文；一句同时含事实与结论时先做可审计子句边界，拆不开标“混合/需复核”。
5. **最小留痕**：原响应、版本、费用、重试、断点；非法状态不得静默入库。

### P1 契约 v2 与免费重放（不付费）

6. **elements v2**：按语义依赖/值类型分组调用（不要一次 36 字段）；教师与学生共享**字段定义、归一化、最终证据校验**（引擎契约），但调用与答案独立；先在同一小切片对拍两端输出与失败原因，再决定公共函数边界。
7. **分歧路由**：按 contract error / reference error / presence conflict / value conflict / status conflict / evidence-window 分桶；先免费统计，再决定 C 仲裁，避免“分歧当成本”。
8. **免费 replay 套件**：从现有 1,600+ 条 outputs/labels 重建请求、对拍新逻辑；输出字段级错误/分歧分布。90% 契约改动用它验证，付费批只做终确认。

### P2 切片与首跑（G2.2a）

9. **冻结开发切片**：候选 A＝P1-r6＋P1b-r2 严格清洗后 **216 条 / 124 事件**（事实/答案隔离已按“决定语/处罚数额/定性结论/法条依据”剔除；偏样：富要素、江苏/广西/河北、全旧法、无 2026）。或按评审 §7 的 36 事件分层设计（网页叙述 12/公示 12/复议 6/法宝富要素 6）。出 manifest：ID、哈希、剔除原因、N、事件数、来源形态、偏样说明；**不承诺代表总体**。
