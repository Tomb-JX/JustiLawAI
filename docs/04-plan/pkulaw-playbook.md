## 1. 开工先侦察（半天，结果填 §6）

用账号登录 pkulaw.com 逐项确认：

1. **账号形态**：账号类型；**每日批量导出上限**（法宝通常限导出篇数/天）；并发限制
2. **四个库的收录试检**（直接决定渠道价值）：
   - 案例库：行政诉讼文书（案由"治安管理处罚"）覆盖省份与年份深度
   - **行政复议决定书**是否收录（试检：全文"赌博" ∧ 文号含"复"）
   - **行政处罚决定文书库**（执法公示聚合）：赌博类命中量——若收录良好，这是金标最直接来源
   - 法律法规库 + **地方法规库**：治安管理处罚法（2025/2012 两版全文）、公通字〔2005〕30 号、六省市赌博裁量基准原文——直接清掉引擎方案里全部【待核验】项
3. **导出格式**：Word/HTML/是否带法宝引证码与文号元数据；一次批量多少条
4. **API**：官方 **MCP（mcp.pkulaw.com）** 已接入（见 §7）

## 3. 导出与入库 SOP

1. 检索 → 排序（相关性/日期）→ 分批勾选（≤每日导出上限）
2. 官方批量导出 → 存 `D:/02_Dev/Data/justilaw-research/inbox/pkulaw/<检索式编号>-<日期>/`
3. 入库：`python research/discretion/collect/import_manual.py --channel C --region <省> --source-type <行政处罚决定书|复议决定书|判决书|规范文件> --ref "pkulaw R1 <日期>"`
4. 核对：manifest 行数 = inbox 文件数；抽查 sha256 与文号
5. 金标筛选沿用数据收集计划 §4 纳入标准——**重点保留"不予处罚/不构成违法"类**（G3.2 单独达标）

## 4. 体量与节奏（§6 侦察后校准）

- 需求倒推：金标 ≥500（赌博行政处罚为主）→ 法宝侧导出 ≥800 件原始文书（含筛选损耗）
- 人工批量导出估计 50–100 件/小时 → 全量约 2–3 个半天
- 每日导出上限若偏低：跨周分批，挂进 crawler-ops §4 的每周例行（同一天做，形成"周一适配 + 法宝导出"固定节拍）

## 5. 合规与治理

- 原文只存仓库外数据目录（`JUSTILAW_DATA_DIR`），仓库只留 manifest 元数据 + 哈希（治理同数据收集计划 §6）
- 数据卡记录：来源标注"北大法宝"、检索式、导出日期、数量；不记录个人账号信息
- 结题材料引用遵守法宝用户协议（"北大法宝" + 文号）；导出文本不得二次公开分发
- 选择偏差照旧入卡：法宝收录偏争议案件（复议/诉讼类尤甚），训练加权 + T-admin 构成上限照门禁 §7 执行

## 14. L4 Word 补救（2026-10-18）

**背景**：P2 批次 1,746 候选中 348 条 L4（有事实但结果未解析），原因是 web 抓取文本被截断 50%（"剩余50%未阅读"）。

**执行**：CDP 连接 9222 常驻 Chrome，逐条开详情页→点 `a:has-text("下载WORD")`→收 `.doc` 文件。单页复用不弹新标签，限速 2.5s/条，断点续传。

**结果**：
- 317/317 下载成功（0 失败），31 条因 worklist 无 URL 未下载
- `import_manual` → `docs` → `parsed1` 全链路：**314 L1 / 3 L4**（98.4%）
- 按 doc_no 匹配原始 L4：**313/316 转 L1（99.1%）**
- Word 全文中位 1,062 字（vs web 截断 432 字），增幅 2.5x
- 含金额 95%、处罚类型全（拘留 101/罚款 127/拘留并罚 86）

**教训**：
1. `click_download` 的通用 `"下载"` 正则会命中外层 DIV 而非内层 A 链接——法宝详情页的下载按钮在下拉菜单里，需直接定位 `a:has-text("下载WORD")`
2. 个人账户绑机构订阅后 `DownloadFullText` API 才返回文件（否则 `NoMenuRight`）
3. `ctx.new_page()` 每条弹新标签页，用户反感；改为单页 `page.goto()` 原地导航

**产物**：`parsed/pkulaw/20261018-P2-L4word`、`unified_raw/pkulaw/20261018-P2-L4word`、lake `batch-9d20391e4ae3b066`

**P4（正文级锚词验证）**：`赌博 曾因赌博`/`赌博 聚众`/`赌博 以赌博为业`/`赌博 抽头渔利` × 江苏/浙江/湖南。净新增 78 → **54 L1**（方法/赌资/聚众人名丰富）。要素落事实段实测：`曾因赌博` 29 条 L1 **命中 0**、聚众 6.7%、抽头 16.7%。

**根因坐实（关键教训）**：MCP `queryText` 是**词元 AND + 语义软匹配**。
- `曾因赌博` 被切成 `{曾,因,赌博}`，"曾"命中**姓氏"曾\*\*"**（曾**、曾xx），返回的是"姓曾的参赌者"而非有前科者——**前科密度买不到**。
- `周岁` 只出现在当事人元数据（非事实段）——**年龄密度买不到**。
- 参赌人数在正文是"人名罗列"（万xx伙同顾xx…7人），非数字串——**属 I-20 模型抽取，非采集可补**。

**结论**：年龄/前科/参赌人数的"密度"是**源文档稀缺 + 关键词检索词元碰撞**双重问题，无法靠加大检索量购买。能买的是**赌博干净的 L1 叙述件**（方法/赌资/现场赌资/抽头情节/聚众人名），这些对模型抽取是有效原料。

**已止损**：不再为年龄/前科密度投到期分（避免重演 I-21 盲目铺量）。密度要素改由 I-20 模型抽取在既有语料上解决。
