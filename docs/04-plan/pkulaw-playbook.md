## 1. 开工先侦察（半天，结果填 §6）

用账号登录 pkulaw.com 逐项确认：

1. **账号形态**：账号类型；**每日批量导出上限**（法宝通常限导出篇数/天）；并发限制
2. **四个库的收录试检**（直接决定渠道价值）：
   - 案例库：行政诉讼文书（案由"治安管理处罚"）覆盖省份与年份深度
   - **行政复议决定书**是否收录（试检：全文"赌博" ∧ 文号含"复"）
   - **行政处罚决定文书库**（执法公示聚合）：赌博类命中量——若收录良好，这是金标最直接来源
   - 法律法规库 + **地方法规库**：治安管理处罚法（2025/2012 两版全文）、公通字〔2005〕30 号、六省市赌博裁量基准原文——直接清掉引擎方案里全部【待核验】项
3. **导出格式**：Word/HTML/是否带法宝引证码与文号元数据；一次批量多少条
4. **API**：官方 **MCP（mcp.pkulaw.com）** 已接入（见 §7）

## 4. 体量与节奏（§6 侦察后校准）

- 需求倒推：金标 ≥500（赌博行政处罚为主）→ 法宝侧导出 ≥800 件原始文书（含筛选损耗）

- 每日导出上限若偏低：跨周分批，挂进 crawler-ops §4 的每周例行（同一天做，形成"周一适配 + 法宝导出"固定节拍）

## 5. 合规与治理

- 原文只存仓库外数据目录（`JUSTILAW_DATA_DIR`），仓库只留 manifest 元数据 + 哈希（治理同数据收集计划 §6）

- 结题材料引用遵守法宝用户协议（"北大法宝" + 文号）；导出文本不得二次公开分发
- 选择偏差照旧入卡：法宝收录偏争议案件（复议/诉讼类尤甚），训练加权 + T-admin 构成上限照门禁 §7 执行

## 14. L4 Word 补救（2026-10-18）

**背景**：P2 批次 1,746 候选中 348 条 L4（有事实但结果未解析），原因是 web 抓取文本被截断 50%（"剩余50%未阅读"）。

**执行**：CDP 连接 9222 常驻 Chrome，逐条开详情页→点 `a:has-text("下载WORD")`→收 `.doc` 文件。单页复用不弹新标签，限速 2.5s/条，断点续传。

**结果**：
- 317/317 下载成功（0 失败），31 条因 worklist 无 URL 未下载
- `import_manual` → `docs` → `parsed1` 全链路：**314 L1 / 3 L4**（98.4%）
- 按 doc_no 匹配原始 L4：**313/316 转 L1（99.1%）**
- Word 全文中位 1,062 字（vs web 截断 432 字），增幅 2.5x
- 含金额 95%、处罚类型全（拘留 101/罚款 127/拘留并罚 86）

**教训**：
1. `click_download` 的通用 `"下载"` 正则会命中外层 DIV 而非内层 A 链接——法宝详情页的下载按钮在下拉菜单里，需直接定位 `a:has-text("下载WORD")`
2. 个人账户绑机构订阅后 `DownloadFullText` API 才返回文件（否则 `NoMenuRight`）
3. `ctx.new_page()` 每条弹新标签页，用户反感；改为单页 `page.goto()` 原地导航

## 15. P3/P4 高信息密度检索——要素密度可购性证伪（2026-10-21）

1. **语义锚族跨域失效**：P6/P7 验证过的 onsite 语义锚（缴获赌资/现场查获赌资…）在浙江/江苏外全灭——河南 10 锚、江西/四川 6 锚、山东 personal 2 锚全部 0 召回（累计 16 次/1,200 分买到确定负结果）。语义检索按词组近邻匹配，各省公安文书措辞族不同，锚族不可外推。
2. **关键词模式跨域生效**：`searchType=keyword`（token-AND）在 8 个新省全部召回真赌博案，元数据即带定赌引证（治安法70/82条）+没收/并罚信号。`lawRegional` 归属核查：川/鄂/湘/赣/粤/冀/闽/皖无误；**河南省 keyword 出现归属错配（返桂/苏件），剔除**。
3. **年代切片深采**：keyword 单查上限 50 条/页、5 页；用年代片（2013-2020/2021-2026 + 加密 2013-15/16-18/19-20）把语义窗口漂移变成确定性多页召回，缓存可重放。
4. 引擎客户端调用与对话内直调同价同缓存（ledger 记账 data 线）；批量走 `harvest_mcp.py`（结果进缓存不进对话，上下文零污染）。

**波次账**：一波 64 cells/4,800 分（8省×4锚×2片）+ 二波 36/2,700（top6省×2锚×3加密片）+ 河南语义废波 10/750 + 试点 36/2,700（含语义锚族测试）＝今日约 110 次/8,250 分（余额核对以 ledger 为准，直调部分实时扣、客户端部分记账待核）。

**候选池与下载定案**：全缓存净新增 3,599 → 质量闸 `p9_select`（元数据打分：定赌引证+3/没收+2/并罚+2/文号+1/省级汇总-3；阈值≥3；机关簇上限 40）→ **3,266 件全量队列**（满分 787；湖南 690/河北 661/广东 487/湖北 433/江西 406…），负责人"全量下"指令下夜间后台跑完（断点续传+无窗口标签纪律已固化）。**待回填**：解析 L1 率与新省 onsite/personal 密度（相对全库基线 onsite 53.6%/personal 48.0%），入库批 `20261026-P9-r1`。

**给 P10+ 的口径**：新省扩产一律 keyword×年代切片起步，锚族用"赌资 拘留/收缴赌资/赌资 罚款/开设赌场"四件套；语义模式只在已验证省（江浙鲁）用；每省先 3 次试点看归属正确再放波。


## 21. 人工批量导出通道实测：压缩包直采 = 最高吞吐高质量线（2026-10-26）

负责人手动从法宝网页批量导出无锡决定书压缩包（`无锡50（7-12）.zip`，6 包×50 件，19:37–19:40 三分钟完成），实测质量**优于 CDP 逐条线**：

| 指标 | 无锡手工批（本批 300） | 对比 |
|---|---|---|
| 解析 L1 率 | **99.3%**（298/300，仅 2 件空决定段） | CDP P8 90.3%，历史 Word 线 99.1%（P2-L4word）同级 |
| onsite_stake 密度 | **59.1%** | 无锡存量基线 45.2%（+14pp）、全库 53.6% |
| personal_stake 密度 | **41.9%** | 无锡基线 33.0%（+9pp） |
| 付费墙残留 | 0 | Word 导出天然无 50% 墙 |
| 事件折算率 | 60%（179 事件/300 篇；交警队系列合罚文书同案多份） | 正常（P8 为 94%，本批检索面窄聚堆） |

**吞吐结论**：网页勾选批量导出 ZIP 一次 50 件、数分钟一批，无逐条限速问题、无付费墙截断，件件全文 Word——**批量下载的主力通道应转手工压缩包导出**；CDP 后台标签线降级为"补充/自动化兜底"（用于 M1 已排期队列和无人值守时段）。

**本批处置**：解包 300（包间 1 件重复自动改名落 `-dup`，引证码与已入库重叠 50 → 净新增 250）→ `import_manual --channel P` → docs → parsed1（批 `20261026-wuxi-manual-r1`）→ unified_raw → 落湖 **+300，lake 8,850**。机关：滨湖 83/直属 75/梁溪 75/经开区 43——全部真无锡分局，`直公（公交）`系直属分局公交队系列。原始压缩包在仓库 `测试下载资料库/`（已 gitignore，不入库）；建议后续手工包直接存 `$DATA/inbox/pkulaw/manual-zips/`。

**给后续批的口径**：手工压缩包按检索式命名存 $DATA，我按包编号续批解析（无锡 1–6 已在早前批次消化，7–12 即本批）；每包入库即报 L1/密度/重叠三数，连续两包密度低于存量基线则换检索式。
