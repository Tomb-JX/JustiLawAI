> 原则（用户原话的精神）：不延续旧有惯性；**会话为具体任务而设**，任务完成即归档或转下一目标；无当前任务的线归档案或降运维。

## 0. 顶层定调（方向，不是任务）

**项目只有一条主线：让裁量引擎输出第一份带质量数字的结果。** 此前三天的一切（采集、解析、脱敏、验收、协作体系）都是为它铺的路——路已铺完且超额，引擎本体一步没跑。下一阶段的全部意义是把这条主链跑通一次并量化每个环节：

**阶段二 = 闭环首跑**：原文基座格式关口（r6 验收，**非标注底料**）→ 蒸馏标签（S1×unified_raw 全量＋校验＋仲裁 → **parsed-2**，字段即标签）→ M1 行政首跑 → M4 最简基线 → 3 张输出卡片 → 一页"闭环质量报告"（每个环节的真实失败率）。

方向纪律（反惯性条款）：
1. **投机性采集冻结，已知缺口×时限资源例外**（2026-10-17 23:xx 用户指示修订原"数据冻结"条款）：法宝积分 1,625 分 11-15 全部过期，与已知供给缺口（要素稀疏/不予处罚扩面/2026 补充）重叠 → 按扩展计划并行采集（见 collab-log 同日"采集扩展计划"行），由法宝线转活跃执行；投机性采集（无缺口证据的）仍冻结；
2. **不打磨基建**：正则/脱敏/协作文档体系冻结，现有蓝本够用；
3. **平台冻结**：前端 M1–M6 已完成，P5 之前不碰；
4. **门禁是验收语言不是开发前置**（D-002 已解锁开发）；
5. **会话任务制**：每个目标一个负责人会话，完成即销项；无目标的会话不许存在。
