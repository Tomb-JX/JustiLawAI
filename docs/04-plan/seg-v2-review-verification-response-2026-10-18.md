## 2. 本线的两点独立观察（不照单全收评审的部分）

1. **confidence 自评并非无用信号**：final300 免费复算——模型自报 high 的 S3 error 率 **11/268 = 4.1%**，
   low **15/31 = 48.4%**（12 倍区分度）。同意评审"未校准不作门禁"，但**反对把它仅当兼容留档**：
   建议纳入复核队列排序与 §6 字段报告的旁路元数据（零成本、已验证）。待验证项：31 件 low 样本量下界，
   建议新版批内继续记账复测。
2. **W-000563 类"一侧 0 值"的根因待拆**：B=0 全未提及有两种可能（真·未提及 vs 包裹形状不合），
   修复 F1 后应能免费区分，不应现在归入"定义分歧榜"。

## 3. 处置：受影响批次与暂停决定

- **88 件落盘记录改称"88 件已配对落盘"，不再称"有效标签"**（full-record 已随本回应升 v1.1 勘误）。
  64 件输入污染标签**隔离留档、不追改**（评审 D6 裁定），不进入任何验收或训练；
  评审明令不得改 input 信封保旧标——本线遵守，要素标签**唯一恢复路径是新契约新批**。
- **要素续批（88→200）停止原计划**。验收门槛问题（现 6/88 结构合格）不是补量能解决的；
  下一付费批按评审 §7.2 序执行：先完成 §7.1 免费检查全列，再 12 件冒烟→36 件规约（总 cap 建议 ¥12，
  首段 ¥4，上界预登记 ≤252 次含重试），免费检查未清零不起跑。
- r7 维持不放行；26/299=8.7% 口径本线复核与官方一致；<5% 判定按评审口径：分母 299/300 均 ≤14 件。
