# 数据收集计划：赌博案件智能裁量引擎

> 版本 v0.1（待周会评审）· 2026-10-15 · 将[引擎方案 §6](../02-design/gambling-discretion-engine.md) 的数据方向细化为可执行计划
> 配套：[固定对照与阶段门禁](../05-research/sota-baselines-and-gates.md)（数据相关硬性要求 G0.1–G0.4、G1.1–G1.6、测试集治理 §7）· [文献与资料库](../05-research/reference-library.md)（数据集出处）

## 2. 前置决策（本周会确定，直接影响渠道执行）

1. **目标省份（1–2 个）**。选择标准：① 省级裁量基准原文可得且数额线量化清晰；② 复议决定书公开专栏质量好；③ 团队属地（公安合作可行性最高）。候选即引擎方案 §3.1 已检索到的六省市（山西/湖南/云南/安徽/浙江/上海，文号见该节，新法衔接均【待核验】）。**建议**：属地省优先，另选一个基准细化且公开数据充足的省作对照。
2. **学术数据库账号**：确认学校是否有北大法宝 / 威科先行账号（问图书馆）。这决定渠道 C 的效率。
3. **公安合作渠道**：请指导老师启动脱敏案卷对接；同步起草《数据使用协议》（要点见 §6.4）。

## 3. 渠道清单（按代表性排序）

### A. 公安机关脱敏案卷（代表性最好，渠道主力但周期不可控）

> **【2026-10-15 团队决定：暂时搁置】** 转为 B/C/D/E 渠道优先；恢复时从本节步骤继续。

- **内容**：完整案情 + 最终处罚结果 + 情节材料，覆盖"不予处罚"到顶格处罚全谱系。
- **步骤**：指导老师对接 → 签数据使用协议（§6.4）→ 按 §6.3 SOP 脱敏后交付 → 模型组登记入 manifest。
- **目标量**：目标省 ≥300 件；其中 2026 年行为案件优先（直接支撑 T-time ≥50，这是其他渠道短期内给不了的）。
- **定位**：尽力争取，但**不作为关键路径**——量估计按 0 处理，方案不因它翻车。

### B. 行政复议决定书（各省市司法厅/局公开专栏）

- **内容**：复议决定通常载明事实认定、原处罚决定、复议结论——事实+处罚+说理三要素齐全，是行政侧最好的公开来源。
- **操作**：目标省 + 周边省市司法厅（局）网站"行政复议决定书公开"专栏；检索式：`赌博`、`治安管理处罚法第七十条`、`第八十二条`；逐件登记 manifest。
- **目标量**：全国范围采集 300–600 件【估计，W1 试采集校准】。
- **注意**：**选择偏差**——进入复议的案偏争议、偏重罚。应对：数据卡如实记录；训练加权；T-admin 内复议/诉讼合计 ≤50%（门禁 §7 硬约束）。
- **自动化实测（2026-10-15）**：采集管线全通（`research/discretion/collect/crawl_reconsider.py`，已适配浙江司法厅 jpaas 接口，58 条脱敏 PDF 全量入库台账）；**但该专栏 0 件赌博案**（以信息公开/建设用地类为主）——产量依赖多省市专栏适配，这是渠道 B 达到 300–600 件目标的关键路径。单省专栏对赌博案覆盖率低的风险已列入 §8。

### C. 行政诉讼裁判文书（北大法宝/威科 > 裁判文书网）

- **内容**：案由"治安管理处罚""行政处罚"，不服赌博处罚或复议决定的行政判决；法院审查意见是额外的说理数据。
- **操作**：商用库按案由 + 法条（治安管理处罚法 §70/§82，刑法 §303）+ 全文关键词 `赌博` 检索导出；遵守账号协议（仅校内科研用途）。无账号则退回裁判文书网手动检索（效率低，仅兜底）。
- **目标量**：200–500 件【估计，W1 试采集校准】。
- **注意**：与渠道 B 同受 ≤50% 构成约束；平台下载的文书保持原文原样，不二次传播。

### D. 公开刑事数据集（模型组自助，无外部依赖）

- **CAIL2018**：下载后按锚点 A2 协议过滤——exercise 与 final 子集，去死刑/无期/零刑期，去多罪名多法条，保留赌博罪与开设赌场罪**单罪名**案件；10 个刑期区间沿用 PLJP 仓库 `data/output/meta` 定义。产出：T-crim + 抽取器预训练语料。
- **LeCaRDv2**：官方仓库下载（800 查询 / 5.5 万候选），P4 前到位即可，仅测通用检索栈。

### E. 公开处罚决定与执法公示（补充来源，撑 T-admin 构成）

- **内容**：信用中国"双公示"、各地公安局执法公示与典型案例中的赌博处罚。
- **定位**：事实通常简略，主要价值是**非复议/诉讼来源的处罚结果**——T-admin 要求复议/诉讼 ≤50%，若渠道 A 落空，靠 E 多省市采集补足非复议部分。
- **目标量**：100–300 件【估计】。

### F. 合成数据（严格限位）

- **生成**：从金标要素向量出发，LLM 改写/生成案情表述变体。
- **硬约束**：只用于抽取器鲁棒性训练；**绝不作为类案、绝不作为裁量标签、绝不进入任何测试集**（引擎方案 §6 原文约束）。

## 4. 处理流水线（每条数据的标准路径）

```
采集 → 来源登记(manifest) → 资格筛选 → 脱敏 → 去重/泄漏检查 → 预标注(教师模型) → 人工校正 → 金标
```

- **manifest 登记字段**（`research/discretion/collect/manifest.csv`，入库；与论文库 manifest 同风格）：`id, source_type(A/B/C/D/E/F), source_url_or_文号, region, behavior_date, decision_date, law_version, sha256, harvest_date, harvest_by, status(待筛选/纳入/排除+原因)`。金标每条记录可回溯到 manifest id。
- **纳入标准**：① 赌博相关（治安：参与赌博/为赌博提供条件，含**不予处罚与不构成违法**——G3.2 要求该类单独达标，严禁只收处罚了的样本；刑事：刑法 §303）；② 事实描述足以支撑要素抽取；③ 处罚结果明确；④ 行政案件辖区可定位到省级。
- **排除标准**：事实过于简略、跨省无法定位、时间不明、MinHash 近重复、脱敏不通过。
- **脱敏 SOP**（入库与封存前置条件）：姓名→编号；删身份证号、住址、电话、车牌；出生年月→年龄段（对齐本体字段）；具体日期→年月粒度（时间效力判断够用）；文号→哈希短码（保留查重能力）。处理前 R6 扫描（证件号/手机号正则 + NER）一遍，封存前再扫一遍。

## 5. 标注体系

- **工具**：Label Studio 自托管（导入/导出 JSON，对齐 `schema.py` 的本体结构）。
- **流程**：教师模型（= B1，P0 在 G0.5 确定）预标注 → 法律组逐条校正 → 金标。关键设计：**人工只做校正不做冷标注**，把单件工作量从 40–60 分钟压到 20–40 分钟。
- **质控**：≥20% 双人标注，分类字段 Cohen's κ ≥ 0.80、数值字段完全一致率 ≥ 95%（G0.3/G1.2）；分歧仲裁；cleanlab 疑似错误全复核，标签错误率 ≤ 3%。标注指南版本化，修订须记录。
- **工作量估算**：500 件 × 20–40 分钟 ≈ 170–330 人时 → 2–3 名标注人 × 3–4 周（W2–W4）。人手不足时按"目标省 300 件优先"分批。
- **B-H 专项**（G1.6）：2 名法律组成员对 ≥60 件**只看案情、看不到实际处罚**，独立给出定性/档次/处罚；由保管人分发脱敏输入，不触碰封存答案。

## 6. 数据治理与封存

1. **存放**：原始件与脱敏件均存仓库外的受控目录（保管人 + 组长两人可知），`research/data/` 整体加入 `.gitignore`；仓库只保留 manifest、脚本与哈希登记。金标数据哈希写进数据卡（G1.4）。
2. **封存**（门禁 §7）：T-admin / T-time / T-crim 由**测试集保管人**一人持有；文件 SHA-256 登记到门禁文档 §7 末尾；只能经 `research/eval/run_gate.py` 访问并自动记 `access-log.csv`；查看预算每门禁每候选 2 次、T-admin 全项目 ≤10 次。
3. **划分协议**：按事件分组（同一案件多名违法行为人同侧）；时间外推（2025 训练 / 2026 测试）与地域外推各留测试集；所有预处理只在训练集拟合；训练–测试 MinHash Jaccard ≥ 0.8 的配对必须为 0（R7）。
4. **合作数据协议要点**（供指导老师）：用途限定本项目研究；仅交付脱敏数据；原始数据不复制、不扩散、不公开；结题后按约定归还或销毁；符合《个人信息保护法》。
5. **数据卡**（G1.4，按 Datasheets for Datasets）：来源构成、采集时间窗、选择偏差说明（复议偏置必写）、脱敏方式、划分方法、各来源数量表。

## 8. 风险与预案

| 风险 | 触发信号 | 预案 |
|---|---|---|
| 公安合作落空或周期长 | W2 末无实质进展 | 主干转 B+C+E；T-admin 非复议部分靠 E 多省采集补足；仍不满足 ≤50% 构成 → 偏离日志登记调整构成比例（需指导老师批准） |
| T-time ≥50 件 P1 内难达标 | 试采集未见 2026 年行为案件 | 合作数据优先（2026 新案）；或申请将该子门禁移至 P3 评审时点并登记偏离日志——2026 年案件公开存在天然滞后，属可预见偏差 |
| B/C 公开量不足 | W1 试采集 < 预期半数 | 扩大采集省份（他省数据作分层/迁移材料）；目标省 ≥300 的硬线只能靠 A/E 补，提前向指导老师升级求助 |
| 复议/诉讼选择偏差 | — | 数据卡如实记录；T-admin 构成 ≤50%；训练加权；不得单独作评测集 |
| 隐私泄漏事故 | R6 扫描命中 | 立即停用该批次→溯源→脱敏返工→向指导老师报告；入库前+封存前双次扫描 |
| 标注进度滞后 | W3 末金标 <200 | 预标注提示词优化降负；目标省 300 件优先分批交付；周会跟踪趋势 |
| 商用库协议风险 | — | 仅用学校正版账号、仅校内科研用途、不批量转售/传播原文 |
