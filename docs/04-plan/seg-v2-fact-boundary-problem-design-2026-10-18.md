# 事实边界问题：定位、目标与修复设计（2026-10-18）

## 结论及阶段目标

这不是单一的“模型漏选子句”问题。六件付费试点的 6/6 S3 pass 与 1/6 旧 oracle ID 完全一致同时成立，原因有三层：旧 oracle 把标题和独立时间都当事实；S3 的 `facts_quality` 主要检查定性污染，不检验事实覆盖；`run_elements.build_inputs` 仍按整句 zones 生成 `facts_text`，没有消费 `fact_clause_ids`。当前子句试点只改了校验视图，尚未改到项目真正要交付给要素/引擎的输入。因此不得把 S3 改善解释为教师输入改善，也不能先扩付费批。

本阶段主目的应是让**本人行为事实及其必要上下文**从原文可追溯地进入后续要素判断，同时排除法律定性和处罚结论。句内边界是这个目的的一个内部表示，ID 完全一致不是最终业务指标。S0 负责保真和来源行边界；S1 负责语义角色；S2 负责原文定位；S3 负责契约、污染及必要信息覆盖；要素输入投影负责只把已批准的事实与上下文送到引擎。不要让 S3 的 pass 代替人工参考答案。

## 工程问题拆解

1. **目标/标签语义混合**：现有 `fact_clause_ids` 只有“选/不选”，混合了行为、日期、标题、证据、投案自首、处罚定性。应先定义 `behavior_core`、`context_time_place`、`other_case_fact`、`heading`、`legal_conclusion`、`decision`、`evidence`；输出可先保持少量角色，参考标注必须逐角色明确。
2. **候选切分不保证语义原子性**：`fact_spans._CLAUSE` 只按标点切。W-000333 的账号尾号与下一日期共处一候选，无法用单个 ID 同时满足保留时间与排除尾号。S0 首先核原 HTML、parsed-1 与 cleaned_text：若来源边界已存在而被压平，修 S0；若原文确实粘连，则在 S1 候选生成时添加可追溯的数字/日期边界，不修改原文字符。任何自动切分只提候选，不自动认定事实。
3. **校验只有精度方向**：S3 检查定性句残留、空区间及过短等，删掉标题甚至删掉时间仍易 pass。需要在参考集上同时衡量行为核心召回、上下文召回、法律结论泄漏，并检查本人/行为谓词/场景的覆盖。无参考集时只能给出高风险提示，不能宣称完整性合格。
4. **消费者未接入**：`run_elements.build_inputs` 从句级 zones 投影原文，不读取 `fact_clause_ids`。要先定义新的 `fact_view` 版本及兼容策略，再让要素输入与 replay 都从同一个投影函数产生。否则 S3 精修与下游实际文本两套口径，会持续出现“检查通过、输入仍污染”。
5. **风险件与原料件混淆**：表格跨行、原文缺数值、OCR/脱敏粘连需分别记录 `source_missing`、`parser_bleed`、`cleaning_boundary`、`semantic_boundary`。只对最后一类评价语义模型；原料问题走 S0 修复或候选过滤，不能用模型补造。

## 推荐接口与处理顺序

保留现有 `zones` 作为全文覆盖结构，不让它承担精细事实边界。新增版本化 `fact_view`，每条引用记录原文半开坐标、句 ID、候选 ID、角色、来源（模型选择/确定性连接/人工复核）及源哈希；角色只描述引用用途，不改变原文。第一步由 S0 输出原文与清洗映射并做表格/粘连质量标志。第二步按原文可追溯候选切分；模型负责语义角色选择，日期解析器只规范化已锚定的时间文本，不能凭日期形状认定它是行为时间。第三步从候选 ID 编译 clean→orig 片段，校验不重叠、逐字相等、主体与行为角色一致。第四步由同一个投影函数生成 S3 审计文本和要素 `facts_text`，并冻结 view hash。无法把行为核心与结论分开的候选标 `ambiguous`，进入人工复核或暂不作为教师输入。

先采用“行为核心 + 必要时地上下文”的两层事实视图：`behavior_core` 必须有原文行为陈述；`context_time_place` 仅在与该行为有可解释的相邻/同句关系时接入；标题、法律定性、处罚决定不进入。投案自首等情节作为独立 `other_case_fact`，由要素契约决定是否消费，不能与赌博行为混成同一正例。该职责划分比把所有可疑文字交给一个二值 ID 列表更可审计。

## 免费验证与后续试点门槛

先把六件旧 oracle 重新裁成角色参考，并补同源页外的正反例：纯定性句应无 `behavior_core`；时间与行为分离、标题与行为分离、含脱敏账号/日期粘连、表格跨行及源缺数值分别至少覆盖。参考样本需双人裁决分歧，保存 source hash、可接受的边界区间及必要上下文，避免对无害标点差异做机械 exact-match。随后免费回放全部固定 final300：逐件比较旧/新 S3 硬错、行为核心覆盖、法律结论泄漏、要素输入文本变化；特别核对原本的 25 个错误及新增污染。再在同源页外盲样评价核心召回、结论泄漏率、上下文召回及 `ambiguous` 比例，按“可进入教师输入的件数/原料 eligible 件数”报告，而非只报 S3 pass。

在接口、参考集和下游投影联通前，不追加付费调用。后续新付费批必须冻结样本、请求、价格、预算和停止阈值；若盲样行为核心漏失、定性泄漏或投影不一致，则停止扩量并回到免费分析。固定 final300 的可比 25/299 基线保留；不得用过滤后的候选分母代替它。
