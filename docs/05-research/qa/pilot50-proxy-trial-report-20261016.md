## 2. 方法与运行事实

- **标注员 A**：GLM-5.3（max，独立上下文 ×10 分片）标 45 条；chunk-09 的 5 条因 bigmodel 提供商通道故障经三次换源改由 **DeepSeek-v4-pro** 完成（45+5 混合，逐片归属已记录）。
- **标注员 B**：DeepSeek-Flash（max，×10 分片）标 50 条。
- 两位标注员互不可见，使用同一协议 v1.1（含冒烟共识澄清 11 条）。
- **仲裁**：67 处分歧（36 条案卷）全部落定——GLM-5.3-Flash 裁 17 条（缓存决定生效）；其余 19 条因提供商落盘通道反复故障，由金标线操作员按同一协议与逐字证据规则代裁（`arbitration/decisions/part-90.jsonl`，逐条附理由可审计）；DeepSeek-v4-pro 对其中 17 条的裁决在同故障中丢失，未参与生效结果。合并用 `merge_arbitration.py`（修复了 B 采纳未实际拷贝的 bug 后重跑），另对 6 处开口金额 max=null 按 G-12 数量级上界做确定性修复。终版 `arbitrated.jsonl` 校验 0 错误、证据命中 100%。
- **提供商通道事实**（供后续调度）：阿里百炼 qwen3.8-max 账户欠费（Arrearage）；bigmodel GLM 三种账户形态（individual / highspeed-card / Flash）在本轮均出现持续 unknown/network_error，但同账户本会话主通道正常；DeepSeek 通道全程稳定（12/12 分片）。
- 成本：双标阶段约 440 万 token（20 个标注代理）；法宝 MCP 消耗约 175 分（余额 6,250）。

## 3. 系统性分歧（67 处，占 1800 个联合字段判断的 3.7%）

| 字段 | 分歧数 | 根因 |
|---|---|---|
| `intent.profit_purpose` | 14 | "仅凭金额大小=推断"无阈值；B 对大额（3.5 万/6 万）推断 true，A 保守未提及 |
| `conduct.times` | 9 | 单场当场查获是否记 1 无规则（A 多记 1，B 多未提及） |
| `person.pregnant_or_nursing` | 9 | 男性可否由性别推 false：双方各自内部都不一致 |
| `conduct.duration_days` | 7 | 起止年月折算无口径（取月首相减 vs 月×30） |
| `persons.participant_count` | 5 | "共 N 人"（与点名下界冲突）、"伙同他人"（无点名）无规则 |
| 金额四字段 | 11 | "X 元以上"开口上界（A 记 max=null、B 按数量级）；"赌资共计"归 personal 还是 cumulative |
| 其余 | 21 | venue 细类（野外/台球厅）、method 缺牌九等枚举、first_offense 与"违法前科栏"关系 |

## 4. 历史指南提议（G-12…G-19；仅 v0.2 候选明确采纳的规则可用于下一轮）

- **G-12 开口金额（旧提议，未采纳）**：曾建议人为设数量级上界；复核认为原文不支持该上界。当前 schema 又不允许 max=null，故转入异常表并交 schema 负责人决定表示法。
- **G-13 单场次数**：当场查获/单次叙述 → `conduct.times`=1（推断）；"多次"无数字 → 未提及。
- **G-14 男性孕产**：原文明写性别"男" → `pregnant_or_nursing`=false（明确）；仅结构化性别无正文 → 未提及。
- **G-15 时长折算（旧提议，未采纳）**：按月×30 会在起止日不明时引入虚构精度；当前改为记录原文粒度并留待异常复核。
- **G-16 人数三型**："等人"→点名下界；"共 N 人"→N（推断）；"伙同他人"无点名 → 未提及。
- **G-17 营利目的（旧阈值提议，未采纳）**：金额 ≥ 5000 元不能单独证明营利目的；按指南 v0.2 候选仅以明确目的或本人获利机制赋值，待法律组签核。
- **G-18 method 枚举**：增设 牌九、炸金花、跑得快；网络平台内玩法 → "网络赌博"优先于具体玩法。
- **G-19 归属字段**：抽头/头钱/桌费 → commission；"非法获利"未写机制 → illegal_gain；"赌资共计/涉及金额"未写"个人" → personal_stake（推断）。
