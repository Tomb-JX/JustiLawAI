## G2.3a M1 学生原型诊断

在 validation 64 条上，以 `input.views` 构造案情，只运行现有本地 `qwen3.5:9b` **推理原型**；输出只落外置 `engine/development`，没有写回 parsed-2、没有生成训练参考。64/64 请求成功且原始 JSON 可解析；原始 390 个候选 item，最终保留 324 个有值字段、363 条证据。后处理丢弃 47 个“取值无法解析”、11 个“证据在原文中找不到”；最终保留证据均为允许视图内的逐字片段（363/363）。这个 363/363 是**过滤后证据定位率**，不能冒充原始候选证据命中率；更不能证明值语义正确。单件耗时中位约 5.30 秒，总推理时长约 378 秒、输出 15,230 tokens。

**字段准确率：暂缺**（没有独立 `reference_elements`）；类别、金额、营利目的等均不报正确率。本地模型的此次用途仅是学生端诊断，不作为标签生成来源。
