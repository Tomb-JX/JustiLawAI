# 外部对照：类似裁量模型的公开研究与实务系统（2026-10-26 网络检索版）

> 目的：以最新现状文档（[engine-line-status-2026-10-26](./engine-line-status-2026-10-26.md) v1.1、[data-pipeline-status](../04-plan/data-pipeline-status.md) v2.2）为内部基线，用网络检索核实的公开研究/实务系统做外部对照，回答宏观问题：**核心模型能力训练（M1 抽取、M4 裁量）在同类工作里是怎么做的、我们偏在哪、该修什么**。
> 方法：三路并行检索（裁判预测主线 / 罚金与行政裁量实务 / 低资源法律标注与要素抽取），全部数字取自论文原文、官方 README 或政府文件原文，逐条附来源；检索不到的明确标"未检得"。内部沉淀见 [reference-library.md](./reference-library.md)（本篇是它的**实测数字补充与空白点核实**，不重复其条目）。
> 项目内部基线（10-26 晚）：金标 0；统一文本银标训练包 train 1,740 条/1,348 事件（valid 三套 357、test 40 封存）；M4 实测"纯文本最强、要素/融合无增益"，数值回归打不赢中位数基线；binding v1.1 仅影子；双模型标注 union-κ 0.691。

## 0. 一页结论

1. **任务空白点属实，项目定位站得住**：公开学术里"行政处罚裁量预测"几乎空白——主流中文 LJP 数据集（CAIL2018 267 万件）只做法条/罪名/刑期三项，**不含罚金**（原文核实）；可核实的罚款金额回归仅韩国（TRACS-LLM，3.7 万件）与马来西亚（ANFIS）两例；中国大陆行政处罚数据驱动研究仅检得一篇（Electronics 2022）。实务侧（国办发〔2022〕27号、浙江 405 号令、SAMR 裁量基准+自算器、环境部裁量计算器）**全部是"分档规则表 + 情节修正"的规则引擎，无机器学习**。我们的"神经符号混合"与实务范式同构、与学术空白互补。
2. **"金标 0 是总单点"被外部证据加固，但金标门槛比想象低**：Lawyer-LLaMA 实测 **850 条专家手写数据胜过 42,000 条模型蒸馏数据**；智海-录问的罪名/刑期预测指令各仅 ~0.5k 条；DisTAPT 用 **40–60 条主动挑选的标注**逼近 4,371/44,249 条全监督的 F1（0.65 vs 0.70 / 0.93 vs 0.95）。→ §7.1"先产 100–200 件金标"的路线有直接文献背书，且金标应花在**主动学习挑出的高价值样本**（binding unresolved 集正是这种样本池）。
3. **M4"要素无增益"与文献不矛盾，是密度/对齐问题**：LawBench 实测给 LLM 喂法条原文做刑期预测**常常反而降分**；GLARE（2025）却证明判例/要素增强把困难罪名从 57.0 提到 75.7、agent 方案 88.6 超过微调 BERT 83.3（10 万级训练子集）。要素增益取决于要素质量与注入方式——我们 512 条银标扩量后 Macro-F1 反降，同属"低质量结构化信息无增益"区间。
4. **数值预测的正确目标是"档位+偏差"，不是绝对金额回归**：实务罚款额由规则表决定（SAMR：分档 100/250/400 万 ± 每情节 10%；环境部公式 X=N+(M−N)×[(A−1)/4]×(1+B)），历史决定书的金额本质是"规则档位+裁量偏差"；学术侧 SMS（内部文献库 A 级）按"起点+情节增量×调节系数、截断法定区间"建模，小数据胜过 CatBoost（91.34 vs 87.36）。→ M4 数值头应改为**在 M2 法定空间/档位内学偏差**，与两阶段试验（拘留 MAE 降）方向一致。
5. **M1 的终局形态是微调判别式抽取器，LLM 只当银标生成器**：GerPS-Compare（2024，法律细粒度要素）实测微调判别模型 macro F1 0.61–0.65 **碾压**生成式 LLM（宽匹配 0.45、严格 span 匹配 0.11）；阿拉伯语判决预测 3,752 条 LoRA 微调全面超过 zero/one-shot prompting。数百条金标即可启动 LoRA。
6. **金额/日期要素最难、"未提及"须显式建模，都是跨领域一致结论**：DCFEE 实测 NUM（数额）F1 最低 56.38、END（日期）pattern 法 46.86；GerPS "Data field" F1 仅 0.07–0.18；ContractNLI 把 NotMentioned 设为正式第三类标签并承认模型"fail badly"。→ 我们金额绑定 F1 0.60、"未提及占大头"不是管线特别差，是任务固有难度；但同时意味着**这类字段不过人工闸就不能发布**（与现行裁定一致）。
7. **我们仍缺而外部已验证有效的两件东西**：① 判例库/检索增强（GLARE 消融显示判例推理是最大增益源；SAILER/KELLER 已在内部文献库，LeCaRDv2 数据已就位，M5 未启动）；② 足量封存测试集（LEEC 另留 1,400 份非公开测试；我们 test 仅 40 条，且验证 357 条 underpowered——3pp 差异需约 1,300）。
8. **模型自主抽取的问题分层（v1.2 修正）**：结构层实测质量高（引文坐标零错、schema 通过 ~100%）；语义错误集中在人-金额归属、NIL 校准、数值归一化残点——但引擎四轮实验（E1–E3/消融/弃判，§6.1a）与融合注入对照已证明：**这些是要素产线质量闸（L5 放行）的瓶颈，不是 M4 判别的瓶颈**；M4 无增益的主因是源端信号密度（facts 中位 72.5 字），注入绑定答案集亦不提升。schema 硬缺口 2 个实测局部（赌博机 3/203、前科日期 4/203），随升版处理。归属线唯一解锁点是 24 事件边盲标（包已备好、10-21 暂缓）——见 §7 人工需求清单。

## 3. 方法路线对照：M1 与 M4 该怎么训

### 3.1 M1（要素抽取）

- **证据**：GerPS-Compare（arXiv 2412.02427）——法律细粒度要素上微调 XLM-R macro F1 0.6455、BiLSTM-CRF 0.6058，生成式 LLM 仅 0.4488（宽）/0.1067（严格 span）；Fine-grained Contract NER（arXiv 2401.13545）同样结论"LLM prompt 做 NER 不及有监督基线"。
- **对照项目**：M1 现状是零样本+受限解码原型（CAIL 诊断，丢弃率 14.5%），行政数据未正式跑、未微调。LoRA 蒸馏在计划中但被"金标 0"卡住。
- **裁定**：路线正确、卡点唯一。外部证据支持"**LLM 当银标生成器 + 数百条金标 LoRA 微调判别式抽取器**"的两段式；金额/日期/NIL 三类字段按 DCFEE 经验单独设验收线（数值类 F1 预期天花板 ~0.6，别按 0.9 立军令状）。

### 3.2 M4（裁量模型）

- **证据链**：① 纯文本强于低质量结构化特征——LawBench"喂法条反降分"、我们 168/357 条实测一致；② 结构先验+小数据——SMS 按量刑流程建模（起点+增量×系数、截断法定区间）小数据胜 CatBoost；③ 检索/判例增强是最大增益源——GLARE 消融困难罪名 57.0→75.7、整体 88.6 超微调 BERT；④ 实务金额=规则档位+修正——SAMR ±10% 分档、环境部公式。
- **对照项目**：M4 现为 LR/Ridge 文本基线（未放行），四专家未实现；两阶段试验（先分类后回归）拘留 MAE 三组均降、罚款 MAE 恶化；事件分组/近邻试验外部无收益。
- **裁定（按依赖排序）**：
  1. **把数值目标重构为"M2 档位分类 + 档内偏差"**：M2 已能算法定空间（94.3%），罚款/拘留天数改为"落在哪一档 + 档内偏移方向"，比裸回归符合实务生成机制，也回避了中位数基线打不赢的问题（档位分类的基线是多数档，更容易赢）。
  2. **专家 A（分层贝叶斯）优先**（与 §7.2 一致），其结构先验直接套 SMS 的"起点+增量×系数+截断"；专家 C（类案近邻）等 M5 案例库立项后才有原料——GLARE 证明判例增强收益最大，**案例库（SQLite+FTS5）立项优先级应上调**。
  3. **停止单纯扩银标量**：1,740 包实测收益递减（旧验证 Macro-F1 下降）；下一份算力/人力预算投给"金标核验层"（DCFEE 式 200 条抽查）而不是再产 500 条银标。
  4. **少数类靠结构不靠采样**：不予处罚 50/警告 2/不构成 1 的极端不均衡，与 CAIL2018 top10 罪名占 79% 同构；主流做法是分层/按类建模（Charge-Based Prison Term Prediction，内部文献库 B 级）+ PDP-Bench 警示（"不予处罚"边界单独设门禁）。

### 3.3 评测与统计功效

- 外部惯例：LEEC 1,400 份非公开测试；A2 锚点（CAIL）5×5 折已实操。我们 357 valid 检验 3pp 需 ~1,300 的缺口不变——**一切 M4 对比结论继续只作方向性**，发布判定必须等封存测试集扩容。
- COMPAS 教训入红线：按人群分层的假阳性率差异应进入 R 系列检查项（现有 R1–R8 若未含公平性分层，建议周会讨论补充——本条仅为建议，未改门禁文件）。

## 6. 补充核查（用户追问）：模型自主抽取的真实问题与 36 字段缺口对照

### 6.1 模型自主抽取：分层定性（全部实测数字）

**结构层（机器可校验的部分）质量高，不是问题所在**：P3-P7 批 655→631 合格（96.3%）；next-30 批 239 条引文**零坐标错**、19/20 过硬闸；expansion-454 引文逐字一致 99.93%；909 批 909/909 过 schema。"能不能产、格式对不对"已解决。

**语义层错误集中在四处**：

1. **人-金额归属（最重）**：binding P1 批 399 个 scene-level money 节点中 254 个（64%）实为"他人姓名+赌资"的个人金额被误标 shared；H3 复核 bound 语义错个人赌资 1/4、现场总额 1/7；v1.1 自动绑定单字段放行率仅 4–11%，171 条中 141 条（82%）至少一字段需人工。10-25 金额闭环的错误分析已定性：**候选供给不是瓶颈**（test 正例 19/19、17/17 能在允许视图找到同值候选），错误全在字段角色、人物-事件关系、NIL 弃判。
2. **NIL/未提及校准**：双模型背对背 union-κ 0.691（门槛 0.80 未过）、数值一致率 86.4%；金丝雀 30 条中 4 条金额拒收、9 条本人归属待判——近半数卡点即"这个金额是谁的/算不算有"。
3. **数值语义归一化**：开口金额 `{100,null}` 与确数 100 的区分、"X至Y元"区间、"每局100元起"（硬闸误拒，open）；per_bet 与 personal_stake 的口径混淆。
4. **源端缺失（不是模型的错）**：facts 中位仅 72.5 字；出生日期源头打码（web 批 46.5% 有出生日期字样且多为打码格式）、前科提及率 11.1%、营利目的词 4.3%。36 字段中"未提及"占大头是数据事实，任何抽取器都无法恢复原文没有的信息。

**关于文书长度（修正 §1 类比）**：行政处罚决定书短不是劣势也不是我们的难点——S1 分区 994/1000 成功、证据定位已跑通。但"短"带来一个反向难度结构：**单句承载多人多金额**（如"现场查获张某某赌资12000元、李某赌资3000元"），facts 越短，人-金额对齐错误的相对代价越大；且每篇可支撑 36 字段判断的信号极少。自主抽取的真实难点 = 短文本多人多金额归属 + 大面积缺失判定，不是长文理解。

### 6.1a 归属瓶颈的准确定位（v1.2 按引擎四轮实验修正）

上一版把"归属"写成 M4 判别的主瓶颈，**过重，已被引擎侧实验证伪**，修正如下：

- **注入无效已实验证实**：融合 pilot 把要素（含绑定产物）注入 M4，168 条验证上融合 106 ≈ 文本 107、要素仅 86——绑定/要素答案集注入不提升判别。
- **归属线四轮实验（`notes/2026-10-21-*`）已把问题拆干净**：E1 证明候选供给已解决（证据内金额覆盖 147/147，外部识别器无增量）；E2 证明角色/主体规则不可部署（个人赌资仅 12–19/53 一致，年龄主体约束系统性误杀 8/8）；目标距离特征消融仅改变 valid 2 条（同一双目标事件）；弃判实验证明排序分差**不能回答"字段该不该有值"**。结论：规则路线到头，下一步要可学习关系打分——**而它被边金标盲标（24 事件包已备好、10-21 决定暂缓）卡住**。
- **因此归属/NIL/归一化是"要素产线质量闸（L5 放行）"的瓶颈，不是 M4 整体判别的瓶颈**。M4 判别无增益的主因是**源端信号密度**（facts 中位 72.5 字，裁量过程/执行口径不写入决定书）；数值归一化主链已修复（E-05 三函数补全、c3343ec 短语级硬闸、v1.1 结构化 {min,max}），"X元起"误拒为单点 open 工单，局部。
- **schema 两个硬缺口经实测确认为局部**：203 参照集 method=赌博机仅 3/203（1.5%）、last_prior_penalty_date 明确仅 4/203（2%）——影响面是完备性问题，不显著影响整体判别；随下次 SCHEMA_VERSION 升版处理即可，优先级下调。

### 6.2 36 字段 schema 与规范需求方（M0 YAML）对照的缺口

对照方法：把 `norms/provinces/320000.yaml`（江苏，档次最全）、`130000.yaml`（河北）、`national/interpretations.yaml`（公通字〔2007〕1号、法释〔2005〕3号涉刑门槛）引用的每个情节，逐一映射到 `schema.py` 的 36 字段。

**硬缺口（规范档次直接引用、schema 无字段）**：

| 缺口 | 规范依据 | 影响 |
|---|---|---|
| **赌博机台数**（含"操作基本单元"计数规则、**校园周边200米**加重） | 江苏第三/四节按 2台/5台/10台 直接分档；"中小学校园周边200米内设置赌博机"列第三档 | method=MACHINE 只有方式没有台数，赌博机类案件在江苏无法定档 |
| **刑事前科/刑罚执行完毕日期** | 江苏从重"刑事处罚执行完毕三年内，或缓刑假释期间又实施"；从重"聚众/开设赌场共犯中未被追究刑事责任的" | circumstances 只有治安处罚日期（last_prior_penalty_date）；first_offense bool 按公通字定义把"曾受刑罚"排除出初次，但"三年内"档算不出来 |

**枚举级缺口（不加字段，扩枚举即可）**：

| 缺口 | 规范依据 |
|---|---|
| Role 枚举缺"发牌坐庄、兑换筹码、接送参赌人员" | 江苏第三档"为赌场接送参赌人员、望风看场、发牌坐庄、兑换筹码的"——现有枚举只覆盖望风（LOOKOUT）、放贷（LENDER） |

**指南级需明确（字段已有、语义要补）**：

1. "检举揭发他人赌博经查证属实"应写入 meritorious 字段指南（江苏从轻第 5 项）。
2. "在赌博场所从事一般服务、领取固定工资、不抽成"是**不以为赌博提供条件论处**的出罪依据（江苏第六条第三项）——现只能靠 role+commission 未提及间接表达，建议评估加 bool 或扩 Role 枚举 STAFF；同理"只收正常场所服务费"的出罪（第六条第二项）与 intent.profit_purpose 指南已部分覆盖。
3. 网络/赌博机赌资按"点数×每点金额"认定（江苏第五条）——points 原始值应以 evidence 引文保留换算依据，指南需写明，不必加字段。

**派生值（正确地不作为抽取字段）**：人均赌资 = onsite_stake_total ÷ participant_count，`interpretations.yaml` calculation_rules（per_capita_stake，公通字/法释依据）已建，江苏 band `personal_or_per_capita` 引用——保持派生，勿入 36 字段。

**涉刑提示门槛核对（无缺口）**：法释〔2005〕3号聚众赌博四门槛 commission≥5000 / cumulative_stake≥50000 / cumulative_participants≥20 / abroad_organized_count≥10 字段全部在 schema。

**流程约束**：data-spec §8.3 规定数据线不得自行增删字段，任何增删须引擎 `SCHEMA_VERSION` 升版并同步契约——上表是**周会/引擎线的决策输入**，两个硬缺口（赌博机台数、刑事前科）建议随下次 schema 升版一并处理；扩 Role 枚举同属升版范围。

## 7. 执行路径（v1.3 重写：零预算、无法律组的现实约束）

> **v1.2 的"人工需求清单"已撤回**，其前提被用户逐条证伪：① 项目为学生项目，**不存在法律组，无专家标注预算**；② 关系边人工盲标已被实测否定——**负责人本人试标的效果不如现有模型标注链路**，且该线非主力；③ 法律效力核查有**已接入的北大法宝 MCP** 可做绝对严格的逐字查证（国家层 22 项即此法核出，playbook §14–16；省级裁量基准文书可检索、全文可取，10-26 实测通路：江苏库命中 28 部，含徐州市公安局赌博量罚指导意见全文）；④ L5 放行积压中属误判/工程缺陷的部分已检测修复（127 条误判纠正、标题闸关闭、旧 127 回放通过），剩余不构成主线阻塞。
> 外部文献结论相应重读：Lawyer-LLaMA"850 条专家数据"、DisTAPT"40–60 条挑选标注"、DCFEE"200 条人工核验"的前提都是有付费专家或受训标注员——本项目没有，**这些数字不构成我们的行动项**，只说明"高质量小数据有效"，而我们的高质量小数据只能来自机器可核验的客观信号（结果标签）与 MCP 权威文本。

在此约束下，真正可执行且零资金的路径（与 engine-line-status §7 v1.3 一致）：

1. **门禁口径修订**（唯一需要周会/指导老师拍板）：G0.1/G0.2"法律组签字"→"法宝 MCP 逐字查证留痕 + 指导老师确认"；G1.1"人工金标 ≥500"→"经核验结果标签 ≥500"（客观解析+双通道校验）；G1.6 B-H →"历史机关决定基线"替代或登记暂缓。按 sota §0 规则 2 附证据登记偏离日志。
2. **评测锚扩容**：lake 9,327 分层抽样，test 40→300+；结果标签双通道解析一致性校验，人工只看分歧件（预计几十件、学生可做）。
3. **源端增量**：手工 ZIP 通道放量（零成本、已实证单日 +777 L1、定向检索可富集密度）——M4 主瓶颈是 facts 信号稀疏（中位 72.5 字），这是唯一能动天花板的杠杆。
4. **两省基准 MCP 核验 → M2 档位接入 → M4"档位+档内偏差"**：河北/江苏 YAML 待核验项逐字查证留痕（学生可执行）；M4 数值头改档位分类+偏差（SMS 同构，专家 A 优先）。
5. **要素/L5/binding 维护态**：盲标包归档；不再投入放行复核与付费扩产；冻结产物保留（binding 留作 M5 检索键）。
6. **功效模拟**（纯机器）：选省决策前置。
