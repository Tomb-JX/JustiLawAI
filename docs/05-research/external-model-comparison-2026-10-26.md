# 外部对照：类似裁量模型的公开研究与实务系统（2026-10-26 网络检索版）

> 目的：以最新现状文档（[engine-line-status-2026-10-26](./engine-line-status-2026-10-26.md) v1.1、[data-pipeline-status](../04-plan/data-pipeline-status.md) v2.2）为内部基线，用网络检索核实的公开研究/实务系统做外部对照，回答宏观问题：**核心模型能力训练（M1 抽取、M4 裁量）在同类工作里是怎么做的、我们偏在哪、该修什么**。
> 方法：三路并行检索（裁判预测主线 / 罚金与行政裁量实务 / 低资源法律标注与要素抽取），全部数字取自论文原文、官方 README 或政府文件原文，逐条附来源；检索不到的明确标"未检得"。内部沉淀见 [reference-library.md](./reference-library.md)（本篇是它的**实测数字补充与空白点核实**，不重复其条目）。
> 项目内部基线（10-26 晚）：金标 0；统一文本银标训练包 train 1,740 条/1,348 事件（valid 三套 357、test 40 封存）；M4 实测"纯文本最强、要素/融合无增益"，数值回归打不赢中位数基线；binding v1.1 仅影子；双模型标注 union-κ 0.691。

## 0. 一页结论

1. **任务空白点属实，项目定位站得住**：公开学术里"行政处罚裁量预测"几乎空白——主流中文 LJP 数据集（CAIL2018 267 万件）只做法条/罪名/刑期三项，**不含罚金**（原文核实）；可核实的罚款金额回归仅韩国（TRACS-LLM，3.7 万件）与马来西亚（ANFIS）两例；中国大陆行政处罚数据驱动研究仅检得一篇（Electronics 2022）。实务侧（国办发〔2022〕27号、浙江 405 号令、SAMR 裁量基准+自算器、环境部裁量计算器）**全部是"分档规则表 + 情节修正"的规则引擎，无机器学习**。我们的"神经符号混合"与实务范式同构、与学术空白互补。
2. **"金标 0 是总单点"被外部证据加固，但金标门槛比想象低**：Lawyer-LLaMA 实测 **850 条专家手写数据胜过 42,000 条模型蒸馏数据**；智海-录问的罪名/刑期预测指令各仅 ~0.5k 条；DisTAPT 用 **40–60 条主动挑选的标注**逼近 4,371/44,249 条全监督的 F1（0.65 vs 0.70 / 0.93 vs 0.95）。→ §7.1"先产 100–200 件金标"的路线有直接文献背书，且金标应花在**主动学习挑出的高价值样本**（binding unresolved 集正是这种样本池）。
3. **M4"要素无增益"与文献不矛盾，是密度/对齐问题**：LawBench 实测给 LLM 喂法条原文做刑期预测**常常反而降分**；GLARE（2025）却证明判例/要素增强把困难罪名从 57.0 提到 75.7、agent 方案 88.6 超过微调 BERT 83.3（10 万级训练子集）。要素增益取决于要素质量与注入方式——我们 512 条银标扩量后 Macro-F1 反降，同属"低质量结构化信息无增益"区间。
4. **数值预测的正确目标是"档位+偏差"，不是绝对金额回归**：实务罚款额由规则表决定（SAMR：分档 100/250/400 万 ± 每情节 10%；环境部公式 X=N+(M−N)×[(A−1)/4]×(1+B)），历史决定书的金额本质是"规则档位+裁量偏差"；学术侧 SMS（内部文献库 A 级）按"起点+情节增量×调节系数、截断法定区间"建模，小数据胜过 CatBoost（91.34 vs 87.36）。→ M4 数值头应改为**在 M2 法定空间/档位内学偏差**，与两阶段试验（拘留 MAE 降）方向一致。
5. **M1 的终局形态是微调判别式抽取器，LLM 只当银标生成器**：GerPS-Compare（2024，法律细粒度要素）实测微调判别模型 macro F1 0.61–0.65 **碾压**生成式 LLM（宽匹配 0.45、严格 span 匹配 0.11）；阿拉伯语判决预测 3,752 条 LoRA 微调全面超过 zero/one-shot prompting。数百条金标即可启动 LoRA。
6. **金额/日期要素最难、"未提及"须显式建模，都是跨领域一致结论**：DCFEE 实测 NUM（数额）F1 最低 56.38、END（日期）pattern 法 46.86；GerPS "Data field" F1 仅 0.07–0.18；ContractNLI 把 NotMentioned 设为正式第三类标签并承认模型"fail badly"。→ 我们金额绑定 F1 0.60、"未提及占大头"不是管线特别差，是任务固有难度；但同时意味着**这类字段不过人工闸就不能发布**（与现行裁定一致）。
7. **我们仍缺而外部已验证有效的两件东西**：① 判例库/检索增强（GLARE 消融显示判例推理是最大增益源；SAILER/KELLER 已在内部文献库，LeCaRDv2 数据已就位，M5 未启动）；② 足量封存测试集（LEEC 另留 1,400 份非公开测试；我们 test 仅 40 条，且验证 357 条 underpowered——3pp 差异需约 1,300）。

**裁定**：不存在与"赌博行政处罚裁量引擎"同任务的公开数据集或预训练资产可迁移。项目的差异化定位（规则档位打底 + 学习偏差 + 要素证据链）与实务范式和学术 SOTA（SMS/RLJP/GLARE 的"结构先验+检索增强"方向）一致，**不是路线错误，而是无先例任务的正常代价：一切监督信号必须自建**。

## 3. 方法路线对照：M1 与 M4 该怎么训

### 3.1 M1（要素抽取）

- **证据**：GerPS-Compare（arXiv 2412.02427）——法律细粒度要素上微调 XLM-R macro F1 0.6455、BiLSTM-CRF 0.6058，生成式 LLM 仅 0.4488（宽）/0.1067（严格 span）；Fine-grained Contract NER（arXiv 2401.13545）同样结论"LLM prompt 做 NER 不及有监督基线"。
- **对照项目**：M1 现状是零样本+受限解码原型（CAIL 诊断，丢弃率 14.5%），行政数据未正式跑、未微调。LoRA 蒸馏在计划中但被"金标 0"卡住。
- **裁定**：路线正确、卡点唯一。外部证据支持"**LLM 当银标生成器 + 数百条金标 LoRA 微调判别式抽取器**"的两段式；金额/日期/NIL 三类字段按 DCFEE 经验单独设验收线（数值类 F1 预期天花板 ~0.6，别按 0.9 立军令状）。

### 3.2 M4（裁量模型）

- **证据链**：① 纯文本强于低质量结构化特征——LawBench"喂法条反降分"、我们 168/357 条实测一致；② 结构先验+小数据——SMS 按量刑流程建模（起点+增量×系数、截断法定区间）小数据胜 CatBoost；③ 检索/判例增强是最大增益源——GLARE 消融困难罪名 57.0→75.7、整体 88.6 超微调 BERT；④ 实务金额=规则档位+修正——SAMR ±10% 分档、环境部公式。
- **对照项目**：M4 现为 LR/Ridge 文本基线（未放行），四专家未实现；两阶段试验（先分类后回归）拘留 MAE 三组均降、罚款 MAE 恶化；事件分组/近邻试验外部无收益。
- **裁定（按依赖排序）**：
  1. **把数值目标重构为"M2 档位分类 + 档内偏差"**：M2 已能算法定空间（94.3%），罚款/拘留天数改为"落在哪一档 + 档内偏移方向"，比裸回归符合实务生成机制，也回避了中位数基线打不赢的问题（档位分类的基线是多数档，更容易赢）。
  2. **专家 A（分层贝叶斯）优先**（与 §7.2 一致），其结构先验直接套 SMS 的"起点+增量×系数+截断"；专家 C（类案近邻）等 M5 案例库立项后才有原料——GLARE 证明判例增强收益最大，**案例库（SQLite+FTS5）立项优先级应上调**。
  3. **停止单纯扩银标量**：1,740 包实测收益递减（旧验证 Macro-F1 下降）；下一份算力/人力预算投给"金标核验层"（DCFEE 式 200 条抽查）而不是再产 500 条银标。
  4. **少数类靠结构不靠采样**：不予处罚 50/警告 2/不构成 1 的极端不均衡，与 CAIL2018 top10 罪名占 79% 同构；主流做法是分层/按类建模（Charge-Based Prison Term Prediction，内部文献库 B 级）+ PDP-Bench 警示（"不予处罚"边界单独设门禁）。

### 3.3 评测与统计功效

- 外部惯例：LEEC 1,400 份非公开测试；A2 锚点（CAIL）5×5 折已实操。我们 357 valid 检验 3pp 需 ~1,300 的缺口不变——**一切 M4 对比结论继续只作方向性**，发布判定必须等封存测试集扩容。
- COMPAS 教训入红线：按人群分层的假阳性率差异应进入 R 系列检查项（现有 R1–R8 若未含公平性分层，建议周会讨论补充——本条仅为建议，未改门禁文件）。
