# M4 机关分层先验：接口与首轮对照（2026-10-27）

## 接口落地

本轮使用冻结 v5 `train.jsonl` 2,681 条，不改记录或处罚标签，不抽取新要素，不读取封存 test40。训练包只有 `facts_text`、`event_id` 等精简字段；决定日期不能从 `event_id` 推断。因此以稳定 S1 ID 对接三个已有 `unified_raw_refresh` 记录文件，只取作出决定机关和**决定日期**，另存 `context.jsonl`。来源文件、训练包和 manifest 的 SHA-256 写入报告。湖表只用于“机关名称完全相同且地域代码不冲突”的地区映射；机关名称明确以省名开头时可补省份。不做模糊机关匹配。

接口为 `AgencyPrior(rows, contexts, train_indices).predict(context, max_level)`：结果包含四类历史处罚分布、相对全局分布、使用层级、有效事件数、历史截止日期与**决定日期分组**。同事件多人按人数分摊，单事件历史总权重至多为 1；只计入训练折中**早于本案决定日期**、不属于本案事件且处于同一决定日期分组的结果。2026 年界线只是统计上的时期切分，**不等于认定本案实际适用新法**。省→市→机关逐级以 20 个事件的固定等效权重向父级收缩。缺日期或该时期无历史时返回 unavailable；无该机关历史时回退市、省或全局。省级建议和 M2 法定空间未参与这个统计模型。

文本头沿用同折的字符 TF-IDF、类别平衡 LR、C=3。固定融合：`p_fused ∝ p_text × (p_prior / p_global)^0.5`；先验不可用时原样返回文本预测。这是分类实验，**尚未完成概率校准，不可当已校准的部署分布**。

## 输入审计

三个既有 S1 来源按 ID 覆盖 2,681/2,681 条；作出决定机关有值 2,653 条，精确决定日期 2,638 条。可可靠映射到省份 594 条、市级代码 523 条；其余地区保持未知。源记录与训练包的 `event_id` 有 270 条不一致，因此不把 `event_id` 当机关或决定日期的正式来源。这个上下文补充是现有元数据对接，未重洗冻结样本。

## 固定对照结果

| 轴 | 文本 Macro-F1 / 准确率 | 文本＋省先验 | 文本＋逐级机关先验 | 机关历史可用 |
|---|---:|---:|---:|---:|
| 未见事件，2,681 条 | 0.5124 / 0.5972 | 0.5120 / 0.5949 | **0.5197 / 0.5983** | 1,271 |
| 未见机关，2,681 条 | 0.3711 / 0.5062 | 0.3728 / 0.5073 | 0.3724 / 0.5069 | 0（只能回退） |
| 2024 年起的时间外推，439 条 / 281 事件 | **0.2963 / 0.3986** | 0.2838 / 0.3872 | 0.2650 / 0.3713 | 233 |

未见事件轴的机关融合让“罚款↔拘留”互错从 480 降到 472，拘留召回从 0.5214 到 0.5338；全量准确率只多 3/2,681。按事件整体重采样，准确率增量 +0.0011 的 95% 区间约为 [-0.0049, +0.0078]。时间外推中，准确率少 12/439，Macro-F1 下降 0.0313；准确率增量区间约为 [-0.0641, +0.0068]。不能宣称已验证稳定增益。

本轮未见机关轴改用源记录的**真实机关字段**分组；此前 `m4_type_loss_cv.py` 以 `event_id` 第一段分组，二者的冷启动分数不能直接相减解释为模型退步。时间轴只用 2024 年之前的记录训练文本模型，先验进一步按每案决定日期截断；2026 年及以后决定日期组的 75 条因无更早同组训练历史，先验弃判并保留文本结果。

## 判定

**首轮固定参数的“文本×机关频率”融合不放行。**普通事件折有微弱正向，但真正的后续年份表现明显变差；机关历史不是可直接乘进概率的稳定修正项。不能为了挽救这一版数字在同一冻结训练集上反复调指数或收缩强度。下一个算法问题应是检验机关差异是否随时间、案件构成和法律时期变化，以及文本概率是否需要先校准；这些属于新的预注册模型对照，不是重启要素标注。本轮先保留独立机关先验接口与负结果报告，不接正式 M4。
