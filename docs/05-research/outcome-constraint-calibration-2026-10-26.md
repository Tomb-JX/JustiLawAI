# 方案 C 最小验证：处罚结果→赌资区间反推校准（2026-10-26，development-only）

> 目的：验证[外部对照 §8.1-C](./external-model-comparison-2026-10-26.md)"结果标签通过规范层反推稀疏要素"路线是否可行。方法：在**文书写明赌资金额**的记录上，假装金额不可见、只按处罚结果和省基准档位反推金额区间，然后对答案（区间覆盖率）。
> 脚本 `research/eval/outcome_constraint_calibration.py`（v3，纯 stdlib+E-05 cn_to_number）；产物 `$DATA/engine/development/outcome-constraint-calib-20261026/{report.json, weak_stake_intervals.jsonl, misses.jsonl}`；数据 = `m4-facts-silver-1740-v3-clean`（mechanism=base）+ lake region join。
> 档位依据：河北/江苏两省 YAML（**verification=待核验**，故本实验仅开发校准，不作发布依据）；升档触发词（河北网络/公共场所等→第三档）命中的 24 条单列不进分母；边界含本数/不含本数双口径并报。

## 0. 结论（一段话）

**反推不是"一律可靠"，而是强烈的档位依赖：第三档（拘留并处罚款 ⇒ 赌资 ≥1000 元）覆盖率河北 22/22=100%、江苏 12/14=86%——可当高置信弱标签直接用；第一/二档覆盖率仅 33%–62%——只能当带实测违例率的软先验，不能当硬约束。** 全体严格口径覆盖率 63.7%（100/157，含本数口径；不含本数 59.2%），低于预设的 75% 可用线，因此"处罚⇒金额区间"的确定性反推**整体不成立**、但**分档成立**。违例本身高度结构化（低于档仍处罚 38 条、高于档却轻判 19 条、无减轻/前科文本线索），即**实践与成文基准的系统性偏离率 ≈36%——这恰是 M4"档位+偏差"建模要学的目标信号**，与外部 Electronics 2022（处罚偏离检测）同向印证。

## 2. 对方案 C 的裁定

1. **C 可行，但必须分档实现**："处罚档位⇒金额区间"在第三档上是近似确定的规则（可直接产高置信弱标签/硬约束）；在第一、二档上是带 ~40–67% 违例率的噪声观测（只能做贝叶斯软先验，违例率用本实验数字）。
2. **违例不是失败，是第二个学习目标**：below/above 偏离与文本可见情节（投案/供认/前科）无关（本批 miss 全部 mitigate_hint=False），说明偏离信息在 facts 之外（说理段、案卷、执行口径）——档位模型学"基准档位"，偏差头学"实践偏离"，两者分开，正与 forensic §4.3 的"档位+偏差"重编码合流。
3. **归属歧义再次收费**：99 条多人案跳过（占严格分母的 63%）——binding 维护态的代价在 C 路线上定量显形；若未来要扩大 C 的覆盖面，这是唯一值得重启归属线的理由。
4. **待核验前提**：两省 YAML 未核验（G0.1 新口径下待 MCP 查证留痕）、"以上含本数"边界假设未获法律确认（含本数口径实测更优，+4.5pp，可作边界解释的经验证据）；江苏 tier1 的 below 偏多可能与 special/other 类别误判（网络赌博识别漏）混杂，扩大应用前需逐档人工抽 10 条复核。

## 3. 下一步（小步、可证伪）

1. 把 tier3 反推规则接入档位重编码实验（引擎线"档位重编码 E4"工单的输入）：第三档记录直接得"赌资≥1000"约束特征，零标注成本。
2. tier1/2 软先验进专家 A（分层贝叶斯）：区间约束作为 censored likelihood，违例率 36% 作为噪声参数先验。
3. 两省 YAML 完成 MCP 核验后重跑本脚本（阈值若修正，覆盖率会变）；扩省份需先录该省基准。
4. 99 条多人歧义记录单独立册——若 C 路线证明增益，再评估是否值得重启归属线（这是唯一理由，不为要素而要素）。
