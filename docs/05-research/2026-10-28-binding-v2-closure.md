# binding-v2 停止与归档（2026-10-28）

**决定**：binding-v2（金额归属算法线）停止，不再投入算力、费用和放行复核。负责人 10-28 确认。

## 为什么停

1. **核心模型不消费绑定**：
   - M4 的输入只有 `facts_text`，监督来自决定段的结果字段；
   - 注入绑定值没有增益，连“完美绑定”的上限实验也是零增益。这个结论在 v3-clean 净化包上复测成立，三组均为 94/42/86；
   - 引擎线现状 v1.3（10-26）已把 binding/要素线转为维护态。见 main 的 `docs/05-research/engine-line-status-2026-10-26.md` §6.3、§7.5，以及 `m4-forensic-diagnosis-2026-10-26.md` E8。
2. **给 L5 提供候选和约束，这个定位站不住**：
   - **数值准确、证据可追溯**：靠确定性候选抽取、E-05 归一化和坐标硬闸已经做到，不需要训练出来的绑定器。实测：金额字段只有 2 处分歧（17 条记录对比 203 条参照）；候选供给 19/19、17/17；L5 next-30 引文 0 坐标错。
   - **人—金额归属**：绑定器比标注大模型弱。单个模型在 dev 上 84–86%、H3 上 70–78%；两个模型一致时约 95%。v1 在 H3 上只填了 4 条；配对模型按人—金额对算约 80%；配对解码的精度只有 61%。用更弱的判断去约束更强的判断，做硬约束会删掉对的答案，做交叉检查又误报太多。
3. **两条自实现路线都没过事先写定的止损线**：
   - 弱监督标签模型：见 [2026-10-28-record-level-comparison.md](2026-10-28-record-level-comparison.md)；
   - 配对模型 ＋ 结构约束：见 [2026-10-28-blind-spot-decomposition-and-pair-decoder.md](2026-10-28-blind-spot-decomposition-and-pair-decoder.md)。

## 过程教训

- 开新阶段之前，没有核对下游消费方是否受益（引擎线现状、协调看板）。10-26 之后的 binding-v2 工作（T4 放行评估、U/F5、弱监督、配对解码）都是在维护态的线上继续投入。
- 产出大多是大模型标注与校准的设施，算法核心没有进展。“多个模型标同一批数据再仲裁会更准”不是研究结论。
- 花费：binding-v2 阶段 1 ¥26.2，阶段 2 ¥7.19，合计 ¥33.4。
