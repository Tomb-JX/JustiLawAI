# 北大法宝 MCP 与行政执法数据链路调研

> 版本 v0.1 · 2026-10-16 · 模型组
> 背景：行政金标的主力是个人治安处罚决定书，北大法宝收录在"行政执法库"，网页下载要会员（约 2,500 元/年，超预算）；裁判文书网暂时无法访问。本文回答三个问题：① 已接入的法宝 MCP 能拿到行政执法库的什么数据；② 拿不到全文时有哪些替代途径；③ GitHub 上有哪些相关项目可用。
> 配套：数据链路的[北大法宝作战手册](../04-plan/pkulaw-playbook.md)（§7 记录了最初接入的 9 个服务）· [文书体系与检索方案研究](./gambling-documents-and-retrieval.md) · 探针脚本 `research/eval/pkulaw_mcp/mcp_probe.py`

## 1. 结论

1. **法宝 MCP 有专门的"检索行政执法"服务（enforcement-doc），本账号已开通**，每次 75 积分。数据链路最初只接了 9 个服务，没有包括它。
2. **它只返回目录，不返回正文**：每次最多 20 条，不能翻页。每条包含标题、文号、处罚机关、处罚种类（粗分类）、个人或组织、依据法条（部分有）、公布日期、法宝链接，**没有违法事实、赌资金额、拘留天数、罚款金额**。另外每次都会返回命中总数。
3. 所以 MCP **不能替代会员下载**，但有三个实在的用途：
   - **普查**：按省、年份、处罚种类统计命中总数，用来选目标省、搭建抽样框；
   - **找原始出处**：拿文号和处罚机关，到原发布机关的公示页面免费取全文，交给数据链路的发现层和收割管线；
   - **定位稀缺类别**：文号含"不决字"的是不予处罚决定书；依据法条含"2025 修订第 82 条"的是新法案件，含"第 20 条"的通常写有从轻情节。
4. **另一个高价值用途是核验规范库**：法条沿革接口一次调用就返回某一条的全部历史版本原文。实测治安管理处罚法第 82 条（2025）与第 70 条（2012）和规范库录入**逐字一致**。
5. **积分有限，而且快过期**：账户剩 9,700 分（调研用了 300 分），**2026-11-15 全部过期**，与数据链路共用一个令牌。§5 给出分配建议。
6. **全文的出路**按成本从低到高排：原发布机关的公示页（免费）→ 绑定学院订阅（问图书馆）→ 向法宝申请科研数据合作 → 会员（超预算）。

## 3. "检索行政执法"实测

### 3.1 参数

`search_enforcement`：
- 检索字段：`queryText`（正文短语或案情）、`title`（标题短语）、`documentNo`（文号短语）；
- 筛选：`lawRegional`（只接受省级名称，如"浙江省"）、`punishmentType`（如"罚款""行政拘留"）、`punishmentTarget`（个人或组织）、`lawEnforceType`（行政处罚、行政处理等）、`startPunishmentDate` 与 `endPunishmentDate`（公布日期）；
- `searchType`：keyword（默认）或 semantic；
- **不能按执法机关、依据法律筛选**，只能把这类词写进 queryText。

### 3.2 三次调用的结果

| 条件 | 命中总数 | 观察 |
|---|---|---|
| 正文含"赌博"，个人，公布日期 2026-01-01 至今 | **8,292** | 前 20 条全是公安机关的赌博处罚；包头市公安局 8 条、土默特右旗 3 条、佳木斯东风分局 3 条；依据法条有的写到条（"2025 修订第 82 条""2012 修正第 70 条"），有的只写到法律，有的为空 |
| 同上，限浙江省 | **37** | 各省收录量差别极大；出现了反电诈罚款等误命中（正文顺带提到赌博） |
| 正文含"赌博 不予处罚"，个人 | 22,204 | 两个词分别匹配，噪声大；但确实找到一份长沙天心分局的**不予处罚决定书**（文号"天公（新）不决字〔2022〕第0083号"，依据第 12 条，未成年人） |

**返回字段**：标题、文号、类别、处罚种类、处罚对象、执法层级、执法类型、处罚机关、依据法条、公布日期、法宝链接（`?way=mcp`）。**没有正文**。

### 3.3 能用来做什么

| 用途 | 做法 | 价值 |
|---|---|---|
| **普查** | 每个"省 × 年份"调用一次，只看命中总数 | 选目标省（看哪些省 2026 年新法案件多）；作为后续采集的抽样框与验收基准 |
| **找原始出处** | 拿每条记录的"处罚机关 + 文号"到搜索引擎查原发布页面，交给发现层和收割管线 | 法宝的行政执法库是从各地执法公示汇集的，原始页面是公开的，免费取全文，合规 |
| **定位不予处罚** | `documentNo` 填"不决字"，queryText 填"赌博"，按省调用 | G3.2 要求不予处罚类单独达标，这类最稀缺 |
| **定位新法和从轻案件** | 依据法条含"2025 修订第 82 条"为新法；同时含"第 20 条"多为从轻、减轻 | T-time 测试集至少需要 50 件；情节样本 |
| **元数据交叉核对** | 处罚种类粗分类（拘留 / 罚款 / 拘留并罚款） | 核对收割得到的全文抽取结果 |

**做不到**：取正文；单个检索条件下列出超过 20 条（只能把条件切细，比如按省 × 月份切）。

## 4. 拿全文的途径

| 途径 | 成本 | 规模 | 说明 |
|---|---|---|---|
| **A 原发布机关公示页** | 免费 | 大 | MCP 目录提供文号和机关，发现层用搜索 API 定位原页面，收割管线取全文。旧公示可能已下线，2025–2026 年的最可能还在 |
| **B 绑定学院订阅** | 免费 | 大 | 作战手册 §6 记录：当前登录的是免费个人账户，**学院订阅未绑定**。需要向图书馆确认两点：学院订阅是否包含行政执法库，是否允许批量导出（校园 IP 或 VPN 登录） |
| C 网页在线阅读（免费账户） | 免费 | 小 | 作战手册记录免费账户能看到个人处罚决定书的结构化字段（处罚事由、依据、结果）；适合人工挑选测试集，不适合批量 |
| D 科研数据合作 | 待询价 | 大 | 以大创项目名义联系法宝，询问科研或教学数据合作、短期账号 |
| E 会员 | 约 2,500 元/年 | 大 | 超预算 |

**建议顺序**：A 和 B 并行。A 由数据链路接 MCP 目录；B 只需发一封邮件或打一个电话给图书馆。D 作为后备，E 不考虑。

**红线**（同作战手册）：不对法宝网页写自动抓取脚本；链接 `?way=mcp` 只用于人工核对。

## 5. 积分分配建议（剩 9,700 分，2026-11-15 过期，与数据链路共用）

| 项 | 调用次数 | 积分 | 产出 |
|---|---|---|---|
| ① 规范库核验：治安法第 12、16、20、21、22、23、144 条沿革（每次连带返回 2012 版对应条文） | 7 | 525 | psal-2012、psal-2025 两份文件全部有法宝原文出处 |
| ② 规范库核验：行政处罚法第 37 条等、两高 2005 解释、公通字〔2005〕30 号、〔2007〕1 号（先关键词找文件，再查条文） | 约 12 | 约 300 | interpretations.yaml 中的"待核验"项清零 |
| ③ 行政执法普查：31 个省 × 2026 年 | 31 | 2,325 | 各省新法案件数 + 620 条目录（含机关、文号） |
| ④ 不予处罚定向：文号"不决字" + 赌博，按省 | 约 10 | 750 | 稀缺类的目录与出处 |
| ⑤ 检察不起诉：赌博、开设赌场 | 约 5 | 375 | 行刑边界样本目录 |
| ⑥ 目标省细切（周会选定目标省之后，按省 × 月份切片取目录） | 约 50 | 3,750 | 目标省约 1,000 条目录 |
| 余量 | — | 约 1,675 | 留给数据链路的其他调用 |

①②属于引擎侧，花费少且收益确定，可以先做。③–⑥涉及数据链路的采集计划，需要两边在协作记录里对一下再执行。

## 7. 调研消耗与产出

- 调用：积分查询 2 次（0 分）、行政执法检索 3 次（225 分）、沿革 1 次（75 分），共 300 分。
- 原始响应存放在 `$JUSTILAW_DATA_DIR/engine/pkulaw_mcp/`：目录里有当事人姓名，所以不进仓库。
- 脚本：`research/eval/pkulaw_mcp/mcp_probe.py`。令牌从环境变量、官方 CLI 配置或 ZCode 配置读取，不打印、不写盘。
