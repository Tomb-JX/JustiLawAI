## 2. M4 裁量模型：实测证据链（全部 development-only，release_approved=false）

### 2.1 银标 pilot（203 参照集，10-20）

事件级划分 train 140 / valid 23 / **test 40 封存**；固定参数（LR C=1 balanced / Ridge α=10），不搜参。

| 模型 | 类型准确率 | Macro-F1 | 拘留 MAE | 罚款 MAE |
|---|---:|---:|---:|---:|
| 多数类/中位数 | 47.83% | 0.216 | **3.83 天** | **413 元** |
| 纯事实文本 B4 | **56.52%** | **0.517** | 4.20 | 501 |
| 纯银标要素 | 47.83% | 0.481 | 3.94 | 557 |

### 2.2 文本+要素融合 pilot（10-21，同冻结划分）

等权拼接（字符 1–3 元 TF-IDF + 90 维要素字典特征），valid 23：融合 Macro-F1 **0.353**，比纯文本（0.517）、纯要素（0.481）都差；罚款 MAE 494.61 仍高于中位数 413。结论：当前银标密度下加要素无改善。

### 2.3 合并 203+909（168 条验证，全景文档 10-22）

类型答对：文本 107 / 融合 106 / 要素 86 / 多数类 61；**罚款中位数基线 341 优于文本 389**。纯文本最强、要素/融合无增益在更大验证集上仍成立。

### 2.4 两字段金额绑定最小闭环（10-25，最新）

冻结 S1 facts/meta 视图 → 源坐标金额候选 + E-05 归一化 → 字段候选/NIL 决策 → 个人赌资/现场总额输出或弃判。本地确定性代码、无新增 LLM 调用、离线独立运行（未接正式 S2 服务）。train 140 拟合、按事件 5 折选 NIL 门槛、valid 23 选路线、test 40 一次性评估（不回调）。

| 字段 | 冻结闭环 test F1（TP/FP/FN） | 原 S2 test F1 | 采用路线 |
|---|---:|---:|---|
| 个人赌资 | **0.600**（9/2/10） | 0.370（5/3/14） | candidate_nil:local，NIL 门槛 0.75 |
| 现场总额 | **0.625**（10/5/7） | 0.923→test 掉到 6/0/1 | original_s2（沿用） |

## 6. 引擎线真实问题诊断（宏观指引视角；v1.3 按零预算现实修正）

> **v1.3 修正依据（用户裁定，10-26）**：① 项目为学生项目，**不存在法律组，也没有专家标注预算**——本节与 §7 旧版把"法律组复核/签字/金标"当作可排期资源，不成立，相关条目已重写；② 负责人实测**人工标注关系边的效果不如现有模型标注链路**，人工盲标路线废弃；③ 法律效力核查走**北大法宝 MCP 逐字查证**（国家层 22 项即此法核出，playbook §14–16；省级裁量基准文书可检索、全文可取，10-26 已验证通路）；④ L5 要素/binding 放行线**非主力**，隔离积压中属误判/工程缺陷的部分已检测修复（127 条误判纠正、标题闸关闭、旧 127 回放通过），其余转维护态。

1. **监督信号的真实结构（修正"金标 0 是总单点"的旧表述）**：M4 主线（facts 文本 → type/fine/detention）的监督信号是**决定书决定段的客观结果字段**，机器可解析、可双通道校验——这条线的训练并不被"无专家"卡死。真正缺的是：① **可信评测锚**（test 仅 40 条、valid 357 underpowered、结果标签存在 S1 数值错误残留如 706b 的 9 条 outcome 数值）；② **要素线的可信度**（银标要素质量未证，但要素已实测不增益 M4，此项降级为非阻塞）。"金标 0"阻塞的是旧门禁口径下的发布叙事，不是主线训练本身。
2. **M4 判别天花板是源端信号密度，不是标注质量**：1,740 包扩量后旧验证 Macro-F1 反降；要素/绑定答案注入均无效（融合 106≈文本 107、要素 86；E1–E3 与消融实验链见 notes/10-21）。facts 中位 72.5 字，裁量过程与执行口径不写入决定书——剩余方差大部分在文本之外，**继续堆模型或堆银标收益递减，能动天花板的只有源端增量**。
3. **binding/要素线：工程结论已闭环，转维护态**：四轮实验证明候选供给已解决、规则关系不可部署、可学习关系缺训练信号；而人工盲标已被实测否定（负责人标注不如模型链路）。该线保留隔离态与冻结产物（binding 结果留作未来 M5 检索键），**不再投入盲标、放行复核或付费扩产**。
4. **数值目标的结构出路依赖 MCP 核验而非专家**：实务罚款/拘留由"分档规则表+情节修正"生成（SAMR/江苏/河北同构），M4 数值头应改为 M2 档位分类+档内偏差；前提是两省 YAML 完成法宝 MCP 逐字核验 + 2025 新法衔接核验（学生可执行，无需法律组）。
5. **规范层可用但未核验、省级未接**：M2 国家层 94.3% 可算；G0.2 旧口径"签字 0/5"应改为"MCP 核验留痕 0/2 省"——国家层 22 项已有法宝逐字核对记录，缺的是省级核验与门禁口径的形式更新。
6. **集成/治理债**：① PROJECT-PANORAMA-STATUS-2026-10-22 已归档入 main（10-26 完成）；② M3/M5/M6 零代码，全链路只走通前两段；③ 案例库（M0 SQLite+FTS5）未建，M5 无从启动——GLARE 类外部证据显示判例增强是最大增益源，案例库是 M4 之外的第二结构出路。
