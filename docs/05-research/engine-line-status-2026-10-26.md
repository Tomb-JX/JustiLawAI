## 0. 一页结论

1. **引擎的"符号半边"已立住，"学习半边"仍在银标开发阶段、零金标零发布**。M0 规范库/M2 规范层已实现且国家层可用（但未签字）；M1 只有 CAIL 原型、行政数据未正式跑、未微调；M4 只到银标 pilot + 离线金额绑定闭环，四专家未实现；M3/M5/M6 未开始。
2. **M4 的实测结论是"纯文本最强、要素/融合无增益"**：合并 203+909 的 168 条验证上文本 107 / 融合 106 / 要素 86 / 多数类 61；数值预测无方法打赢中位数基线。这是当前要素密度的直接后果，且样本量 underpowered（验证集仅 23–168 条），不是要素路线的终局判定。
3. **binding（本人归属绑定）v1.1 已冻结但只许影子推理**：工程缺陷已修（同额不同人、开口金额、哈希绑定），但 H3 复核 bound 仍有语义错（个人赌资 1/4、现场总额 1/7），H3 是开发复用集不能作放行依据（BIND-SVC-QA-01 未关闭）。
4. **10-25 金额绑定最小闭环是最新引擎进展**：个人赌资/现场总额两字段的离线确定性闭环，一次性 test F1 个人赌资 0.600（vs 原 S2 0.370）、现场总额 0.625；结论"工程可运行、质量不足以发布"，下一阶段转关系建模 + NIL 校准。
5. **合并入 main 后引擎↔unify 集成缺口已补**：`normalize_date_range`/`normalize_count`（binding-fix 调用但 E-05 从未实现）已补全，run_elements binding 审计兼容缺 supply_packet 输入；collect 67 / eval 83 / unify 286 测试全绿。
6. **一切学习侧结论的总前置仍是金标 = 0**：203/909/454/345 全是 training-only 银标；G0.3 union-κ 未正式过、G0.1/G0.2 签字 0/5、B-H 人类基线未做。引擎能算规范结论（M2），但"预测历史处罚"（M4）缺可信监督信号。

## 2. M4 裁量模型：实测证据链（全部 development-only，release_approved=false）

### 2.1 银标 pilot（203 参照集，10-20）

事件级划分 train 140 / valid 23 / **test 40 封存**；固定参数（LR C=1 balanced / Ridge α=10），不搜参。

| 模型 | 类型准确率 | Macro-F1 | 拘留 MAE | 罚款 MAE |
|---|---:|---:|---:|---:|
| 多数类/中位数 | 47.83% | 0.216 | **3.83 天** | **413 元** |
| 纯事实文本 B4 | **56.52%** | **0.517** | 4.20 | 501 |
| 纯银标要素 | 47.83% | 0.481 | 3.94 | 557 |

### 2.2 文本+要素融合 pilot（10-21，同冻结划分）

等权拼接（字符 1–3 元 TF-IDF + 90 维要素字典特征），valid 23：融合 Macro-F1 **0.353**，比纯文本（0.517）、纯要素（0.481）都差；罚款 MAE 494.61 仍高于中位数 413。结论：当前银标密度下加要素无改善。

### 2.3 合并 203+909（168 条验证，全景文档 10-22）

类型答对：文本 107 / 融合 106 / 要素 86 / 多数类 61；**罚款中位数基线 341 优于文本 389**。纯文本最强、要素/融合无增益在更大验证集上仍成立。

### 2.4 两字段金额绑定最小闭环（10-25，最新）

冻结 S1 facts/meta 视图 → 源坐标金额候选 + E-05 归一化 → 字段候选/NIL 决策 → 个人赌资/现场总额输出或弃判。本地确定性代码、无新增 LLM 调用、离线独立运行（未接正式 S2 服务）。train 140 拟合、按事件 5 折选 NIL 门槛、valid 23 选路线、test 40 一次性评估（不回调）。

| 字段 | 冻结闭环 test F1（TP/FP/FN） | 原 S2 test F1 | 采用路线 |
|---|---:|---:|---|
| 个人赌资 | **0.600**（9/2/10） | 0.370（5/3/14） | candidate_nil:local，NIL 门槛 0.75 |
| 现场总额 | **0.625**（10/5/7） | 0.923→test 掉到 6/0/1 | original_s2（沿用） |

203 条独立推理输出 115 个金额，逐个核验原文哈希 + `[start,end)` 字符串，**0 坐标错位**。结论原文："工程上可运行，质量上仍不足以直接发布"；候选供给不是瓶颈（test 正例 19/19、17/17 都能在允许视图找到同值候选），**错误集中在字段角色、人物/事件关系、NIL 弃判**。下一阶段：关系建模 + NIL 校准，不再扩金额正则。

## 6. 引擎线真实问题诊断（宏观指引视角）

1. **零可信监督信号是总单点**：金标 0，银标被自家 binding 审计判"不可入训"，M4/M1 学习半边没有地基。四专家（分层贝叶斯等）全部未实现——因为实现了也没有可信数据训练/验证。
2. **M4 负结果不可过度解读，但方向明确**：23–168 条验证 underpowered，统计上既不能证明要素无效也不能证明有效；但"纯文本≥要素+文本"在三个独立切片一致出现，指向**当前要素密度不足以超过裸文本**。这与数据链路结论（源端稀疏天花板）同因。
3. **binding 质量上限已知且偏低**：H3 171 条中 141 条至少一字段需人工，v1.1 自动绑定单字段仅 4–11%，且复核仍有语义错。"自动化链路解决了能产、没解决可信"——最后一公里必须人工，而人工（法律组）节奏未定。
4. **金额绑定闭环质量不足以发布**：个人赌资 F1 0.60（19 条有值只对 9 条）、现场总额 test 掉到 5 FP；错误在关系/NIL 而非候选供给。下一步是关系建模 + NIL 校准，不是扩正则。
5. **规范层可用但未签字、省级未接**：M2 国家层 94.3% 可算，但 G0.2 签字 0/5、省级"赌资较大"门槛未接、河北/江苏 YAML 待核验——法律效力未确认，不能称"省级基准已生效"。
6. **集成/治理债**：① 最权威全景状态文档（PROJECT-PANORAMA-STATUS/CURRENT-STATUS-2026-10-22）**未提交**，只在协调工作树，有丢失风险；② M3/M5/M6 零代码，引擎完整链路（抽取→规范→定性→裁量→检索→解释）只走通前两段；③ 案例库（M0 的 SQLite+FTS5）未建，M5 无从启动。

## 7. 引擎线下一步（按依赖排序，供周会/引擎线参考）

1. **产首批真金标**（最高优先，解总单点）：法律组优先复核 binding 的 unresolved 集（每批约 141 条的四字段），按 LIMA 原则先出 100–200 件人工金标，比再采千件银标对 M4 价值大。
2. **M4 首版降复杂度**：n<500 时四专家过参数化；先做专家 A（分层贝叶斯，partial pooling 对小样本最友好）+ 专家 C（类案近邻），以 B4 文本和中位数基线为对照锚；把"是否罚款/是否拘留"与"金额/天数"拆开建模、补少数类。
3. **binding 关系建模 + NIL 校准**：按 10-25 闭环结论，攻字段角色/人物-事件关系/NIL 弃判，不再扩金额正则；BIND-SVC-QA-01 用全新来源批次做字段级独立复核定放行阈值。
4. **目标省决策前补功效模拟**：n=300/省、10 类不均衡、高缺失下分层贝叶斯稳定性用模拟研究低成本回答。
