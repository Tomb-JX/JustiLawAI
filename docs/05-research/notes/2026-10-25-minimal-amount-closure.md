# 两字段金额绑定最小闭环（2026-10-25）

## 已跑通的闭环

冻结 S1 facts/meta 视图 → 源坐标金额候选与 E-05 归一化 → 字段候选/空结果决策 → 个人赌资和现场总额输出或弃判 → 与高置信度银标评估。训练与推理为本地确定性代码，无新增 LLM 调用。引擎字段接口尚待统一，因此当前是**可独立运行的离线闭环**，未接入正式 S2 服务。

`minimal_amount_closure.py fit` 只用 140 条 train 标签训练，并以按事件分组的 5 折预测选每个候选模型的 NIL 门槛；在 23 条 valid 上比较 3 种候选特征和原 S2，选定每字段路线，写出冻结模型。`test` 在模型文件已存在后才读取 40 条 test 银标；结果文件拒绝覆盖。`infer` 不接受银标参数，用同一冻结模型从 203 条 teacher 输入独立产出结果。40 条 test 的 `infer` 与 `test` 预测逐条相同。

## 一次性 test 结果

| 字段 | 冻结闭环 TP / FP / FN、F1 | 原 S2 TP / FP / FN、F1 | 银标未提及仍输出 |
| --- | --- | --- | ---: |
| 个人赌资 | **9 / 2 / 10，0.600** | 5 / 3 / 14，0.370 | 1/21 |
| 现场总额 | **10 / 5 / 7，0.625** | 相同（该字段沿用 S2） | 5/23 |

个人赌资相对 S2 多选对 4 条且少 1 条误输出，但 19 条银标有值只选对 9 条；现场总额沿用 S2，valid 的 0 条误输出在 test 变成 5 条。这说明闭环**工程上可运行，质量上仍不足以直接发布**。本轮没有声明生产门槛，也没有把 test 用于改模型。

test 中个人赌资 19/19、现场总额 17/17 个银标有值样例，都能在允许视图找到证据内同值金额候选。候选供给在这两个字段的 test 正例上不是当前瓶颈；错误集中在字段角色、人物/事件关系和 NIL 弃判。203 条独立推理共输出 115 个金额，逐个核验了原文哈希和 `[start,end)` 对应的原文字符串，**0 个坐标错位**。
