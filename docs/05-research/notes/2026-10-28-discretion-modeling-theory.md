本文回答三件事：
1. 按目的，"裁量预测"在数学上到底是什么问题（§1–§3）；
2. 机器学习、深度学习、强化学习里，哪些知识和算法真正对得上这个问题，各自解决哪一块、代价是什么（§4–§6）；
3. 对照我们的数据现实，哪些可以做、哪些做不了、真正的难点在哪（§7–§8）。

## 1. 先按目的分清三个不同的"预测"

同一份要素，三类服务要的是三个**不同的数学对象**（Q-26）：

| 目的 | 要估计的对象 | 性质 | 评价标准 |
|---|---|---|---|
| A 执法计算器："按法律应当怎么罚" | 合法集合 Ω(x, 法, 地, 时) 与基准档位 B(x) | **规范性**：由条文决定，不是统计量 | 合法、完整、可追溯；不是准确率 |
| B 公众预期："实际上大概会怎么罚" | 条件分布 p(y \| x, 地, 时) | **描述性**：统计规律 | 校准度、区间覆盖率、对新机关 / 新时期的泛化 |
| C 决定书审查："这个处罚偏不偏" | 给定实际 y，算它在 Ω、B、p(y\|x) 下的位置 | **检验性**：异常检测 | 误报率、漏报率，偏离的可解释性 |

把三者混成一个"准确率"，是之前多次走偏的根源：规则层对 A 是"答案"，对 B 只是"特征"；新数据上"成文结论 ≠ 实际处罚"对 B 是误差，对 C 恰恰是要报告的发现。

## 2. 决策的生成过程（为什么不能当普通分类题）

把一次处罚看成下面这个过程：

```
真实案情 x*（完整事实）
   │  ① 立法：法定空间 Ω(x*, 法(t))                  ← 规范，确定
   │  ② 省级基准：档位 z = g_省(x*)，档位给处罚种类      ← 规范，确定（但有"可以"）
   │  ③ 办案人在档内选择 y ∈ Ω ∩ 档(z)                 ← 自由裁量：偏好 + 机关习惯 + 时期
   ▼
实际处罚 y
   │  ④ 写文书：机关选择写哪些情节、写多细             ← 选择性记录
   ▼
我们看到的：文书里的要素 x_obs（缺失、带抽取误差）+ y
```

这决定了它在机器学习里属于**带约束、带隐变量、带选择偏差的结构化条件分布估计**，而不是"输入特征、输出标签"的普通分类：

1. **输出有结构**：y = (种类, 拘留天数, 罚款额)，种类有轻重顺序，天数和罚款只取少数法定锚点值，且受法定幅度约束。
2. **有隐变量**：档位 z 在要素齐全时由规则确定，要素缺失时是隐变量（ADR-008 的"候选"、Q-12 的概率链路就是在对 z 做边缘化）。
3. **缺失不是随机的（MNAR）**：情节写不写由机关决定，且与结果相关（从轻的案子才写"认错认罚"）。这在统计上叫"非随机缺失"，会让直接拟合产生偏差。
4. **样本分组且分布会漂移**：同一机关的决定相关（机关习惯），习惯随时间变（C-39）；新数据的标签分布也会变（工单 B 并处占 54%，开发集 29%）。
5. **数据极少**：两省人工要素只有约 475 条，每个档内、每个锚点只有几十条。

**不简化**的意思是：模型和评估必须正面处理这五点，而不是换一个更大的分类器。

## 3. 目标函数：要预测什么、用什么损失

### 3.1 输出的分解

联合分布按法律结构分解（链式法则）：

  p(种类, 天数, 罚款 | x) = p(种类 | x) · p(天数 | 种类, x) · p(罚款 | 种类, 天数, x)

每个因子的**支撑集**由法律限定：p(天数=d | 种类, x) = 0，如果 d 超出本案法定幅度。实现上就是"掩码"：先算所有锚点的分数，把不合法的置为负无穷再归一化（masked softmax）。这是"法律作为模型结构"而不是"事后截断"（ADR-001 否定的选项 e）。

### 3.2 有序结果

处罚种类有轻重（不予处罚 < 罚款 < 拘留 < 拘留并处罚款），天数、罚款锚点也有大小。对有序结果：
- **累积链接模型（cumulative link / proportional odds）**：假设一个潜在的"严重程度" s = wᵀx + ε，用阈值 θ₁ < θ₂ < θ₃ 切成类别，P(y ≤ k) = σ(θ_k − wᵀx)。参数少、可解释，适合小样本。它的"比例优势"假设可检验，不成立时放宽为部分比例优势。
- **评价用 RPS（Ranked Probability Score）**：比较累积分布，判"罚款"成"拘留"比判成"不予处罚"罚得轻。我们一直在用 RPS，就是这个原因。

### 3.3 恰当评分规则与校准

服务 B、C 要的是**概率**，不是一个答案：
- **恰当评分规则**（log loss、Brier、RPS）：只有说出真实概率时期望得分最优，鼓励诚实的概率。
- **校准**：说 70% 的事件实际发生约 70%。工具：可靠性图、ECE；事后校准用温度缩放、保序回归。
- **锐度**：在校准的前提下，分布越集中越有用。

## 4. 法律知识进入模型的四种方式（这是"法律逻辑学习"的真正落点）

| 方式 | 原理 | 本项目对应 | 状态 |
|---|---|---|---|
| ① 规则即函数（知识表示与推理） | 条文编成可执行规则：时间效力、法定空间、档位映射。理论上属于**可废止逻辑 / 义务逻辑**的工程化 | `norm_layer.py`；逐条台账（ADR-010 拟议） | 已实现，需补完整性 |
| ② 规则作为支撑约束 | 模型只在合法集合上分配概率（掩码） | 档内数额按法定幅度过滤 | 已实现（统计分布上） |
| ③ 规则输出作为特征 / 锚点，学习残差 | 先用知识给出"应然"，再学"实然相对应然的偏离"。机器学习里叫**残差学习 / 知识引导特征**，物理信息学习也是这个思路 | RAP（ADR-007） | 已实现，特征需改为由规则生成 |
| ④ 规则作为隐结构，概率推断 | 档位是隐变量，要素缺失时对档位求和：p(y\|x_obs) = Σ_z p(y\|z,x) p(z\|x_obs) | 候选集（ADR-008）；概率链路 Q-12 | Q-12 因先验循环关闭（C-13） |

更"学术"的神经符号方法（这里只作知识地图，均未做）：
- **概率逻辑**（Markov 逻辑网、ProbLog）：给规则加权重，规则可违反但有代价——正好对应"成文与实务不一致"；
- **语义损失 / 后验正则化**：把"不得超出法定空间""赌资越大不应越轻"写成训练时的约束项；
- **规则归纳**（归纳逻辑程序设计、最优规则列表 CORELS、RuleFit）：从数据里**学出可读的规则**，例如"河北、网络投注、累计赌资 < 500 → 实务多为罚款"。这是"学习法律适用逻辑"最直接、可解释的路线，输出可以直接和成文规则逐条对照。

## 5. 机器学习算法谱系：各自解决哪一块

### 5.1 广义线性模型（GLM）
- 多项逻辑回归（RAP 现用）、有序逻辑回归（§3.2）。
- 原理：对数几率是特征的线性函数；L2 正则防过拟合。
- 优点：样本少时稳定；贡献可精确分解（基线 + 逐项贡献 = 对数几率），满足"不做黑箱"。
- 局限：交互作用（"网络 × 河北 × 金额小"）要手工加。

### 5.2 分层（多层）贝叶斯模型 —— 处理"机关差异"的标准工具
- 结构：y 的参数 = 全局效应 + 省效应 + 市效应 + 机关效应，下层效应服从以上层为中心的分布。
- **部分汇合（partial pooling）**：机关样本多就更信自己，样本少就向省、全国收缩（我们 EXP-058 的 k=10 收缩就是它的简化版）。
- **时变随机效应**：机关效应按随机游走随时间变化，正面建模"习惯漂移"——这是 C-39（本机关历史预测不了以后）失败后唯一合理的下一步，之前没做。
- 推断：MCMC（Stan / PyMC）或变分推断。输出天然是后验分布，校准性好。
- 代价：建模和诊断成本高；部署时遇到新机关只能用上层效应（这正是"对未见机关泛化"的上限所在）。

### 5.3 梯度提升树（GBDT：XGBoost、LightGBM、CatBoost）
- 原理：逐棵树拟合上一轮的残差，自动学交互作用；表格数据上通常最强的基线。
- **单调约束**：可以强制"赌资越大、预测不越轻"，把法律常识写进模型。
- 解释：TreeSHAP 给出每个特征的精确 Shapley 贡献。
- 局限：475 条样本上容易过拟合；要用强正则 + 分组交叉验证。适合作为"非线性上限"的对照，而不是主模型。

### 5.4 缺失数据理论（Rubin 框架）
- MCAR（完全随机缺失）/ MAR（取决于可见变量）/ MNAR（取决于缺失值本身或结果）。
- 方法：缺失指示变量（RAP 现用）、多重插补（MAR 下无偏）、**选择模型 / 模式混合模型**（MNAR 下的敏感性分析）。
- 对本项目的意义：情节缺失多半是 MNAR，所以"缺失"本身就带信息，但也会让"情节效应"被高估或低估。部署时要素由办案人确认填写，缺失机制和训练时不同——这是训练–部署偏移的又一来源。

### 5.5 分布偏移与域泛化
- 协变量偏移（x 分布变）、标签偏移（y 分布变，工单 B 就是）、概念漂移（p(y|x) 变，C-39）。
- 方法：按机关 / 时间分组评估（我们已用）；**分组分布鲁棒优化（Group DRO）**：优化最差机关组的损失；**不变风险最小化（IRM）**：只学在各机关间都稳定的关系；标签偏移下用 EM 重估先验。
- 意义：服务 B 面对的是"没见过的机关"，平均准确率不重要，最差组的表现才重要。

### 5.6 不确定性量化：共形预测
- 原理：用留出集的不符合度分数取分位数，给出**有覆盖率保证**的预测集合（"以 90% 概率落在 {罚款 500, 罚款 1000}"），对模型是否正确不作假设，只要求可交换性。
- 分组（Mondrian）共形：按省份、档位分别保证覆盖率（Q-07）。
- 意义：服务 B 的"结果范围"、服务 C 的"偏离"（共形 p 值）都应该建立在它上面，而不是拍一个阈值。

### 5.7 因果推断（与预测是两个问题）
- "认错认罚**会不会**让处罚变轻"是因果问题，不是预测问题：存在混杂（轻案子更容易认罚），需要倾向得分、双重稳健估计或敏感性分析。
- Q-03（"可以从轻"何时实际适用）本质是因果 / 机制问题。
- 反事实："赌资若是 500 元会怎样"在规则层是确定的（规则可直接重算），在实务层需要模型——补查提示（Q-25）用的就是这种反事实。

### 5.8 贝叶斯决策与信息价值（追问哪一项）
- 期望信息增益 / 决策信息价值：补上哪一项要素，最能改变结论或收窄分布。
- 规则层可精确计算（对每个缺失要素的可能取值重算档位），这就是 Q-25 的确定性方案；加上实务分布后就是完整的信息价值计算。

### 5.9 检索与基于实例的学习
- k 近邻、类案检索（Q-08）：给出"最相似的已决案件"作为证据，既是预测也是解释。
- 外部文献中类案检索是大增益来源；但对"未见机关"同样受机关差异影响。

## 6. 深度学习与强化学习：放在哪里才对

### 6.1 深度学习
| 用途 | 方法 | 本项目判断 |
|---|---|---|
| 文本 → 要素 | 序列标注、抽取式问答、大模型受限解码 | **最合适的位置**，已用（A 层，ADR-002） |
| 文本直接 → 处罚 | BERT / Lawformer 分类、多任务（罪名-法条-刑期的依赖图，如 TopJudge） | 文献主流；对我们是"判决后文书"任务，与部署输入不符（R8、ADR-009），新人群上不迁移（C-42） |
| 表格 → 处罚 | TabNet、FT-Transformer 等表格深度模型 | 475 条样本上一般不如 GBDT / GLM，无优势 |
| 案例关系 | 图神经网络（案件–法条–机关图） | 需要大规模图数据，暂无条件 |
| 法律推理 | 大模型思维链、三段论提示、检索增强 | 可作为"解释生成"或"复核助手"，不作裁决依据（不可复现、难校准） |

结论：深度学习在本项目的价值集中在**感知层（读文本、抽要素）**，不在**裁决层**。这不是退化，是数据量与任务形态决定的：裁决层是小样本、强规则、需可解释的结构化问题。

### 6.2 强化学习
诚实地说：**"由要素预测处罚"是监督学习问题，用强化学习没有意义。** 强化学习在这里只有三个真正对得上的位置：

1. **逆强化学习 / 离散选择模型**——"学习裁量逻辑"最深的一种表述：
   把办案人看成在合法集合里选一个处罚以最大化某种效用 U(y; x) = 法定严重度的匹配 + 机关偏好 + 噪声。从大量决定中反推 U 的权重，就是逆强化学习；单步决策的逆强化学习在计量经济学里就是**随机效用 / 条件 logit 离散选择模型**。
   有意思的是：RAP 的多项逻辑回归在数学上正是一个随机效用模型。区别在于，严格的选择模型把"选项"本身的属性（该处罚的严厉度、是否在基准档内、离基准多远）作为特征，能回答"办案人多大程度上遵循基准、偏离时偏向哪边"——这比单纯预测更接近"理解裁量逻辑"。
2. **序贯追问（部分可观测马尔可夫决策过程 / 序贯实验设计）**：对话引导里"下一步问哪个要素"是序贯决策；但在要素少、规则确定时，§5.8 的贪心信息价值已足够。
3. **大模型抽取的强化微调**（RLHF / 可验证奖励的强化学习）：用"证据能定位、通过校验"作奖励训练抽取模型。属于 A 层工程，与裁量算法无关。

## 7. 对照数据现实：哪些能做，难点在哪

| 难点 | 本质 | 对策 | 现有证据 |
|---|---|---|---|
| 档内差异主要来自机关 | 分组异质性 + 漂移 | 分层模型 + 时变效应；对未见机关只承诺上层效应 | 同事件几乎同判（C-04）；机关习惯不迁移（C-26、C-39） |
| 文书短、情节选择性记录 | MNAR、信息缺失 | 缺失建模 + 敏感性分析；部署时由办案人补全 | 事实段中位约 117 字 |
| 样本少 | 方差大 | 低容量可解释模型（GLM / 分层贝叶斯 / 规则归纳）；GBDT 只作上限对照 | 两省约 475 条 |
| 结果是锚点值 | 结构化离散输出 | 有序 + 掩码的锚点分布，不做回归 | 罚款 91% 在锚点（C-05） |
| 成文 ≠ 实务 | 规范与描述分离 | 规则层给应然，学习层学偏离（RAP 思路），规则归纳把偏离写成可读规则 | 河北网络投注（C-32、C-44） |

**档内要素学习从未被正式检验过**：已有的负结果用的是文本、机关先验、省份 / 档位条件化（C-07 明写"没有用结构化要素"）。真正的问题是：档内差异里，**要素能解释多少、机关能解释多少、剩多少是不可约噪声**——这可以用分层模型的方差分解直接回答，是"能否实现"的上限。

## 8. 推荐的算法组合（按层）

| 层 | 主方法 | 对照 / 补充 | 输出 |
|---|---|---|---|
| A 要素 | 大模型受限抽取 + 证据校验 | — | 要素与证据 |
| B / C 规则 | 逐条台账驱动的规则编码 | — | 法定空间、档位、候选（可追溯） |
| D 种类（候选内） | 规则锚定的有序 / 多项 logit（RAP），特征由规则生成 | GBDT（单调约束）作上限对照；规则归纳把实务偏离写成可读规则 | 校准的种类分布 + 逐项贡献 |
| D 档内数额 | **分层贝叶斯有序模型**：锚点上的有序分布，法定幅度掩码，要素固定效应 + 省 / 机关随机效应（可时变） | 全国分布（现行）作基线；方差分解给上限 | 校准的锚点分布 |
| E 偏离 | 共形 p 值 + 规则对照 | 离散选择模型分析"遵循基准的程度" | 偏离等级与理由 |
| F 输出 | 分组共形预测集 | — | "结果范围 + 条件" |

判定"档内要素学习能否实现"的实验（待预注册）：
- 任务：法定档内的锚点选择；
- 模型：上表 D 档内数额主方法，及 GLM、GBDT 对照；
- 评估：按机关留出 + 时间外推；RPS、对数损失、校准；方差分解；
- 结局：通过 → 进入 D 层；不通过 → 关闭并写明重开条件（机关内部案卷、情节记录完整的数据）。

**实验结果（10-28，EXP-064 / C-45）**：第一阶段未通过。要素模型在未见机关上比不用要素的边际分布显著更差（RPS +0.033），梯度提升树同样更差；方差分解显示机关间差异占档内方差 11%～62%，要素的样本内解释度不能迁移。这与 §7 的预期一致：档内差异主要来自机关习惯与不可约噪声。

## 术语速查

- **部分汇合**：分层模型中，小组的估计向总体收缩，收缩程度由组内样本量和组间差异自动决定。
- **掩码 softmax**：把不合法选项的分数设为负无穷后再归一化，概率只分配在合法集合上。
- **RPS**：对有序类别，比较预测与真实的累积分布差，越小越好。
- **共形预测**：不依赖模型正确性、在可交换性假设下保证覆盖率的预测集合方法。
- **MNAR**：缺失与否取决于缺失值本身或结果，直接忽略会产生偏差。
- **随机效用模型**：选择者对每个选项有"效用 = 可观测部分 + 随机误差"，选效用最大者；误差服从极值分布时即多项 logit。
- **规则归纳**：从数据中学习"如果……则……"形式的可读规则。
