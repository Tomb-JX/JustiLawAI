# 金额关系选择式试标流程（6 案）

## 给标注人的操作

打开 `.tmp-edge-review-20261021/simple-review.html`。六案按金额候选数 1、1、2、3、4、15 排列；最后一案较复杂，可以先完成前五案。每案只回答两题：目标人的**个人赌资**是哪笔、目标人本次行为的**现场总额**是哪笔。金额候选在原文中用黄色标出，并有原文位置，重复的同值金额需要按上下文选具体位置。

每题可选一个金额候选，也可选“原文未提及”“有线索但无法确定”“正确金额漏出候选”。选候选后，个人赌资再选“目标人／其他人／多人共同／看不清”；现场总额再选“目标人本次行为／其他事件或既往行为／看不清”。漏候选时复制原文中的金额文字。说明可选。

点“标为完成并下一案”会检查两题及其关系选择是否填全。进度保存在本机浏览器的 localStorage；“导出标注 JSON”会下载 `simple-amount-review.json`，之后可用“导入进度”恢复。导出文件未自动上传，也不含银标或系统预测。该包为单人复核试标，**不是双人仲裁金标**。

## 工程边界

该轻量标注记录的是 `字段 → 精确金额候选 → 粗粒度人物／事件关系`，足以检验当前两类金额字段的候选、错配与弃判；它不标人物实体、事件编号、跨句同指、年龄或人数，不能直接替代完整图边集。选样来自旧盲标包，偏向系统争议和控制样例，不能估计总体准确率。

页面由 `research/discretion/unify/prepare_simple_review.py` 从现有盲包生成；`simple-cases.json` 与页面并列保存。人工导出后可运行：

```powershell
python research/discretion/unify/validate_simple_review.py --cases .tmp-edge-review-20261021/simple-cases.json --review <导出的 simple-amount-review.json 路径>
```

校验会检查案件及原文哈希、候选 ID、关系选择和漏候选原文是否出现在允许视图。只有标注人完成后，才与冻结的银标和系统输出做独立对照。原 24 案详细盲标包保持不变。
