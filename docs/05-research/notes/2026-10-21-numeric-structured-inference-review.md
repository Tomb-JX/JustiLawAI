# 数值与绑定：结构化推断复审（2026-10-21）

## 对上一版设计的否定性结论

“模型先找 mention、再提议关系边、最后投影字段”是工作流拆分，不是降低模型语义依赖的算法。来源坐标、边日志和逐阶段复核只能改善可审计性；如果候选提及与关系仍由同一个模型自由提出，随机性、系统性偏见和共同遗漏会原样传递。把 `proposed` 改成 `confirmed` 若没有独立判据，也只是改名。不能以“有图”为算法创新或质量证明。

当前可验证的事实是：新候选包的关系、推导、绑定均为 0；旧引擎 `binding.py` 虽有图节点/边和确定性约束，但候选入口仍是正则，谓词/主体以局部词法判定，未形成可学习、经字段质量验证的全局求解。163 条银标的直接候选覆盖总计 193/268，其中 51 个年龄和 23 个人数缺口本来就需要推导，不能把它们一律算作“正则需要更多花样”。银标不是独立金标，无法据此证明任何新语义模型更准。

## 真正的算法对象

给定允许视图原文和指定 target，建立**候选解释空间**，而不是先让模型给出唯一答案。每个原文数值片段可以有多个类型/范围候选；每个金额可以有个人赌资、现场总额、抽头、罚款等多个角色候选；每个人物提及可以属于目标、他人或未知；每个行为/时间/金额可以落入多个事件候选，另设 `NIL/unknown`。同一字段允许多个候选路径竞争，也允许弃判。模型只能为候选或边提供分数，不能以自由文本直接写最终数值作为证明。

定义离散变量：`x_i` 表示数值片段及解析方案是否成立，`p_j` 表示人物提及的实体身份，`e_k` 表示行为场景，`r_i` 表示数量角色，`o_i` 表示数量归属，`b_f` 表示字段选择哪条直接或推导路径（包括 `ABSTAIN`）。总分可以写成 `S(z)=Σ span_score + Σ relation_score + Σ event_score + Σ field_score`，在满足硬约束的解释 `z` 中求最高分和次优分；输出要保留其竞争解释及差距。可用整数规划/CP-SAT，也可在规模较小时枚举或 beam search；求解器选择并不能弥补坏候选和坏分数。

### 候选空间：避免单一抽取器漏掉就永远消失

以宽松的 Unicode 数词/货币符号扫描器和数值语法生成**类型未知、可重叠**的 span lattice，包括阿拉伯/中文数字、单位、省略单位、比较符、约数、打码、表格标签值、日期。它只是识别“可能是数量”的通用词法，不用“赌资附近 16 字”决定角色。另有可训练的 span 提议器与 LLM 提议器，三者取并集并记录来源；任何一个单源缺席不意味着文本未提及。日期范围的两个端点和完整区间可同时保留，待解析与冲突约束选择。人员列举是实体 mention lattice，不假造一个原文里不存在的“人数数字”。

词法扫描仍是代码规则，但其目标是覆盖字符形式，而非用不断新增业务关键词完成字段判断。上限仍受各提议器共同遗漏限制；因此必须报告候选召回和“所有来源都漏”的比例。若离线比较证明开放式 LLM 提议器没有提高召回，它不应留在主路径。

### 解析与关系分别计分

对已定位 span，唯一规范化器输出无损 `Decimal/整数/日历范围 + 单位 + 精度 + 比较符/开闭端点 + 解析失败原因`，绝不根据字段预期值倒选数字。E05 可作数词解析底层，但当前浮点与宽松句级对账不足以表达全部中间语义。解析不决定个人或共享角色。

关系打分使用**可观察特征**：实体同指、依存/谓词论元、句法距离、标点边界、指代、事件时间和行为词、否定与既往、场景成员、单位与字段类型、同事件其他文书的独立佐证。词法线索、语言模型分数和跨文档信息都是软证据；需要学习或校准权重。若某类特征不稳定，应通过消融去掉，而非把它写成硬规则。

### 硬约束、软约束、弃判

硬约束只放机械或契约上可证的事实：来源区间必须逐字落在 facts/meta；选择的解析值必须来自该 span 或有明确操作数的推导；单位必须与字段兼容；单人字段不能绑定到已证实的另一个人；先前处罚事件不能直接冒充本次赌博场景；同一字段的互斥数值不能同时作为唯一值。目标参与某场景要有独立路径，不能因为场景字段是 shared 就自动继承。

“现场总额 ≥ 个人赌资”“同句金额属于最近的人名”“多人金额均分”“同一事件重复文书数值相同”**不宜作为硬约束**：它们有账面范围、证物归属、重复记述等反例。只能作为软证据，并接受冲突。对比最优/次优解释、候选源扰动和模型分数扰动；若字段绑定不唯一、分差不足或某关键边只有单一不可靠来源，就输出 `needs_review/ABSTAIN`。这是一种选择性预测，目标是控制 silent-wrong，而不是把每条都填满。

例如“甲、乙分别持有 500 元、1000 元，现场共查获 1500 元”，两个人物、三笔钱先保留全部人物—钱款候选关系；“分别”的顺序、`持有` 和 `现场共查获` 的论元结构支持两笔个人款及一笔场景总额，字段投影只能选与 target 对应的个人边。若把句子改成“甲和乙持有 500 元”，原文没有足够证据判定各持 500 元还是二人合持 500 元，约束求解应弃判个人金额。前一句是否绑定正确仍依赖提及/关系分数与句法证据，不能由图结构自身保证。

推导为有类型的运算节点：`age(birth_date, behavior_date, target-person)`，`count(unique persons participating in same scene)`。出生和行为日期的精度不足时年龄给区间或弃判；“等人”表示名单可能不完整，不能把列举人数当精确总人数。数值合计只在金额角色、期间、是否重复包含都已确定时计算。推导节点列出全部操作数和损失政策，以便重算与反例测试。

## 无金标条件下如何获得分数与验证增益

当前 203 银标只有字段值和句级证据，不包含可靠的 mention/主体/事件/角色边。它可提供**弱监督**：正确字段值约束可能路径，但不能唯一标出哪条边正确；不能把任一最大分路径回填为真边再训练，否则形成自证循环。可从它构造候选路径的边际似然或排序信号，并结合原文强约束生成部分可信负例（不同主体、不同单位、先前事件）；边权保持低容量并做事件级拆分。没有充分独立标注时，权重和阈值只能称为试验值，不能称为已校准正确率。

必须做**增益归因实验**，而非只比较整条新流水线：

1. 保留现行单次字段教师与当前正则候选两条基线，冻结同一输入和成本。先做候选来源消融：扫描器、span 模型、LLM、并集；按可核对证据统计覆盖和新增误候选。
2. 在相同候选和相同局部分数上，比较独立逐字段贪心与联合约束求解。只有后者降低冲突或 silent-wrong，才能说“图算法”本身有效。再分别去掉人物边、场景边、推导节点与弃判，测各模块增益。
3. 对同值异人、个人与现场总额、跨句指代、多人“各有”、出生日期推龄、列举人数、历史处罚、遮蔽金额造冻结反例及文本变体；同一语义的标点/姓名替换不应改变答案，不同主体的交换应改变个人字段。这是稳定性/一致性证据，不是假冒金标准确率。
4. 真实语义正确率仍需独立裁决样本。若短期没有人力，只能报告相对银标、逻辑冲突率、来源合法率、扰动稳定率、弃判率、覆盖率及成本；不能报告“主体绑定正确率已提升”。test40 继续封存，不能在它上面选择权重或阈值。

## 实施判断

先做一个可证伪的窄切片：个人赌资、现场总额、参赌人数、年龄。若统一候选集上的联合推断相比贪心没有可归因的改进，或改进完全来自 LLM 多轮投票，就撤销图求解方案，保留较简单的直接抽取 + 明确弃判。只有通过消融，才扩大到全部数字字段及更复杂场景。这一结论比先建完整图平台更符合当前数据量和质量证据。

本页提出的是待检验的算法假设，**不是已实现能力**。形式化约束本身不能消除语义不确定性；真正可减少随机依赖的是多来源候选、可学习且校准的局部分数、全局互斥约束、明确弃判，以及相同输入上的消融验证。
