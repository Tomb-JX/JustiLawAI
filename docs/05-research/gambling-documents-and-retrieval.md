# 赌博案件的文书体系与检索方案研究

> 版本 v0.1 · 2026-10-16 · 模型组
> 目的：回答三个问题：① 赌博案件在法律上分几条线，每条线产生哪些文书；② 本项目需要哪些文书、各拿来做什么；③ 裁判文书网上不同检索方式为什么结果差这么多，各自适合检索什么。
> 配套：[裁判文书批量检索需求](./wenshu-retrieval-plan.md)（下单与验收）· [行政案例数据交付规格](./data-spec.md) · [引擎方案](../02-design/gambling-discretion-engine.md)
> 核验状态说明：**已核对**表示已对照官方页面；**待核验**表示只看到二手转述，引用前需在北大法宝核对原文。

## 1. 法律体系：同一个"赌博"行为，分三条线处理

```
                       ┌─ 不构成违法（亲友间不以营利为目的的娱乐）──→ 不处罚
赌博行为 ── 公安查处 ──┼─ 违反治安管理 ──→ 治安管理处罚（行政线）──→ 不服可复议 / 起诉（行政诉讼）
                       └─ 达到刑事追诉标准 ──→ 移送起诉（刑事线）──→ 一审 / 二审判决
另有民事线：赌债、因赌博离婚、借钱给人赌博等纠纷（本项目不需要，但它是全文检索的主要噪声来源）
```

### 1.1 行政线（本项目的主战场）

| 规范 | 要点 | 状态 |
|---|---|---|
| 治安管理处罚法（2012 修正）第七十条 | 以营利为目的为赌博提供条件，或参与赌博赌资较大：五日以下拘留或五百元以下罚款；情节严重：十日以上十五日以下拘留，并处五百元以上三千元以下罚款 | 已录入 `norms/national/psal-2012.yaml` |
| 治安管理处罚法（2025 修订）第八十二条，2026-01-01 施行 | 罚款上限提高到一千元 / 五千元；从轻、减轻、认错认罚等总则条款同时变化 | 已录入 `psal-2025.yaml` |
| 公安部《关于办理赌博违法案件适用法律若干问题的通知》（公通字〔2005〕30 号） | "赌资较大"的数额由各省公安机关确定；亲属间不以营利为目的的少量输赢娱乐不予处罚 | 待核验（原文未录入） |
| 公安部《公安机关对部分违反治安管理行为实施处罚的裁量指导意见》（2018-06-05 印发） | 先按"情节较轻 / 较重 / 严重"的具体情形定处罚幅度，再看对象、后果、数额、次数、主观恶意 | 待核验（赌博条目原文未找到） |
| 各省公安厅治安管理处罚裁量基准 | 各省"赌资较大""情节严重"的具体数额不同；新法施行后各省在改 | 需逐省收集（M2 的省级规范） |
| 《公安机关办理行政案件程序规定》第十条 | 管辖条款"……但是涉及卖淫、嫖娼、赌博、毒品的案件除外"。**与赌博处罚无关，却几乎每份治安案件判决都会引用**，是行政全文检索最大的噪声 | 已核对（文书原文） |
| 行政诉讼法第六十九、七十、七十四、七十七条 | 法院审查处罚后的四种结论：驳回（维持）、撤销、确认违法、**变更**（第七十七条：行政处罚明显不当的可以直接改判处罚） | 已核对 |

### 1.2 刑事线（行刑边界与后续扩展）

| 规范 | 要点 | 状态 |
|---|---|---|
| 刑法第三百零三条 | 第一款赌博罪（聚众赌博、以赌博为业）三年以下；第二款开设赌场罪；第三款组织参与国（境）外赌博罪 | 已核对（新闻及论文转述一致） |
| 刑法修正案（十一），2021-03-01 施行 | 开设赌场罪基本刑由"三年以下"提高到"五年以下"，情节严重由"三年以上十年以下"提高到"五年以上十年以下"；新增第三款 | 已核对 |
| 两高罪名补充规定（七） | 第三款罪名确定为"组织参与国（境）外赌博罪" | 待核验（只见论文转述） |
| 两高《关于办理赌博刑事案件具体应用法律若干问题的解释》（法释〔2005〕3 号） | 聚众赌博的入罪标准：组织 3 人以上赌博，且抽头渔利累计 5,000 元以上，或赌资累计 5 万元以上，或参赌人数累计 20 人以上；组织 10 人以上赴境外赌博收取回扣、介绍费 | 已录入 `interpretations.yaml`，待核验 |
| 两高一部《关于办理网络赌博犯罪案件适用法律若干问题的意见》（2010） | 网络开设赌场"情节严重"：抽头渔利累计 3 万元以上、赌资累计 30 万元以上、参赌人数累计 120 人以上等 | 待核验 |
| 两高一部《关于办理利用赌博机开设赌场案件适用法律若干问题的意见》（2014） | 设置 10 台以上赌博机，或 2 台以上并容留未成年人等，按开设赌场罪处理 | 待核验 |
| 两高《关于常见犯罪的量刑指导意见（二）（试行）》及各省实施细则 | 开设赌场罪是其中的七个罪名之一，量刑起点由各省细则规定 | 待核验（全国文件的发布日期未查到） |

**对建模的直接影响**：
- 开设赌场罪在 2021-03-01 前后法定刑不同，**刑期标签跨时期不可直接比较**，模型要带"适用哪部刑法"的特征。行政线 2026-01-01 前后同理。
- 入罪标准是"累计"计算的。行政案件中"抽头几千元、赌资几万元"的，正处在行刑边界附近，这正是 M2 "是否移送刑事"判断要学的区域。

### 1.3 民事线（不需要，但要知道它在哪）

赌博在民事文书里大量出现，但都不是赌博本身的处理：
- 民间借贷：借款人辩称"这是赌债"，出借人明知借款用于赌博的，借款合同无效；
- 离婚：民法典第一千零七十九条把"有赌博等恶习屡教不改"列为调解无效应准予离婚的情形；
- 不当得利、合同纠纷等。

民事案由体系里**没有**"赌博"案由，这类文书只能靠全文检索碰到，所以**全文检索一定要先限定案件类型**。

## 2. 每条线产生哪些文书，本项目要哪些

| # | 文书 | 在裁判文书网？ | 内容 | 本项目用途 | 优先级 |
|---|---|---|---|---|---|
| 1 | 公安行政处罚决定书（赌博，个人） | ❌ 不在 | 事实、处罚、依据，情节写得少 | **行政金标主力**：M4 训练集与测试集 | P0 |
| 2 | 不予行政处罚决定书 | ❌ 不在 | 不处罚的理由 | 下界案例，门禁 G3.2 要求单独达标；**最稀缺** | P0 |
| 3 | 行政复议决定书 | ❌ 不在（复议机关公开、法宝） | 复议机关对处罚的审查 | 复核标签 | P1 |
| 4 | 行政一审判决书（案号"行初"） | ✅ | 复述原处罚（事实、拘留天数、罚款、收缴赌资）+ 证据 + 法院审查结论 | 金标（测试集中占比 ≤ 50%）+ 复核标签 + M6 说理素材 | **P0** |
| 5 | 行政二审判决书（"行终"） | ✅ | 复述"一审判决查明"，二审结论；行政二审维持原判也用判决书 | 同 4，与一审按案号合并 | **P0** |
| 6 | 行政裁定书（驳回起诉、再审审查"行申"等） | ✅ | 多为程序性内容；再审审查裁定偶尔复述处罚 | 低 | P2 |
| 7 | 非诉执行审查文书（"行审"） | ✅ | 公安申请法院强制执行罚款等，附处罚事实 | 少量补充 | P2 |
| 8 | 行政赔偿文书（"行赔"） | ✅ | 处罚被撤销后的赔偿 | 几乎不用 | P3 |
| 9 | 刑事一审判决书（"刑初"，案由赌博罪、开设赌场罪） | ✅ | 指控、查明（含"另查明"退赃等）、本院认为（自首、坦白、认罪认罚、主从犯、获利金额、量刑建议）、判决 | 行刑边界、重做锚点 A2、后续刑事扩展 | P1 |
| 10 | 刑事二审判决书（"刑终"） | ✅ | **刑事二审维持原判用裁定，改判才用判决**，所以二审判决基本都是改判 | 量刑偏差的案例 | P2 |
| 11 | 刑事二审裁定书（维持原判） | ✅ | 维持理由 | 低 | P3 |
| 12 | 刑罚变更裁定（"刑更"，减刑、假释） | ✅ | 与量刑无关，但案由仍是赌博罪、开设赌场罪 | **排除**：开设赌场罪案由下有约 4.5 万份裁定书，多为这一类 | — |
| 13 | 刑事判决里的前科记载（"曾因赌博被行政拘留……"） | ✅ | 只有处罚时间和结果，没有当时的事实 | 很低 | P3 |
| 14 | 民事文书（赌债、离婚等） | ✅ | 与赌博处理无关 | **排除**（全文检索噪声） | — |
| 15 | 规范文件（法律、司法解释、公安部文件、省级裁量基准） | ❌ | 处罚规则本身 | **M2 规范层** | P0 |

**结论**：
- 行政金标的主力（1、2、3）**都不在裁判文书网**，要靠发现层的执法公示和北大法宝。
- 裁判文书网对本项目的价值集中在 4、5（行政诉讼判决）和 9（刑事一审判决）。
- 12 和 14 是检索时必须主动排除的两大噪声。

## 3. 案由体系：为什么"案由搜赌博罪"会是 0

裁判文书网的"案由"不是自由填写的文本，而是从一棵分类树里**选一个节点**。这棵树按案件性质分成几个互不相通的大类：

```
刑事案由 ─ 妨害社会管理秩序罪 ─ 扰乱公共秩序罪 ─ 赌博罪 / 开设赌场罪   ← 按罪名
民事案由 ─ ……（没有任何赌博相关案由）                               ← 按民事法律关系
行政案由 ─ 行政处罚 ─ 行政拘留 / 罚款 / 警告 / 没收违法所得 ……        ← 按被诉行政行为（2021 年起）
执行案由、国家赔偿案由 ……
```

出现 0 结果，常见原因有四个：

| 原因 | 说明 | 怎么做 |
|---|---|---|
| ① 案由与案件类型冲突 | 例如案件类型选了"行政案件"，案由选"赌博罪"：行政案件不可能有刑事案由，结果为 0 | 用刑事案由时，案件类型不选或选"刑事案件" |
| ② 没有在树里选中叶子节点 | 直接在案由框里打字，或停在上层节点 | 逐级展开到"赌博罪""开设赌场罪"后点选 |
| ③ 行政案件根本没有"赌博"案由 | 依《最高人民法院关于行政案件案由的暂行规定》（法发〔2020〕44 号，2021-01-01 施行），行政案由按**被诉行政行为**命名，赌博拘留的案由就是"行政拘留"或"行政处罚"，看不出是不是赌博 | 行政赌博案件只能靠全文检索，再本地过滤 |
| ④ 树里没有这个罪名 | "组织参与国（境）外赌博罪"是 2021 年新罪名，文书网的案由树里没有这个节点 | 改用全文检索"组织参与国（境）外赌博" |

**行政案由的新旧两套写法**：2021 年以前按 2004 年《关于规范行政案件案由的通知》，案由 = "管理范围 + 行为种类"，标题里写作"公安行政管理：治安管理（治安）"；2021 年起删去了管理范围，只写"行政拘留""行政处罚"。所以：
- 按标题含"治安"检索，2013–2020 年的命中不少（实测 908 份），2021 年以后几乎为 0；
- 文书网的行政案由树里仍保留旧节点"行政主体 › 治安管理（治安）"，它能否覆盖新文书尚未验证（见 §6 待验证清单）。

**案由标签会跨案件类型**：实测案由 = 赌博罪的 60,623 份文书中，有 51 份属于民事案由、1,723 份属于执行案件（刑事判决中财产部分的执行）。按案由检索时要同时限定案件类型和文书类型。

## 4. 各种检索方式的差别

### 4.1 原理与适用场景

| 方式 | 原理 | 适合 | 主要风险 |
|---|---|---|---|
| **A 案由**（树选） | 法院按罪名或行为打的标签 | **刑事首选** | 行政没有赌博案由；新罪名不在树里；与案件类型冲突时结果为 0 |
| **B 全文关键词** | 正文任何位置出现即命中 | **行政只能用这个** | 噪声：管辖条款、前科、民事赌债和离婚；"第七十条""第八十二条"在不同法律里含义不同 |
| B′ 全文限定段落 | 只在网站切好的"事实 / 理由 / 判决结果"等段落里找 | 行政降噪 | 网站切段的准确度未知；事实段里也可能写有前科 |
| **C 案件名称（标题）** | 标题含词即命中 | 辅助核对 | 标题格式随年代变化：刑事标题常写"开设赌场"不带"罪"；行政标题 2021 年前后完全不同 |
| D 法律依据 | 结构化法条字段 | 理论上最准 | 实测返回 0，输入格式要求不明（待验证） |
| **E 案号代字** | 案号含"刑初""行初""行终"等 | 限定审级、排除"刑更" | 2016 年前旧案号写作"刑初字第××号"，仍含"刑初"，影响不大 |
| F 左侧分面 | 网站对当前结果的统计 | 取官方计数基准 | 只能看数，每次最多翻看 600 条 |

### 4.3 时间维度上的断点

检索结果和标签都要按这些时间点分段看：

| 日期 | 变化 | 影响 |
|---|---|---|
| 2016-01-01 | 新案号规则施行（法〔2015〕137 号） | 之前的案号不一定含省份简称，省份要从法院名称补 |
| 2021-01-01 | 新行政案由施行 | 行政标题、案由写法整体改变 |
| 2021-03-01 | 刑法修正案（十一）施行 | 开设赌场罪法定刑提高；新罪名出现 |
| 2021–2022 年 | 文书网公开量骤降（行政赌博从 2019 年的 650 份降到 2022 年的 23 份） | 近年样本少，第三方数据库更可能缺 |
| 2026-01-01 | 新治安管理处罚法施行 | 罚款幅度变化，从旧兼从轻 |

## 5. 推荐的检索组合

| 目标 | 推荐方式 | 理由 |
|---|---|---|
| 行政诉讼判决（文书 4、5） | 案件类型 = 行政；**全文"赌博"全量**；本地过滤（排除只命中管辖条款的；要求出现"参与赌博""为赌博提供条件""赌资""赌具""聚众赌博"之一） | 行政没有赌博案由，只能用全文；总量不到 4,000 份，全量加本地过滤最稳 |
| 刑事一审判决（文书 9） | **案由 = 赌博罪或开设赌场罪**，文书类型 = 判决书；用案号"刑初"限定一审 | 精确且全；限定判决书可排除"刑更"裁定 |
| 组织参与国（境）外赌博罪 | 全文"组织参与国（境）外赌博"，案件类型 = 刑事 | 案由树里没有这个罪名 |
| 刑事改判（文书 10） | 案由同上 + 案号"刑终" + 判决书 | 二审判决基本就是改判 |
| 官方计数基准 | 每种组合看左侧分面的年份、地域统计 | 用于到货验收与退款计算 |

## 6. 待验证清单（适合人工在网页上直接做）

网页操作人工做更快。每项记录命中总数、年份分面，必要时记录抽查结果：

| # | 操作 | 要回答的问题 |
|---|---|---|
| V1 | 高级检索 → 案由逐级选"刑事案由 › 妨害社会管理秩序罪 › 扰乱公共秩序罪 › 赌博罪"，案件类型不选 | 能否复现 60,623 份（全部类型）；如仍为 0，截图案由框和已选条件 |
| V2 | 同上，选"开设赌场罪" | 能否复现 192,225 份 |
| V3 | 在案由树里找"组织参与国（境）外赌博罪" | 确认是否确实没有这个节点 |
