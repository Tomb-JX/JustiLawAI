# 年龄和参赌人数最小闭环实验（2026-10-25）

## 口径与冻结

- 数据：同一批 203 条教师可见输入及高置信银标；按事件分组为 train 140、valid 23、test 40（测试集 25 个事件）。银标是工程参照，不是人工仲裁金标。
- 训练集用于人数候选分类；5 折事件级 OOF 选 NIL 阈值 0.45；验证集仅看模型表现。年龄推导是确定性算法，无训练参数。冻结产物写出后才读取 test 标签，测试集没有用于调参。
- 预测只读教师可见文本。年龄不读取银标中的 `behavior_date`；人数不读取银标证据。每条选中输出带候选坐标，年龄另带出生和事件日期两个操作数。

## 实际实现

1. **年龄**：从供应包找出生日期候选和 facts 区域中的非出生、非前科日期候选。出生年月只有区间时按最早、最晚生日计算所有可能周岁；所有有效操作数对只能导出同一个整数才输出，否则弃权。这是可检查的区间计算和溯源，还没有证明日期属于正确的事件、出生日期属于正确的人。
2. **参赌人数**：只考虑 E05 已归一化的精确“人”数候选；训练稀疏逻辑回归给候选打分，与 NIL 阈值比较。特征来自局部词片、角色与主体提示和场景数量，不调用 LLM。它仍依赖供应包的正则候选，且没有从姓名列举生成派生人数。
3. **还没有实现** 人物—参与—事件的显式图边、约束求解、姓名列举集合去重，也没有引擎接口集成。年龄输出保留了两个操作数，人数输出保留了原始候选；这是后续建图的数据基础，并非完整关系图。

## 结果

| 字段 | 开发集 valid | 冻结 test | 原 S2 在 test（不提供银标日期） |
|---|---:|---:|---:|
| 年龄 | TP 7 / FP 0 / FN 1；F1 0.933 | TP 22 / FP 0 / FN 1；F1 0.978 | TP 0 / FP 0 / FN 23 |
| 参赌人数 | TP 6 / FP 0 / FN 1；F1 0.923 | TP 9 / FP 3 / FN 14；F1 0.514 | TP 0 / FP 0 / FN 23 |

203 条无银标推理输出：年龄选中 73，人数选中 51。40 条测试预测与同一批无银标推理逐条一致；已检查全部 203 条选中操作数和候选的原文坐标，0 处越界或文本不符。三个确定性单元测试通过。

## 失败分型与下一步

- 测试集人数 23 个正例中，仅 11 个有任何精确“人”数候选，9 个有同值候选，**7 个**在银标证据内有同值候选。多条证据是匿名姓名列表，本身没有“X 人”；部分列表同事件在不同目标文书重复。现有候选分类不可能解决这个供应缺口。9 个同值命中中有 2 个在银标证据外，需谨慎看待字段一致性。
- 3 个人数错误输出：1 条银标未提及却输出“6 人”，2 条银标为 5 却输出“6 人”。这说明角色提示“参赌人数”不足以证明目标事件的人数。
- 下一项工程实验应以**实体提及识别、同一人去重、参与关系和事件绑定**生成可追踪的派生人数候选，并与显式人数候选竞争；按事件分组评估候选召回和边正确性。测试集已打开，不能再用这 40 条挑规则或阈值；下一轮须另留封存样本或做事件级交叉验证。
