- **重算**：本文指标由当前冠军栈的实际预测重算。三个组件在 v3-clean 包上本地复现，与引擎线报告逐位一致；产物在 `relation_annotation/m4-tmark-20261027/run-A`。

## 0. 结论

1. **M4 的实现偏离了设计的问题定义。**
   - 设计：以要素为输入的神经-符号模型。法定空间 Ω 和地域随机效应作为结构，单调先验，分组共形区间。
   - 实现：事实文本的字符 TF-IDF，接分层 softmax（用采集批次做随机截距），再做档位重编码。
   - “符号”那一半：省级“赌资较大/情节严重”门槛没有核验，没有接进模型。
   - “学习”那一半：只有线性词袋模型，没有试过预训练编码器。
2. **离设计门槛很远，而且现有评估说不清差距的大小。** 所有 M4 硬指标都不达标（§3）。验证集只有 337 条：
   - 大约 30 个开发实验反复在同一批验证集上选模型；
   - 验证集里的批次全部在训练集中出现过，而部署时新案件没有批次；
   - 逐批留出（LOBO）显示，新批次上的类型准确率从 0.709 跌到 0.635。
   所以现在的验证分数是偏乐观的上限。
3. **主要瓶颈在问题定义和数据，不在模型细节。**
   - 总体没有定义：训练集是多批不同采集策略拼起来的；
   - 数据利用率低：湖里有 14,257 篇，训练只用了 1,682 条；
   - 法律知识没有接入；
   - 不知道裁量噪声的上限：历史机关决定基线 B-Hist 还没建，同案不同罚的程度未知，门槛本身是否可达也未知。
4. **对照同类研究和实务**：
   - **学术上**：处罚幅度预测是判决预测里最难的子任务（CAIL 区间准确率约 42–46%）；有效的做法是把法律结构编进模型（SMS）和类案检索（GLARE）。
   - **实务上**：主流是规则表、类案推送加偏离预警。
   - **本项目**：设计的定位（Ω ＋ 基准档位 ＋ 学习档内分布 ＋ 偏离预警）是对的，现在的实现在追“猜中机关的点决定”这个准确率竞赛。

**部署估计**：
- 验证集的批次全部在训练集中出现过（未见批次记录 0 条）。
- 逐批留出：新批次的截距设 0，类型准确率 0.635；在已见批次上是 0.709；冷启动池化只有 0.591。
- 部署时新案件不属于任何采集批次。改用可以部署的“机关”轴，lake706 只有 0.543，批次轴是 0.757。

所以表中“批次轴”的优势主要是**采集批次先验**，不能部署出去。

## 4. 评估体系的问题（为什么现有结论站不住）

1. **功效不足**：n=148 时，准确率的标准误约 3.9 个百分点。lake706 只有 28 个事件，一个事件翻转就会让类型正确数变化十几条（E8 实验实测）。冠军选择依据的差异（例如 99 对 94）在噪声范围内。
2. **自适应过拟合**：约 30 个开发实验在同一批 357 条上比较、选冠军，还按目标拼成“分目标冠军栈”。验证集实际上已经成了选模型的训练集（Dwork 2015，门禁 §7 引用）。
3. **分布内乐观**：验证集与训练集共享批次，部署场景是没见过的机关和时间，正确的口径是 LOBO 或按机关、时间外推（门禁里的 T-region、T-time 都还没建）。
4. **不知道天花板**：B-Hist 还没建，不知道同类案件的处罚离散度有多大。像 G3.5 的 MAE ≤1.5 天，可能高于数据本身的可达上限，也可能还远有空间。现在无从判断。

## 5. 表示与模型：词袋模型表达不了的东西

赌博行政处罚的生成过程大致如下（江苏、河北基准与公通字同构）：
1. 情节认定：赌资是否“较大”（省级数额线，常按个人或人均计）、角色（组织 / 提供条件 / 参与）、从重从轻情节；
2. 选档：一般档 / 严重档；
3. 档内选择：一般档是“拘留**或**罚款”，取决于机关习惯，这正是 tier 和 mode 两个头里批次方差最大的部分；
4. 锚点数额：跨批次稳定，合体实验测得锚点头的 σ² 只有 0.03–0.17。

字符 TF-IDF 的问题：
- **读不出数额相对于门槛的大小**：“赌资 3000 元”只是几个字符 n-gram；
- **分不清角色归属**；
- **不处理否定**；
- **无法做按要素的反事实和单调性检验**。

已经被证明有效的，恰好是把法律结构编进目标的那一步：档位重编码后，罚款 MAE 第一次在三套验证集上全部低于中位数基线。这与 SMS 的结论一致（起点 ＋ 增量 × 系数 ＋ 截断，小数据下胜过 CatBoost，91.3 对 87.4）。事后的 Ω 约束解码则无效：错误来自判别力不足，不是组合不合法。

**对“要素无增益”的再审视**：
- **证据**：注入实验的 oracle 只覆盖 valid119 中的 52 条，并且是以 log 数值特征喂给线性模型。这只能说明“在这个功效下没观察到增益”，不能证明“数额信息对裁量无用”。
- **为什么不能下“无用”的结论**：从法律机制看，数额相对于门槛是选档的直接原因。
- **正确的接入点**：M2 用已核验的省级门槛算出档位特征，作为先验，而不是建一个绑定服务。
- **先做的检验**：用确定性、不做归属的数额统计（事实中的最大金额、人均）做分组交叉验证，只有看到增益才谈归属。

## 6. 与同类研究、实务对照

| 对象 | 做法 | 对我们的含义 |
|---|---|---|
| CAIL2018 刑期 | TF-IDF ＋ SVM 42.05；MSR²（GRPO ＋ 多源检索）46.2（区间准确率） | 端到端的处罚幅度预测普遍不高，不应期待文本模型接近 0.8 |
| SMS（2025） | 按量刑流程做结构化建模，小数据胜过黑箱 | 支持“档位 ＋ 偏差”和专家 A |
| GLARE（2025） | 去掉判例推理，罪名准确率从 89.7 降到 80.0 | 类案（M5）是最大的结构性增益源，目前为零 |
| 实务（SAMR 自算器、浙江 405 号令、206 系统） | 规则表 ＋ 情节修正 ＋ 类案推送 ＋ 偏离预警，没有端到端预测 | 引擎的价值在“合法空间 ＋ 基准档位 ＋ 档内分布 ＋ 偏离度”，不在点预测准确率 |
| Electronics 2022（大陆行政裁量） | 用历史分布识别偏离裁量 | 与 M6 的偏离预警同向，评测口径应是覆盖率和校准，不只是准确率 |

## 7. 建议路线（按 ML 设计的依赖排序；每步先写判据，零成本证伪）

1. **评估地基（最高优先级）**：
   - 定义目标总体：河北 ＋ 江苏的赌博类行政处罚决定，按机关 × 年份分层；
   - 从湖里封存按事件计的 T-admin（≥300）和 T-time；
   - 选模型改在训练集内做“事件 × 机关”分组交叉验证；部署估计以 LOBO 或未见机关的成绩为准；
   - 现有三套验证集降级为描述性报告。
   - 依赖：积压文书要先过 S1（约 ¥35，需批准）；或者评估对 L1 结构化文书做确定性分段的可行性。
2. **噪声天花板（B-Hist）**：在同档位、近重复事实上量处罚离散度，给出各指标可达上限。若某个门槛高于上限，按门禁 §0 走修订。
3. **法律知识接入**：
   - 通过法宝 MCP 逐字核验两省基准；
   - M2 输出“赌资较大 / 情节严重”的档位特征和 Ω；
   - 先用确定性数额统计做分组交叉验证；
   - 实现专家 A（分层有序、单调先验，随机效应用机关或地域，不用采集批次）。
4. **表示学习对照**：在本机 GPU 上微调中文 RoBERTa 或 Lawformer，多头输出（档位 / 执行方式 / 锚点），在同一分组交叉验证下对比 TF-IDF。
5. **输出形态回到设计**：输出分布、温度校准、按地域 × 档位的分组共形区间、偏离度预警。验收指标是覆盖率、ECE 和 RPS，不只是准确率。
6. **类案（M5）**：建案例库，做 BM25 ＋ 向量检索，给出类案的处罚分布，作为专家 C 并入融合。
