# 裁判文书批量检索需求（第三方数据服务）

> 版本 v0.1 · 2026-10-15 · 依据：[行政案例数据交付规格](./data-spec.md)、[北大法宝手册](../04-plan/pkulaw-playbook.md)、CAIL 探针教训（[M1 学习笔记](./notes/M1-extraction.md) §8）
> 用途：向第三方数据服务提出检索需求，并在到货时验收。到货后的入库、脱敏由数据链路负责。

## 0. 先想清楚：裁判文书网能补什么

| 需要的数据 | 法宝现状 | 裁判文书网的价值 |
|---|---|---|
| 个人治安处罚决定书（行政金标主力） | 行政执法库已收录，"赌博 治安管理处罚法"命中 920 | **不在裁判文书网**：法院只公开法院文书，处罚决定书要靠法宝或执法公示 |
| 不服赌博治安处罚的**行政诉讼判决** | 司法案例库仅命中 25（学院订阅未绑定） | **核心价值①**：判决书会复述原处罚决定（事实 + 处罚），还附法院审查结论 |
| 赌博类**刑事判决全文** | 未系统检索 | **核心价值②**：CAIL 只截了事实段，完整判决的"本院认为"部分写有自首、坦白、退赃、主从犯等情节，能补上 CAIL 的信息缺口；同时用于刑事门槛边界（行刑衔接） |
| 刑事判决里提到的"曾因赌博被行政处罚" | — | 次要：可以拿到行政处罚的时间与结果，但没有当时的事实 |

## 1. 检索条件

### Q1 行政诉讼：不服赌博类治安处罚（优先级最高）

| 条件 | 取值 |
|---|---|
| 案件类型 | 行政案件 |
| 文书类型 | 判决书（必需）；裁定书只要二审、再审 |
| 全文关键词 | 赌博 **且**（治安管理处罚 **或** 行政拘留 **或** 行政处罚决定） |
| 补充关键词（任一命中即可，用来提高召回） | 参与赌博、为赌博提供条件、赌资较大、第七十条、第八十二条 |
| 排除 | 全文同时出现"开设赌场罪""赌博罪"且案件类型为刑事的 |
| 裁判日期 | 2013-01-01 至最新（2026-09） |
| 地域 | 全国，不限 |
| 审判程序 | 一审、二审、再审都要（同一案件的多份文书由我们按案号合并，防止训练集和测试集泄漏） |

**为什么最重要**：每份判决都相当于一件"带复核意见的行政处罚案例"：
- 原处罚决定认定的事实与处罚结果，可直接作为金标；
- 法院的结论（维持、撤销、变更、确认违法）告诉我们原处罚是否合法；被撤销的不能当作正确答案。

### Q2 刑事：赌博类犯罪全文（第二优先，按配额抽样）

| 条件 | 取值 |
|---|---|
| 案件类型 | 刑事案件 |
| 案由 | 赌博罪、开设赌场罪、组织参与国（境）外赌博罪 |
| 文书类型 | 判决书 |
| 审判程序 | 一审（主）；二审只要改判的 |
| 裁判日期 | 2013-01-01 至最新 |
| **抽样** | 这类判决数量很大。先要"省份 × 年份"的命中数统计表，再按每省每年不超过 50 件抽样（全国约 2 万件以内），不要全量 |

**用途**：
- 刑事门槛附近的案件（例如抽头几千元、赌资几万元就被起诉的），用来刻画行政处罚与刑事追诉的分界；
- 完整判决里的量刑情节，用来重做锚点 A2；
- 后续的刑事扩展。

### Q3 刑事判决中的行政处罚前科（低优先，可选）

全文："因赌博被" **且**（"行政拘留" **或** "行政处罚"）。只取命中句子所在段落即可。

## 2. 每份文书需要的字段

| 字段 | 必需 | 为什么 |
|---|---|---|
| 文书唯一标识（文书 ID 或原始 URL） | ✅ | 去重、溯源（数据卡要记录） |
| 案号、标题 | ✅ | 合并同一案件的一审、二审文书 |
| 法院名称、法院层级、所在省、市、区县 | ✅ | 适用哪个省的裁量基准；按地域分组评测 |
| 案件类型、案由、文书类型、审判程序 | ✅ | 筛选与分层 |
| 裁判日期（及公开日期） | ✅ | 判断适用新法还是旧法 |
| **完整正文，保留分段和换行** | ✅ **最关键** | 要能切出"原告诉称 / 被告辩称 / 经审理查明 / 本院认为 / 判决如下"各段。**只给摘要或去掉换行的全文没有用**（CAIL 的教训） |
| 引用法条列表（如有结构化字段） | 建议 | 交叉核对处罚依据 |
| 关联文书（一审与二审的对应关系） | 建议 | 防止同一案件同时出现在训练集和测试集 |
| 当事人姓名、身份证号、住址等 | ❌ **不需要** | 我们只需要当事人的诉讼角色（原告、被告、第三人）；能不要的个人信息一律不要 |

**格式**：UTF-8 编码的 JSONL 或 CSV，每份文书一条记录，正文作为单独字段；附各检索条件的命中数统计。

## 3. 先买样例，验收通过再批量

每个检索条件先要 **20 份样例**，逐项检查：

| 检查项 | 合格标准 |
|---|---|
| 正文完整 | 20 份中至少 18 份能切出"经审理查明""本院认为""判决如下"三段 |
| 编码 | 没有"?"、"�"之类的乱码（CAIL 原文里就有） |
| 字段 | §2 的必需字段齐全 |
| 真实性 | 随机抽 3 份，到裁判文书网或北大法宝核对案号与正文一致 |
| 年份覆盖 | 命中数统计表里 2021 年以后的年份没有异常断崖（若有，问清是源网站公开量减少还是对方采集缺失） |
| 重复 | 同一文书 ID 不重复 |

样例合格，再按 Q1 全量、Q2 抽样下单。

## 4. 到货后怎么用

```
到货文件 → 外置数据目录 inbox/wenshu/ → 数据链路导入台账（channel=C，来源注明"第三方数据服务，原始来源中国裁判文书网"）
        → 脱敏 → 按段切分 → 按数据交付规格 §1 产出：
           Q1：原处罚决定的事实（text_facts）、原处罚结果（outcome）、法院结论（review.result）
           Q2：查明事实（text_facts）、本院认为中的情节（作为情节要素）、判决结果（标签）
```

注意：行政判决中"被告作出的处罚决定认定……"这一段才是原处罚的事实与结果；法院"本院认为"是对它的审查。两者要分开，前者是题目和答案，后者是"答案对不对"的复核。

## 5. 合规注意

- 裁判文书是依法公开的司法文书，但**第三方批量转售的数据来源是否合规无法由我们核实**。下单前请指导老师确认是否可以用于本项目；只作项目研究使用，不再分发，不用于任何营利目的。
- 文书中仍含个人信息。按《个人信息保护法》，处理已合法公开的个人信息应限于合理范围：入库前脱敏，只保留研究需要的字段（§2 已排除姓名、证件号、住址）。
- 数据卡如实记录来源（第三方数据服务）、下单日期、检索条件、数量；结题材料只引用案号，不附原文。
- 同样的检索如果在学院订阅的北大法宝中可以完成，优先走法宝（官方授权渠道）；第三方数据作为补充。

## 6. 可直接发给卖家的需求

> 你好，需要"部分数据检索"服务，先买样例再定全量。
>
> **检索 1（行政）**：案件类型=行政案件；文书类型=判决书（裁定书只要二审、再审）；全文含"赌博"，且含"治安管理处罚"或"行政拘留"或"行政处罚决定"；裁判日期 2013-01-01 至最新；全国。
>
> **检索 2（刑事）**：案件类型=刑事案件；案由=赌博罪、开设赌场罪、组织参与国（境）外赌博罪；文书类型=判决书；一审；裁判日期 2013-01-01 至最新；全国。先只要"省份 × 年份"的命中数统计。
>
> **字段**：文书 ID 或原始链接、案号、标题、法院、法院层级、省市区县、案件类型、案由、文书类型、审判程序、裁判日期、公开日期、**完整正文（保留分段换行）**、引用法条、关联文书。**不需要**当事人身份证号、住址等个人信息。
>
> **格式**：UTF-8 的 JSONL 或 CSV，正文单独一个字段。
>
> **先要**：检索 1 和检索 2 各 20 份样例，加两个检索的"省份 × 年份"命中数统计表。看过样例后再报全量和抽样需求。请问这样的样例和统计怎么收费？
